  - **③ 正常仕損品評価額**：`8,000円`（投入計 `165,000 + 900,000 + 1,720,000 = 2,785,000円` ＝ 産出計 `2,322,000 + 455,000 + 8,000 = 2,785,000円` 完全一致）。
- **誤答パターン分析**：先入先出法で月初仕掛品（進捗40%＜50%）も当期に50%地点を通過した事実を見落とし、完成品から月初100個を引いた660個だけで仕損費を按分してしまうミスに注意。

### 原価計算（25点）：解答＆解説

- **第1問（LP最適セールス・ミックス）**：
  - 制約式：`2X + Y <= 1,000`（機械）、`X + 2Y <= 1,100`（労働）。交点：`X = 300, Y = 400`。
  - 端点比較：`(0,0)→0`、`(500,0)→315,000`、`(0,550)→264,000`、**`(300, 400) → 300×630 + 400×480 = 381,000円`（最大）**。
  - シャドウ・プライス連立（`2π_M + π_L = 630`, `π_M + 2π_L = 480`）：**機械 `π_M = 260円/h`**、**労働 `π_L = 110円/h`**（双対検算：`1,000×260 + 1,100×110 = 381,000円` 完全一致）。
- **第2問（取替設備投資 NPV）**：
  - **① WACC**：`40% × 5% × (1 - 0.30) + 60% × 11% = 1.4% + 6.6% = 8.0%`。
  - **② T=0正味CF**：`△6,000,000 + 1,200,000 + (2,000,000 - 1,200,000) × 30% = △6,000,000 + 1,200,000 + 240,000 = △4,560,000円`。
  - **年次差額CF（T=1〜4）**：`1,800,000 × (1 - 0.30) + (1,500,000 - 500,000) × 30% = 1,260,000 + 300,000 = +1,560,000円/年`。
  - **NPV**：`1,560,000 × 3.3121 - 4,560,000 = 5,166,876 - 4,560,000 = +606,876円 ＞ 0` → **取替案を採用**。
- **誤答パターン分析**：取替投資において旧設備売却時の節税効果（売却損`800,000 × 30% = +240,000`）を見落とす、または旧設備の帳簿価額`2,000,000`そのものをT=0のキャッシュ・フローに含めてしまう（埋没原価の誤り）ミスが最頻出です。
