# EX-01：過去問出題傾向分析＆2027年新区分・合格戦略ガイド

> **本巻の位置づけ**：本カリキュラム全55単元（3級〜1級）の学習効果を最大化するための**「試験構造・過去問傾向・タイムマネジメント・2027年改定対応」完全攻略ガイド**です。ただ闇雲に問題を解くのではなく、**「試験官がどこに配点を置き、どこで受験生を振るい落とすのか」**を数値と構造で把握しましょう。

---

## 1. 2027年4月改定＆新リース会計基準（第34号）の試験インパクト

2026年末〜2028年にかけて日商簿記を受験する学習者にとって、最大の分岐点は**「2027年4月施行の出題区分改定」**と**「企業会計基準第34号（新リース会計基準）の完全適用」**です。

| 級 | 2027年4月で「廃止・縮小」される論点 | 2027年4月で「新設・強化」される論点 | 本カリキュラムでの対応単元 |
| :--- | :--- | :--- | :--- |
| **3級** | ・紙の約束手形・為替手形・小切手論点（※2027年4月改定で廃止）<br>・受取手形・支払手形・他人振出小切手・当座小切手の処理（※2027年3月までの経過論点） | ・**売上原価対立法**（商品販売時の原価振替）<br>・**200%定率法**（期中取得の月割含む）<br>・**固定資産の除却・廃棄**<br>・キャッシュレス／電子決済・電子記録債権債務の比重増 | `L3-02` `L3-03` `L3-04` `L3-06` |
| **2級** | ・手形の裏書・割引・不渡手形等の紙手形実務（※2027年4月改定で廃止）<br>・小切手中心の銀行勘定調整表（※2027年4月改定で廃止） | ・**新リース会計基準第34号（使用権資産・リース負債・利息法）**<br>・**2社間／3社間ファクタリング**（債権流動化）<br>・**口座振替・ネットバンキング中心の銀行勘定調整表**<br>・**収益認識基準（契約資産・契約負債・履行義務配分）** | `L2C-01` `L2C-02` `L2C-05` |
| **1級** | ・旧リース基準の「ファイナンス／オペレーティング」2区分前提の処理 | ・**新リース会計基準第34号・完全版**（単一モデル、条件変更、セール・アンド・リースバック、サブリース、貸手2区分）<br>・**収益認識基準（第29号）の高度論点**（ポイント・返品権・本人/代理人・工事契約） | `L1C-05` `L1C-08` |

> **戦略的結論**：3級から紙の手形・小切手（※2027年4月改定で廃止）に時間を費やす必要はありません。浮いた学習時間を**「電子記録債権・債務」「売上原価対立法」「定率法」「新リース基準第34号」**へ直結させることが最短合格の鉄則です。

## 2. 日商簿記1級 過去問徹底分析（第165回〜第170回ベース）

日商簿記1級は、**商業簿記（25点）・会計学（25点）・工業簿記（25点）・原価計算（25点）＝ 合計100点満点（試験時間：前半90分＋休憩＋後半90分）**で実施されます。

### (1) 絶対ルール：合格基準70点 ＋「各科目40%（10点）足切り」

1級の合否を分ける最大の罠は**「1科目でも10点未満（0〜9点）があると、合計点が80点を超えても即不合格」**になる足切り制度です。

```
【1級・合格スコアの理想ポートフォリオ（目標75〜80点）】
  商業簿記 : 16〜18点 / 25点  ← 難所は捨てて「取れる標準項目」を死守
  会計学   : 17〜20点 / 25点  ← 理論の穴埋め＋標準計算で稼ぐ
  工業簿記 : 20〜23点 / 25点  ← 最大の得点源！計算ミスゼロで満点近くを狙う
  原価計算 : 18〜22点 / 25点  ← 意思決定・NPV・予算管理は型通り解けば安定
  -------------------------------------------------------------------------
  合計目標 : 71〜83点 / 100点（全科目10点以上を安定クリア）
```

### (2) 商業簿記・会計学（50点）の過去問ローテーション分析

第165回〜第170回の出題実績から、1級商簿・会計学は**以下の7大領域がローテーション**しています。

| 領域 | 過去問での出題頻度・トレンド | 本試験での急所と対策単元 |
| :--- | :--- | :--- |
| **① 収益認識（第29号）** | ほぼ毎回出題（商簿決算整理 or 会計学小問） | ポイント制度（契約負債）、返品権付販売（返金負債・返品資産）、本人/代理人、工事契約・工事損失引当金（`L1C-05`） |
| **② 連結会計・組織再編** | 隔回〜連続出題（但し第170回のように連結が出ない回も存在） | 在外子会社換算、段階取得・追加取得・一部売却・時価発行増資、包括利益、連結CF、事業分離（`L1C-12`〜`L1C-15`） |
| **③ 退職給付会計** | 超頻出（個別ワークシート or 連結即時認識） | PBO・年金資産のボックス連携、数理計算上の差異の翌期定額償却 vs 連結上の一括処理（`L1C-09`） |
| **④ 固定資産（減損・ARO）** | 商簿の主役級 | 共用資産・のれんを含む減損（より大きい単位）、AROの割引率・見積り上方/下方修正のレイヤー管理（`L1C-06` `L1C-07`） |
| **⑤ 金融商品会計** | 商簿＋会計学理論で毎回出題 | 債権3区分（CF見積法）、有価証券・社債利息法、新株予約権付社債、ヘッジ会計（繰延/時価）（`L1C-02`〜`L1C-04`） |
| **⑥ 新リース会計基準（34号）** | 2027年以降・最重要急上昇領域 | 借手単一モデル（使用権資産・リース負債）、条件変更（範囲拡大 vs 延長）、S&LB、サブリース（`L1C-08`） |
| **⑦ 税効果・純資産・EPS** | 決算整理の仕上げ・会計学第2/3問で定番 | 回収可能性、税率変更、その他有価証券評価差額金、ストック・オプション、希薄化EPS（`L1C-10` `L1C-11` `L1C-15`） |

> **第170回からの重要教訓**：「今回は連結が出るはず」と山を張ると、連結が出題されずに個別総合F/S＋特殊論点で足切りを食らうリスクがあります。**「連結も個別総合もどちらも18点取れる」**状態を作ることが唯一無二の安全策です。

### (3) 工業簿記・原価計算（50点）の過去問ローテーション分析

工簿・原価計算は商簿に比べて**計算量が読め、解法パターン（型02・型05・型06・型10）がそのまま通用する**ため、合格者のほとんどが後半科目で40点前後を確保しています。

| 領域 | 過去問での出題頻度・トレンド | 本試験での急所と対策単元 |
| :--- | :--- | :--- |
| **① 部門別・個別・総合原価** | 工業簿記の定番（第1問または第2問） | 複数基準配賦・連立方程式法、非度外視法（両者負担 vs 完成品負担）、非累加法の累加法検算、連産品・副産物（`L1I-01`〜`L1I-03`） |
| **② 標準原価・予算差異** | 隔回で高配点 | 配合差異・歩留差異、原価差異の月末仕掛品・売上原価按分、市場総需要・占有率差異（`L1I-04` `L1I-06`） |
| **③ 直接原価・CVP・LP** | 原価計算の得点源 | 最適セールス・ミックス（LP図解法＋シャドウプライス）、固変分解、固定費調整（`L1I-05`） |
| **④ 設備投資・業績評価** | 原価計算の超頻出大問 | 取替設備投資のNPV（売却損益タックス・シールド＋差額減価償却節税）、WACC、IRR、ROI・RI・EVA（`L1I-07` `L1I-09` `L1I-10`） |

### (4) 1級本試験・分単位タイムマネジメント（標準型）

```
【前半90分：商業簿記（25点）＋ 会計学（25点）】
  00〜03分 : 全体俯瞰（会計学の理論・小問から先に着手するか判断）
  03〜33分 : 会計学（30分で20点確保！理論＋第2・3問の標準計算）
  33〜83分 : 商業簿記（50分：型01/04/07/08/09の枠を先に書き、集計）
  83〜90分 : 検算・足切り回避チェック（転記ミス・符号・千円単位確認）

【後半90分：工業簿記（25点）＋ 原価計算（25点）】
  00〜03分 : 問題文の「原価計算基準」「端数処理」「度外視/非度外視」確認
  03〜43分 : 工業簿記（40分：型02ボックス／型06差異図を丁寧に描き切る）
  43〜83分 : 原価計算（40分：型10キャッシュ・フロー表でT=0と各期を分離）
  83〜90分 : 検算（投入＝産出、差異合計一致、LP交点の代入チェック）
```

## 3. 日商簿記2級（90分・100点・CBT/統一）攻略戦略

2級は「90分で5大問」を解き切るスピードと正確性が問われます。**推奨解答順序は「第1問 → 第4問 → 第5問 → 第3問 → 第2問」**です。

| 大問 | 配点 | 目安時間 | 出題内容と攻略の急所 |
| :--- | :---: | :---: | :--- |
| **第1問** | 20点 | 10分 | 商簿仕訳5問（新リース34号、ファクタリング、収益認識、外貨、圧縮記帳など）。満点必須。 |
| **第4問** | 28点 | 20分 | 工業簿記仕訳（12点）＋部門別/個別/総合原価計算（16点）。型02・型05で24点以上確保。 |
| **第5問** | 12点 | 15分 | 標準原価計算または直接原価計算・CVP分析。型06・型10で満点狙い。 |
| **第3問** | 20点 | 25分 | 損益計算書（P/L）または貸借対照表（B/S）作成。銀行勘定・棚卸減耗/評価損・税効果・リースを正確に集計。 |
| **第2問** | 20点 | 20分 | 連結会計（P/L・B/S・精算表）または株主資本等変動計算書（S/S）・銀行勘定調整等。最後に残すことで焦りを防止。 |

## 4. 日商簿記3級（60分・100点・CBT/統一）攻略戦略

3級は60分という短時間決戦です。2027年4月改定後は**「定率法」「売上原価対立法」「除却・廃棄」**が第1問・第2問・第3問のすべてで狙われます。

| 大問 | 配点 | 目安時間 | 出題内容と攻略の急所 |
| :--- | :---: | :---: | :--- |
| **第1問** | 45点 | 15分 | 仕訳15問（×3点）。ここだけで45点あるため、39〜45点を取れば合格がほぼ確定。 |
| **第2問** | 20点 | 15分 | 帳簿・補助簿（商品有高帳・固定資産台帳）・勘定記入・伝票。移動平均法と200%定率法の月割に注意。 |
| **第3問** | 35点 | 25分 | 決算整理後残高試算表・精算表・P/L＆B/S作成。残り5分で見直し（貸借合計一致チェック）。 |
