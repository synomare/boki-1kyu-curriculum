# EX-05：1級会計学・原価計算 頻出理論論証＆穴埋めスーパー50選

> **本巻の使い方**：日商簿記1級の「会計学 第1問」および「原価計算 理論問題」で毎年狙われる**最重要50論証**を10領域に体系化しました。丸暗記ではなく、**「①結論（何が正しいか）→ ②理論根拠（なぜそうなるか）→ ③本試験キーワード（空欄補充の急所）」**の3段構造で脳に定着させてください。

## 領域1：概念フレームワーク・一般原則・会計上の変更（01〜05）

### 01. 財務報告の目的と意思決定有用性
- **結論**：投資家が企業の将来キャッシュ・フローを予測し、企業価値を評価するための情報（**意思決定有用性**）を提供すること。
- **理論根拠**：投資家の自己責任に基づく投資意思決定を支援することが現代会計の主目的であり、副次的に経営者の受託責任の解除にも資する。
- **本試験キーワード**：`意思決定有用性` / `将来キャッシュ・フローの予測` / `受託責任`

### 02. 資産・負債の定義（資産負債アプローチ）
- **結論**：資産＝過去の取引等の結果として報告主体が支配している**経済的資源**、負債＝経済的資源を引き渡す**義務**。
- **理論根拠**：収益・費用を主軸とする収益費用アプローチから、ストック（B/S）の定義を起点とする資産負債アプローチへ世界の会計基準が移行したため。
- **本試験キーワード**：`経済的資源` / `支配` / `義務` / `資産負債アプローチ`

### 03. 実現可能・投資のリスクからの解放
- **結論**：純利益は、投資にあたって期待された成果が**投資のリスクから解放**された時点で認識される。
- **理論根拠**：売買目的有価証券の評価益は事業上の拘束がなく市場でいつでも換金できるため純利益に含めるが、事業用資産や持ち合い株の時価変動はリスクから解放されていない。
- **本試験キーワード**：`投資のリスクからの解放` / `事業投資` / `金融投資`

### 04. 会計方針の変更（遡及適用）
- **結論**：正当な理由により会計方針を変更した場合、原則として新たな会計方針を過去の財務諸表に**遡及適用**する。
- **理論根拠**：財務諸表の期間比較可能性を確保するため、過去から新方針を採用していたかのように修正再表示する必要がある。
- **本試験キーワード**：`期間比較可能性` / `遡及適用` / `累積的影響額`

### 05. 会計上の見積りの変更（プロスペクティブ処理）
- **結論**：耐用年数の変更など会計上の見積りの変更は遡及せず、**当期及び将来期間**にわたり影響額を認識する（キャッチアップは行わない）。
- **理論根拠**：見積りの変更は新たな情報の入手に伴うものであり、過去の誤謬ではないため過年度を修正すべきではない。
- **本試験キーワード**：`新たな情報` / `将来にわたり` / `減価償却方法の変更`（見積りの変更に準じる）

- [ ] **領域1チェック**：概念フレームワークの投資のリスクからの解放と、方針変更（遡及）vs 見積り変更（将来）の違いを自分の言葉で説明できる。

## 領域2：金融商品会計・ヘッジ会計（06〜10）

### 06. 金融資産の消滅の認識（財務構成要素アプローチ）
- **結論**：金融資産の契約上の権利に対する**支配が他に移転**したときに、当該金融資産の消滅を認識する。
- **理論根拠**：リスクと経済価値のすべてが移転しなくとも、権利を構成要素に分解し、支配の移転を基準にオフバランス判定を行うため（ファクタリング等）。
- **本試験キーワード**：`財務構成要素アプローチ` / `支配の移転` / `リコース義務`

### 07. 売買目的有価証券の時価評価とP/L計上
- **結論**：時価をもってB/S価額とし、評価差額は当期の損益（P/L）として処理する。
- **理論根拠**：時価の変動により利益を得ることを目的として保有しており、事業遂行上の制約がなく投資のリスクから解放されているため。
- **本試験キーワード**：`時価評価` / `評価差額の損益計上` / `事業上の制約がない`

### 08. その他有価証券の全部純資産直入法
- **結論**：評価差額（税効果控除後）をP/Lに通さず、B/Sの純資産の部（**その他の包括利益累計額**）へ直接計上する。
- **理論根拠**：直ちに売却できない事業上の制約等があり、時価変動が投資のリスクから解放されていないため、当期純利益に含めるべきではない。
- **本試験キーワード**：`全部純資産直入法` / `リサイクリング` / `洗替方式`

### 09. 償却原価法における利息法と定額法
- **結論**：取得価額と債券金額との差額の性格が**金利の調整**と認められる場合、原則として**利息法**により各期の損益へ配分する。
- **理論根拠**：各期の帳簿価額に対して一定の実効利子率を乗じることで、期間損益計算をより正確に経済的実態に一致させるため。
- **本試験キーワード**：`金利の調整` / `実効利子率` / `利息法`

### 10. ヘッジ会計（原則：繰延ヘッジ vs 特例：時価ヘッジ）
- **結論**：ヘッジ対象とヘッジ手段の**損益を同一の会計期間に認識**し、ヘッジ効果を財務諸表に反映させる。
- **理論根拠**：両者の評価基準のズレによって生じる見かけ上の期間損益の歪みを排除するため（原則はヘッジ手段の損益を純資産に繰り延べる）。
- **本試験キーワード**：`損益の期間的対応` / `繰延ヘッジ損益` / `有効性評価`

- [ ] **領域2チェック**：金融資産の消滅要件（支配の移転）、有価証券4分類の理論的根拠、ヘッジ会計の存在意義を説明できる。

## 領域3：収益認識会計基準・第29号（11〜15）

### 11. 収益認識の基本原則と5つのステップ
- **結論**：約束した財又はサービスの顧客への移転（**支配の移転**）を、企業が権利を得ると見込む対価の額で描写する。
- **理論根拠**：契約を「①識別→②履行義務識別→③取引価格算定→④配分→⑤充足時認識」の5ステップで分解し、業種横断的な比較可能性を担保する。
- **本試験キーワード**：`支配の移転` / `履行義務` / `取引価格の配分`

### 12. 変動対価と見積りの制限
- **結論**：値引き・リベート・返品等の変動対価は最頻値または期待値で見積るが、重大な戻入れが生じない可能性が高い範囲に**制限**される。
- **理論根拠**：不確実性の高い収益を過大計上し、後の期間で巨額の収益取消しが発生するリスク（保守的配慮）を防ぐため。
- **本試験キーワード**：`最頻値` / `期待値` / `重大な戻入れ`

### 13. 重要な金融要素
- **結論**：移転と支払の時期が大きく離れる場合（原則1年超）、貨幣の時間価値の影響を調整し**金利相当額を収益から分離**する。
- **理論根拠**：割賦販売や長期前受金に含まれる実質的な金融収益・金融費用を、本来の売上収益と明確に区別するため。
- **本試験キーワード**：`貨幣の時間価値` / `1年以内の実務上の便法` / `受取利息・支払利息`

### 14. 本人（総額）と代理人（純額）の区分
- **結論**：移転前に財又はサービスを**支配している場合は本人（総額表示）**、手配するだけの場合は**代理人（手数料の純額表示）**となる。
- **理論根拠**：百貨店の消化仕入やプラットフォーム仲介において、実態以上の売上規模の膨張を防ぐため（主たる責任・在庫リスク・価格決定権で判定）。
- **本試験キーワード**：`本人と代理人` / `主たる責任` / `在庫リスク` / `価格設定の裁量権`

### 15. 一定の期間にわたり充足される履行義務と進捗度
- **結論**：顧客が便益を同時に享受、支配を創出・増価、または代替用途がなく対価の強制力ある権利がある場合、**進捗度**に応じて認識する。
- **理論根拠**：長期工事契約等において、完成時点まで収益ゼロとすると経営成績を適切に表せないため（原価発生額割合等のインプット法で測定）。
- **本試験キーワード**：`代替的な用途` / `強制力のある権利` / `原価比例法`

- [ ] **領域3チェック**：5ステップ、変動対価の制限、本人 vs 代理人の3指標、一定期間充足の3要件を説明できる。

## 領域4：固定資産・減損・資産除去債務（16〜20）

### 16. 減価償却の本質（費用配分 vs 資産評価）
- **結論**：減価償却とは取得原価を耐用年数にわたり各期へ配分する**費用配分の手続**であり、時価評価ではない。
- **理論根拠**：収益と費用の期間対応を図り、投下資本の回収計算を体系的・規則的に行うことが目的である。
- **本試験キーワード**：`費用配分の原則` / `規則的・計画的` / `投下資本の回収`

### 17. 減損損失の認識判定と測定（2段階テスト）
- **結論**：兆候あり→**割引前将来CF総額＜帳簿価額**で減損を認識し、**帳簿価額−回収可能価額**を減損損失として測定する。
- **理論根拠**：将来キャッシュ・フローの予測には不確実性が伴うため、割引前CFで「回収不能が確実」な場合のみ減損を認識し、過度な切り下げを防ぐ。
- **本試験キーワード**：`割引前将来キャッシュ・フロー` / `回収可能価額` / `正味売却価額と使用価値の高い方`

### 18. 減損損失の戻入れの禁止
- **結論**：我が国の減損会計基準では、一度認識した減損損失の**戻入れは一切行わない**。
- **理論根拠**：減損処理は帳簿価額の臨時的な切り下げであり、その後の回復を認識すると実質的な時価評価（再評価）に近づき、事務負担も過大になるため。
- **本試験キーワード**：`減損損失の戻入れ禁止` / `取得原価基準との整合`

### 19. 資産除去債務（ARO）の両建処理（引当金処理との比較）
- **結論**：除去支出の割引現在価値を**負債（ARO）**として計上し、同額を有形固定資産の**取得原価に加算（資産化）**して減価償却する。
- **理論根拠**：引当金処理（毎期少しずつ引当金繰入）では資産購入時点で既に負っている法的義務がB/Sに表れないため、投資の全体像（将来負担含む）を開示する。
- **本試験キーワード**：`両建処理` / `資産化` / `無リスクの税引前割引率` / `時の経過による調整額（利息費用）`

### 20. 研究開発費の即時費用処理
- **結論**：研究費および開発費は発生時に全額**費用処理**する（自社利用ソフトウェアの制作費を除く）。
- **理論根拠**：将来の収益獲得との因果関係が極めて不確実であり、資産計上すると利益操作の温床となるため（実務上の一律保守的処理）。
- **本試験キーワード**：`発生時費用処理` / `将来の収益獲得の不確実性` / `市場販売目的のソフトウェア（製品マスター完成後）`

- [ ] **領域4チェック**：減損の2段階判定、戻入れ禁止の理由、AROの両建処理が引当金処理より優れている理由を説明できる。

## 領域5：新リース会計基準・第34号（21〜25）

### 21. 借手の単一会計処理モデル（使用権資産モデル）
- **結論**：新リース基準（第34号）では、借手はファイナンス／オペレーティングを区分せず、原則すべてのリースを**オンバランス**する。
- **理論根拠**：旧基準のオペレーティング・リースによる巨額のオフバランス負債が財務比較可能性を損ねていたため、**使用権資産**と**リース負債**を認識する単一モデルへ統一された。
- **本試験キーワード**：`単一モデル` / `使用権資産` / `リース負債` / `原資産の使用を支配する権利`

### 22. リースの識別（特定された資産＋支配）
- **結論**：契約に「**特定された資産**」が含まれ、借手がその使用からの経済的便益のほとんどすべてを享受し、使用を指図する権利を有するときにリースを含むと判定する。
- **理論根拠**：供給者に実質的な入替権がある単なるサービス契約と、実質的な資産の使用権移転を伴うリース契約を明確に線引きするため。
- **本試験キーワード**：`特定された資産` / `実質的な入替権` / `使用を指図する権利`

### 23. リースの条件変更（別個のリース vs 既存契約の修正）
- **結論**：使用権の追加かつ独立価格に見合う増額であれば「**別個のリース**」、それ以外（期間延長・減額等）は**新たな割引率で負債を再測定**し使用権資産を調整する。
- **理論根拠**：実質的に新しい契約を追加したケースと、既存リースの条件を再交渉したケースを経済的実態に応じて区別するため。
- **本試験キーワード**：`別個のリース` / `独立価格` / `新たな追加借入利子率`

### 24. セール・アンド・リースバック（S&LB）の譲渡判定
- **結論**：資産の移転が**収益認識基準（第29号）の売却要件**を満たす場合のみ売却を認識し、売却損益は**借手が保持しない権利の割合**に限定して認識する（実務上の日本の特徴として全額売却益認識との比較も重要）。
- **理論根拠**：売った直後にリースで買い戻す取引は実質的な担保付金融取引（借入）になり得るため、支配の移転を厳格に判定する。
- **本試験キーワード**：`売却の要件` / `金融取引` / `保持する使用権の割合`

### 25. 貸手の会計処理（2区分モデルの維持）
- **結論**：借手と異なり、貸手は従来通り**ファイナンス・リース**（売買/融資）と**オペレーティング・リース**（賃貸）の2区分を維持する。
- **理論根拠**：貸手は原資産の法的所有権や残存価値リスクを保持しており、実質的な売却か賃貸かを区別した方が経営実態を適切に表すため。
- **本試験キーワード**：`貸手の2区分維持` / `フルペイアウト・ノンキャンセラブル`

- [ ] **領域5チェック**：2027年新リース基準（第34号）でなぜ借手だけが単一モデルになったのか、貸手との非対称性を説明できる。

## 領域6：退職給付・純資産・ストック・オプション（26〜30）

### 26. 退職給付債務（PBO）の性格と遅延認識
- **結論**：退職給付見込額のうち当期末までに発生していると認められる額を割引計算したものがPBOであり、個別B/Sでは数理計算上の差異等を**遅延認識**する。
- **理論根拠**：数理差異（割引率変更や期待運用差額）を個別P/Lで即時全額認識すると損益が大きく乱高下するため、平均残存勤務期間以内で償却する。
- **本試験キーワード**：`退職給付見込額` / `割引計算` / `数理計算上の差異` / `遅延認識`

### 27. 連結財務諸表上の退職給付の即時認識（OCI計上）
- **結論**：連結B/S上では未認識項目を負債（退職給付に係る負債）にすべて反映し、相手勘定を純資産の**退職給付に係る調整累計額（OCI）**とする。
- **理論根拠**：P/Lのボラティリティはリサイクリングにより維持しつつ、B/S上でのオフバランス負債（未認識債務の隠蔽）を解消するため。
- **本試験キーワード**：`即時認識` / `退職給付に係る負債` / `その他の包括利益累計額` / `リサイクリング`

### 28. 自己株式の取得・処分・消却（資本取引の徹底）
- **結論**：自己株式の取得は資本の払戻し（**純資産の控除項目**）、処分・消却差額は損益ではなく**その他資本剰余金**で処理する。
- **理論根拠**：企業と株主との間の資本取引から損益は生じないという「資本取引・損益取引区分の原則」を貫徹するため。
- **本試験キーワード**：`資本の払戻し` / `資本取引・損益取引区分の原則` / `その他資本剰余金`

### 29. ストック・オプション（SO）の費用計上根拠
- **結論**：SOの付与は労働サービスの対価であり、付与日現在の**公正な評価単価**に基づき勤務期間にわたり**株式報酬費用**として計上する。
- **理論根拠**：現金の代わりに自社株オプションで報酬を支払った場合でも、企業が労働サービスを消費した経済的実態（費用発生）は変わらないため。
- **本試験キーワード**：`労働サービスの消費` / `付与日` / `公正な評価単価` / `新株予約権`

### 30. 純資産の部の区分（株主資本 vs それ以外）
- **結論**：純資産の部は**株主資本**と**株主資本以外の各項目**（評価・換算差額等、株式引受権、新株予約権、非支配株主持分）に区分される。
- **理論根拠**：親会社の株主に帰属する自己資本（ROEの分母等）と、リスクから未解放の項目や第三者持分を明確に切り分けるため。
- **本試験キーワード**：`株主資本` / `評価・換算差額等` / `新株予約権` / `非支配株主持分`

- [ ] **領域6チェック**：退職給付の個別（遅延）と連結（B/S即時・OCI）の対比、自己株式とSOの理論根拠を説明できる。

## 領域7：税効果会計・外貨換算会計（31〜35）

### 31. 税効果会計の目的（資産負債法）
- **結論**：会計上の利益と税務上の課税所得との**一時差異**を調整し、税引前当期純利益と法人税等を**合理的に期間対応**させる。
- **理論根拠**：繰延税金資産・負債の計上を通じて、将来の税負担の軽減または増加の経済的実態をB/S・P/Lに反映するため（永久差異は対象外）。
- **本試験キーワード**：`一時差異` / `永久差異` / `資産負債法` / `法定実効税率`

### 32. 繰延税金資産の回収可能性
- **結論**：将来の課税所得を減少させる効果が見込まれない部分については、**評価性引当額**として繰延税金資産を減額する。
- **理論根拠**：将来赤字続きで税金が減らない企業に資産性を認めることは、資産の定義（将来経済的便益）に反するため（5分類で判定）。
- **本試験キーワード**：`回収可能性` / `評価性引当額` / `将来課税所得`

### 33. 外貨建取引の一取引基準 vs 二取引基準
- **結論**：現行基準では、取引の発生と決済を別個の取引とみなす**二取引基準**を採用し、決済までの為替変動を**為替差損益**とする。
- **理論根拠**：商品の売買損益と、代金決済を遅らせたことによる外貨保有リスク（金融損益）を明確に分離して業績評価するため。
- **本試験キーワード**：`二取引基準` / `為替差損益` / `貨幣項目（CR換算）と非貨幣項目（HR換算）`

### 34. 在外子会社の決算日レート法と為替換算調整勘定
- **結論**：在外子会社の資産・負債は**決算日レート（CR）**、収益・費用は**期中平均レート（AR）**で換算し、差額を**為替換算調整勘定**とする。
- **理論根拠**：現地で独立して事業を営む在外子会社の財務比率を維持するためCR法を採り、換算差額は未実現のためP/Lではなく純資産（OCI）とする。
- **本試験キーワード**：`決算日レート法` / `期中平均レート` / `為替換算調整勘定`

### 35. 為替予約等の振当処理と独立処理
- **結論**：原則はデリバティブを時価評価する**独立処理**だが、一定の要件を満たせば予約レートで確定させる**振当処理**（特例）が認められる。
- **理論根拠**：直物と先物のレート差（直々差額・直先差額）を実務上の簡便性から期間配分または一括処理するため。
- **本試験キーワード**：`独立処理（原則）` / `振当処理` / `直々差額・直先差額`

- [ ] **領域7チェック**：一時差異 vs 永久差異、二取引基準の理由、在外子会社CR法の換算差額がP/Lに行かない理由を説明できる。

## 領域8：連結・企業結合・包括利益・CF（36〜40）

### 36. 経済的単一体説（親会社説からの移行）
- **結論**：企業集団を親会社と非支配株主を含めた単一の経済実体とみなし、**非支配株主持分も純資産の部に含め、子会社資産負債を全面時価評価**する。
- **理論根拠**：子会社の支配獲得後、非支配株主との追加取得・一部売却を「資本取引（資本剰余金）」として整合的に処理するため。
- **本試験キーワード**：`経済的単一体説` / `全面時価評価法` / `支配が継続している場合の持分変動（資本剰余金）`

### 37. のれんの規則的償却（日本基準 vs IFRS）
- **結論**：日本基準ではのれんは20年以内の効果の及ぶ期間にわたり**規則的に償却**する（IFRSの非償却・減損テストのみと対照的）。
- **理論根拠**：のれんは超過収益力の対価であり時間とともに減耗していくため、自己創設のれんとの混同を防ぎ、買収対価の費用配分を行うべきだから。
- **本試験キーワード**：`超過収益力` / `自己創設のれんの計上禁止` / `規則的償却`

### 38. 持分法（一行連結）と支配獲得・喪失の違い
- **結論**：関連会社株式の投資勘定を相手企業の純資産・損益の変動に合わせて1行で修正する（合算はしない）。
- **理論根拠**：支配はしていないが「重要な影響力」を有するため、取得原価のまま放置するのではなく実質価値を連結F/Sに反映するため。
- **本試験キーワード**：`一行連結` / `重要な影響力` / `投資と資本の相殺消去を行わない`

### 39. 企業結合のパーチェス法 vs 共通支配下の取引
- **結論**：独立企業間の取得（パーチェス法）は**時価**で受け入れのれんを認識するが、親子間等の**共通支配下の取引は帳簿価額**を引き継ぐ。
- **理論根拠**：グループ内部の再編は外部との交換取引ではなく投資の継続であるため、時価評価による評価益や自己創設的のれんを認めるべきではない。
- **本試験キーワード**：`パーチェス法` / `共通支配下の取引` / `適正な帳簿価額` / `投資の清算と継続`

### 40. 包括利益と純利益の関係（リサイクリング）
- **結論**：包括利益 ＝ 当期純利益 ＋ その他の包括利益（OCI）。日本基準ではOCIを将来純利益へ組み替える**リサイクリング**を必須とする。
- **理論根拠**：企業の純資産全体の増減（包括利益）を示しつつも、投資家の業績予測に不可欠な「投資のリスクから解放された純利益」の情報を守るため。
- **本試験キーワード**：`包括利益` / `その他の包括利益（OCI）` / `リサイクリング（組替調整）`

- [ ] **領域8チェック**：経済的単一体説による追加取得の処理、日本基準でのれんを償却する理由、事業分離の「投資の清算 vs 継続」を説明できる。

## 領域9：原価計算基準・伝統的原価計算（41〜45）

### 41. 原価計算制度の目的（財務会計・価格・管理・予算）
- **結論**：原価計算制度は、①財務諸表作成、②価格計算、③原価管理、④予算編成・統制、⑤基本計画設定の**5つの目的**に資する。
- **理論根拠**：単なる「いくら掛かったか」の集計ではなく、財務会計機構と有機的に結合して企業経営の羅針盤として機能するため。
- **本試験キーワード**：`真実の原価` / `原価管理（標準との比較）` / `予算編成・予算統制`

### 42. 原価の本質（4要件）と非原価項目
- **結論**：原価とは「**経済価値の消費**」「**給付への転嫁**」「**経営目的に関連**」「**正常なもの**」の4要件を満たすものをいう。
- **理論根拠**：火災損失や異常仕損費などの「異常な事態」や経営外費用（支払利息など）を含めると、正常な製品原価や業績比較が歪むため（非原価項目）。
- **本試験キーワード**：`経済価値の消費` / `正常性` / `非原価項目` / `異常仕損費`

### 43. 補助部門費配賦における複数基準配賦法
- **結論**：補助部門費を変動費と固定費に分け、変動費は**実際用役消費量**、固定費は**用役消費能力（最大・予定）**で配賦する。
- **理論根拠**：単一基準（実際消費量のみ）では、ある製造部門が操業度を下げただけで他部門への固定費配賦額が増えてしまう不合理を防ぐため。
- **本試験キーワード**：`複数基準配賦法` / `用役消費能力` / `他部門の操業度変動の影響遮断`

### 44. 総合原価計算の正常仕損「度外視法 vs 非度外視法」
- **結論**：度外視法は仕損費を良品の完成品と月末仕掛品に自動按分（計算簡便）し、非度外視法は仕損費を**独立計算した上で原価計算表に明示・按分**する。
- **理論根拠**：仕損費が原価管理上重要である場合や、仕損品に評価額がある場合は、非度外視法によって仕損コストを可視化する必要がある。
- **本試験キーワード**：`非度外視法` / `両者負担と完成品負担` / `正常仕損費の可視化`

### 45. 原価差異の会計処理（売上原価賦課 vs 棚卸資産按分）
- **結論**：標準原価差異等の原価差異は、原則として当期の**売上原価**に賦課するが、**多額かつ不適切な標準等に基づく場合**は棚卸資産へも按分する。
- **理論根拠**：原価差異は非能率（ムダ）による異常発生分が多く資産価値を持たないため原則費用処理だが、標準の陳腐化による差異まで資産から除くとB/Sが歪む。
- **本試験キーワード**：`売上原価への賦課（原則）` / `多額の原価差異の按分` / `非能率による異常性`

- [ ] **領域9チェック**：原価の4要件、複数基準配賦法の優位性、原価差異を原則売上原価に賦課する理由を説明できる。

## 領域10：管理会計・戦略的原価計算・意思決定（46〜50）

### 46. 直接原価計算と固定費調整（全部原価との利益差）
- **結論**：直接原価計算は固定製造間接費を期間原価とするため、生産量＞販売量（在庫増）の期は全部原価より利益が小さく、在庫減の期は大きくなる。
- **理論根拠**：外部報告（制度会計）では全部原価計算が要求されるため、期末仕掛品・製品に含まれる固定製造間接費の増減を**固定費調整**で修正する。
- **本試験キーワード**：`期間原価` / `利益と販売量の比例` / `固定費調整`

### 47. 活動基準原価計算（ABC）の必要性
- **結論**：多品種少量生産下で増大した間接費を、単一の操業度基準ではなく**活動（アクティビティ）ごとのコスト・ドライバー**で配賦する。
- **理論根拠**：従来の直接作業時間基準では、少ロット多品種製品が過小評価され大量生産製品が過大評価される「**原価の歪み（内部相互補助）**」が起きるため。
- **本試験キーワード**：`コスト・ドライバー` / `活動基準原価計算（ABC）` / `内部相互補助（クロス・サブシダイゼーション）`

### 48. 分権組織の業績評価（ROI vs 残余利益RI・EVA）
- **結論**：ROI（投資利益率）は全社最適より高い率の投資案件を事業部長が却下する**部分最適化**の罠があるが、RI（残余利益）は資本コストを上回る投資をすべて採用させる。
- **理論根拠**：金額ベースのRI（＝営業利益 − 投下資本 × 資本コスト率）およびEVAを用いることで、事業部の目標と全社価値最大化（目標整合性）を一致させるため。
- **本試験キーワード**：`目標整合性` / `部分最適化の回避` / `残余利益（RI）` / `経済的付加価値（EVA）`

### 49. 業務的意思決定における差額原価収益・埋没原価・機会原価
- **結論**：意思決定では代替案間で異なる**差額原価収益**のみを考慮し、過去支出済みの**埋没原価は無視**し、断念した最善案の利益（**機会原価**）をコストに含める。
- **理論根拠**：既に変えられない過去の減価償却費や取得原価に引きずられると、経済合理的な将来選択を誤るため。
- **本試験キーワード**：`関連原価` / `埋没原価（サンク・コスト）` / `機会原価`

### 50. 設備投資評価におけるNPV（正味現在価値）とIRR（内部利益率）の優劣
- **結論**：相互排他的投資案の選択においてNPVとIRRの結論が矛盾する場合、**NPV法**を優先する。
- **理論根拠**：IRR法は投資規模の違いを無視し、かつ途中キャッシュ・フローを「IRR自体で再投資できる」と非現実的に仮定するのに対し、NPV法は**資本コスト（WACC）で再投資**する前提で企業価値の絶対増加額を示すため。
- **本試験キーワード**：`正味現在価値（NPV）` / `内部利益率（IRR）` / `再投資率の仮定` / `加重平均資本コスト（WACC）`

- [ ] **領域10チェック**：直接原価の固定費調整、ABCの内部相互補助、ROIの罠とRIの優位性、NPVがIRRに理論的に優る理由を説明できる。
