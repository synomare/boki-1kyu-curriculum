## 1. 実況中継①：連結精算表（支配獲得2年目・税効果・アップストリーム）

### 【問題資料】
- **X1年3月31日（支配獲得日）**：P社はS社株式の80%を 2,800,000円で取得。S社純資産は資本金 2,000,000円、利益剰余金 1,000,000円。S社土地に時価評価差額（評価益）200,000円があり（法定実効税率30%）、のれんは10年で定額償却する。
- **X2年3月31日（当期末）**：S社の当期純利益は 500,000円、当期中の配当金は 100,000円。
- **アップストリーム取引**：S社からP社へ販売した商品のうち、P社期末在庫に未実現利益 50,000円が含まれている（税効果30%を適用）。
- **要求**：連結修正仕訳を示し、**①のれん期末残高、②非支配株主に帰属する当期純利益、③非支配株主持分期末残高**を求めよ。

### 【実況中継：型07＋型09で3ステップ攻略】
1. **Step 1（支配獲得日の確定）**：
   - S社土地の評価差額（税引後）：`200,000 × (1 - 30%) = 140,000円`（繰延税金負債 `60,000円`）。
   - S社時価純資産：`3,000,000 + 140,000 = 3,140,000円`。
   - のれん：`2,800,000 - (3,140,000 × 80%) = 2,800,000 - 2,512,000 = 288,000円`（年償却額 `28,800円`）。
   - 期首非支配株主持分：`3,140,000 × 20% = 628,000円`。
2. **Step 2（当期S社利益・配当・のれん償却）**：
   - 非支配株主への利益按分：`500,000 × 20% = 100,000円`、配当振替：`100,000 × 20% = 20,000円`。
3. **Step 3（アップストリーム未実現利益＋税効果＋非支配負担）**：
   - 必ず**「①未実現消去 → ②税効果(DTA) → ③税引後額を非支配按分」**の順！
   - 税引後未実現利益：`50,000 - 15,000 = 35,000円` → 非支配負担：`35,000 × 20% = 7,000円`。

## 2. 実況中継②：連結キャッシュ・フロー計算書（営業CF小計）

### 【問題資料】
連結P/L・B/Sの当期増減は以下のとおりである。**営業活動によるキャッシュ・フローの「小計」**を求めよ（間接法）。
- 税金等調整前当期純利益：2,000,000円
- 減価償却費：400,000円、のれん償却額：28,800円
- 受取利息（営業外収益）：20,000円、支払利息（営業外費用）：35,000円
- 売上債権の増加額：150,000円、棚卸資産の減少額：80,000円、仕入債務の増加額：90,000円

### 【実況中継：非資金と運転資本の符号ルール】
- 非資金費用（減価償却・のれん償却）はキャッシュが減っていないので**プラス戻し**。
- 営業外損益（受取利息・支払利息）は小計欄より下で支払/受取額を直接記載するため、小計上は**逆符号で除外**（受取利息 `-20,000`、支払利息 `+35,000`）。
- 運転資本は「**資産増はキャッシュ減（マイナス）、負債増はキャッシュ増（プラス）**」。
- **営業CF小計** ＝ `2,000,000 + 400,000 + 28,800 - 20,000 + 35,000 - 150,000 + 80,000 + 90,000 = 2,463,800円`

## 3. 実況中継③：非累加法による工程別総合原価計算

### 【問題資料】
第1工程・第2工程の2工程で製品を製造している（月初仕掛品はいずれもゼロ）。原料は第1工程の始点で全量投入。**非累加法**により、**①完成品総合原価、②第2工程月末仕掛品原価、③第1工程月末仕掛品原価**を求めよ。
- **第1工程**：当月投入 500個 → 第1完了（第2投入）420個、第1月末仕掛品 80個（加工進捗度50%）。当月材料費 1,000,000円、第1加工費 690,000円。
- **第2工程**：投入 420個 → 完成 360個、第2月末仕掛品 60個（加工進捗度1/3＝換算20個）。第2加工費 760,000円。

### 【実況中継：非累加法の鉄則「最終製品ベースで換算量を数える」】
1. **第1工程材料費の配分**：第2工程にある仕掛品60個も第1工程の材料は100%完了済み。
   - 総換算量：`完成 360 + 第2月末 60 + 第1月末 80 = 500個` → 単価 `1,000,000 ÷ 500 = 2,000円/個`
2. **第1工程加工費の配分**：第2工程にある仕掛品60個も第1工程の加工は100%完了済み。
   - 総換算量：`完成 360 + 第2月末 60 + 第1月末 (80×50%=40) = 460個` → 単価 `690,000 ÷ 460 = 1,500円/個`
3. **第2工程加工費の配分**：
   - 総換算量：`完成 360 + 第2月末 20 = 380個` → 単価 `760,000 ÷ 380 = 2,000円/個`
4. **投入＝産出の完全均衡**：
   - **①完成品原価**：`360 × (2,000 + 1,500 + 2,000) = 1,980,000円`
   - **②第2月末仕掛品**：`60×2,000 + 60×1,500 + 20×2,000 = 250,000円`
   - **③第1月末仕掛品**：`80×2,000 + 40×1,500 = 220,000円`
   - 検算：`1,980,000 + 250,000 + 220,000 = 2,450,000円`（投入合計 `1,000,000 + 690,000 + 760,000` と一致！）

## 4. 実況中継④：取替設備投資の経済性計算（NPV・型10）

### 【問題資料】
耐用年数残り3年の旧設備を、新設備に取り替えるべきか（実効税率30%、WACC＝10%、3年年金現価係数 `2.487`）。
- **新設備**：取得原価 1,500,000円（3年定額法・残存ゼロ）。導入により現金支出費用が毎年 600,000円節約される。
- **旧設備**：現在帳簿価額 300,000円（残存3年・年償却 100,000円・残存ゼロ）、即時売却価額 150,000円。

### 【実況中継：型10「差額CF表」でタックスシールドを制す】
1. **`t=0`（初期差額CF）**：旧設備の簿価300,000円は埋没原価だが、**売却損150,000円による節税額 `45,000円` は関連CF！**
   - `t=0 CF = -1,500,000 + 150,000 + (300,000 - 150,000) × 30% = -1,305,000円`
2. **`t=1, 2, 3`（毎年の税引後増分CF）**：
   - 増分償却費：`500,000 - 100,000 = 400,000円/年`
   - 毎年CF：`600,000 × (1 - 30%) + 400,000 × 30% = 420,000 + 120,000 = +540,000円/年`
3. **NPV算定**：
   - `540,000 × 2.487 - 1,305,000 = 1,342,980 - 1,305,000 = +37,980円`（プラスのため**取替案を採用すべき**）
