## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

商業簿記は「仕入れた商品をそのまま売る」ビジネスであるため、商品1個あたりの原価は仕入値を見れば一目で分かります。しかし、製造業は「鉄板や部品（材料）を買い、工場の作業員（労務）が加工し、機械や電気（経費）を使って新しい製品を生み出す」ビジネスです。もし製造業で材料を買った瞬間や給料を払った瞬間に全額を当期の費用にしてしまうと、**まだ倉庫に眠っている製品や仕掛品の原価まで当期の費用になってしまい、利益が大幅に歪みます**。

この歪みを防ぐために、工業簿記では**「工場内で発生したコストをいったん『仕掛品』『製品』という資産（ストック）に蓄積し、製品が顧客に引き渡されて売上（収益）が立った瞬間に初めて『売上原価（費用）』へ解放する」**という追跡システム（原価計算）を構築します。

- **資産の本質（ストック）**：材料・仕掛品・製品はすべて「将来のキャッシュ獲得に貢献する経済的資源」であり、製造原価はB/Sの棚卸資産に集計される（原価の資産化）。
- **費用収益対応の原則**：売上高に対応する分だけがP/Lの「売上原価」となり、未販売分はB/Sに残る。
- **原価と非原価の峻別**：工場の正常な製造活動に要した価値消費のみが「原価」であり、異常な災害損失や財務費用（支払利息）・本社営業費は製造原価に含めない。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 原価の分類と経済的実態の対応

製造原価は、**①形態別分類**（何に消費したか：材料費・労務費・経費）と、**②製品との関連における分類**（どの製品にどれだけ掛かったか直接跡づけできるか：直接費 vs 間接費）の2軸で整理します。

| 原価の分類 | 経済的実態 | 勘定連絡の行き先 |
|---|---|---|
| 直接材料費・直接労務費・直接経費 | 特定製品に跡づけ可能な価値消費 | 直接 **仕掛品（資産）** へ賦課 |
| 間接材料費・間接労務費・間接経費 | 複数製品に共通する工場コスト | いったん **製造間接費** に集計し、基準で **仕掛品** へ配賦 |
| 販売費及び一般管理費 | 営業活動・本社管理のコスト | 資産化せず、発生期の **P/L費用（期間原価）** |
| 非原価項目 | 異常損失・財務費用・利益処分項目 | 製造原価から除外し、営業外・特別損益等へ処理 |

### 基本仕訳パターン（例題ベースの勘定連絡）

**【例題】** 当月の原価データは以下のとおりである。材料（月初40,000円、当月仕入200,000円、月末60,000円）のうち直接材料費は150,000円、間接材料費は30,000円。労務費発生220,000円（直接160,000円、間接60,000円）。経費発生110,000円（直接20,000円、間接90,000円）。仕掛品は月初50,000円・月末70,000円、製品は月初80,000円・月末60,000円。売上高800,000円、販管費150,000円とする。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 材料購入 | 材料 | 200,000 | 買掛金 | 200,000 |
| ② 材料消費 | 仕掛品 | 150,000 | 材料 | 180,000 |
|  | 製造間接費 | 30,000 |  |  |
| ③ 労務・経費消費 | 仕掛品 | 180,000 | 賃金・給料 | 220,000 |
|  | 製造間接費 | 150,000 | 経費 | 110,000 |
| ④ 間接費配賦 | 仕掛品 | 180,000 | 製造間接費 | 180,000 |
| ⑤ 完成振替 | 製品 | 490,000 | 仕掛品 | 490,000 |
| ⑥ 販売・原価振替 | 売上原価 | 510,000 | 製品 | 510,000 |

- **論理導出**：①〜④で原価3要素が「直接費＝仕掛品へ直行」「間接費＝製造間接費を経由して仕掛品へ配賦」という資産内部の価値移動を行う。⑤は未完成資産（仕掛品）から完成資産（製品）への振替、⑥で初めて資産（製品）が費用（売上原価）へ転化する。

### 【1級貫通・標準下書きフォーマット】型03：T勘定連結図（価値フロー追跡）

工業簿記の問題を見たら、計算を始める前に必ず以下の**T勘定の連結パイプライン**を横に並べて描き、数字を流し込みます。

```text
  [ 材料 (資産) ]        [ 仕掛品 (資産) ]        [ 製品 (資産) ]
  -------+-------        --------+--------        -------+-------
  初 40k | 直150k ====>  初  50k | 完成490k ===>  初 80k | 売510k
  仕200k | 間 30k -.     直材150k|                完490k | (原価)
         | 末 60k  |     直労160k| 末  70k               | 末 60k
                   |     直経 20k|
  [ 製造間接費 ]   |     間接180k|
  -------+-------  |             |    <検算>
  間材30k| 配賦  <-'             |    C/R: 総製造510k + 初50k - 末70k = 490k
  間労60k| 180k  ===============>'    P/L: 売上800k - 売原510k - 販150k = 140k
  間経90k|
```

**手順**：
1. 左から「材料」「製造間接費」「仕掛品」「製品」「売上原価」の5つのT勘定を並べる。
2. 矢印に沿って「直接費→仕掛品」「間接費→製造間接費→仕掛品」へ流し込む。
3. 仕掛品T勘定の貸借差額で**当期製品製造原価**（490,000円）を確定し、製品T勘定へ引き渡す。
4. 製品T勘定の貸借差額で**売上原価**（510,000円）を確定する。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
- **原価の3要素（材料・労務・経費）× 直接費・間接費の2軸分類**を迷わず仕分けられること。
- **T勘定連結図（型03）**を用いて、期首仕掛品・当期総製造費用・期末仕掛品・当期製品製造原価・売上原価の関係を自在に逆算できること。
- **製造原価報告書（C/R）**と**損益計算書（P/L）**の接続構造を暗記ではなく価値フローとして理解すること。

### 【未来の拡張フック（1級への伏線）】
- **原価計算基準の5つの目的（`L1I-01`）**：財務諸表作成目的だけでなく、価格計算・原価管理・予算管理・基本計画（意思決定）という5つの目的に応じて「同じモノでも原価の定義が変わる（機会原価・差額原価など）」ことへ拡張される。
- **直接原価計算と固定費調整（`L2I-08` / `L1I-05`）**：外部報告（全部原価計算）では固定製造原価も製品原価として資産化するが、内部管理では変動費のみを製品原価とする。
- **非原価項目の厳格判定**：1級理論問題では「正常仕損・棚卸減耗は原価だが、異常な減損・災害損失・遊休設備の減価償却費の一部は非原価」という基準の定義が問われる。

## 4. 試験官の罠・混同しやすい論点の対比表

| 比較項目 | 製品原価（製造原価） | 期間原価（販管費） | 非原価項目 |
|---|---|---|---|
| **発生場所・性質** | 工場での正常な製造活動 | 本社・営業部門の販売・一般管理活動 | 経営目的に関連しない価値減少・財務費用・異常損失 |
| **具体例** | 工場機械の減価償却費、工場電力料、作業員賞与 | 営業社員の給料、広告宣伝費、本社ビルの減価償却費 | 支払利息、工場の火災損失、固定資産売却損、法人税等 |
| **決算書での扱い** | まず資産（仕掛品→製品）になり、販売時に売上原価へ | 資産化せず、発生した期に全額P/L費用計上 | C/Rには一切記載せず、P/Lの営業外・特別損益等へ |

> **出題者の意図**：受験生が「減価償却費」「給料」「保険料」といった**形態別の勘定科目名だけを見て機械的に製造原価や販管費へ放り込むミス**を狙う。特に「工場の〇〇」か「本社の〇〇」か、「正常」か「異常」かの修飾語を読み落とすと、B/S棚卸資産とP/L売上総利益の両方が連鎖的に崩れる。

### 問3 解答・解説

**1. 逆算プロセス（下流から上流へ遡る）**
- 売上総利益 ＝ 1,200,000 × 35% ＝ 420,000円
- 売上原価 ＝ 1,200,000 － 420,000 ＝ 780,000円
- **営業利益** ＝ 売上総利益420,000 － 販管費200,000 ＝ **220,000円**
- 当月製品製造原価 ＝ 売上原価780,000 ＋ 月末製品110,000 － 月初製品90,000 ＝ 800,000円
- 当月総製造費用 ＝ 当月製品製造原価800,000 ＋ 月末仕掛品50,000 － 月初仕掛品70,000 ＝ 780,000円
- 当月材料消費額 ＝ 総製造費用780,000 － 労務費260,000 － 経費190,000 ＝ 330,000円
- **当月材料仕入高** ＝ 材料消費額330,000 ＋ 月末材料60,000 － 月初材料40,000 ＝ **350,000円**

**2. 原価分類誤謬が営業利益に与える影響**
- **正しい処理（製造原価）**：100,000円のうち75%（75,000円）が当期の売上原価（費用）となり、残り25%（**25,000円**）は期末仕掛品・期末製品（資産）として翌期へ繰り越される。
- **誤った処理（販管費）**：発生した100,000円の全額（100%）が当期の販管費（費用）としてP/Lに計上されてしまう。
- **結論**：当期の費用が `100,000 － 75,000 ＝ 25,000円` だけ過大計上されるため、当期の営業利益は **25,000円過小** に表示される（同時にB/Sの棚卸資産も25,000円過小となる）。

> **誤答パターン分析**：原価を販管費に誤分類しても「どうせ同じ営業利益のマイナス項目だから影響は0円」と短絡的に答えるミス。製品原価には「期末在庫として資産化され、翌期へ費用が繰り延べられる効果」があることを見抜くのが本問の核心である。
