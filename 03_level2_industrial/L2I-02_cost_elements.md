## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

製品原価を正確に算定するには、まず「材料・労務・経費をいくら消費したか（消費価格 × 消費数量）」を測定する必要があります。しかし、実際の現場では「月末に水道光熱費や材料の最終仕入請求書が届くまで実際単価が確定しない」ことが日常茶飯事です。もし実際単価の確定を待っていたら、月中に完成・販売した製品の原価が計算できず、経営判断や決算が止まってしまいます。

そこで実務では、**「あらかじめ決めた『予定単価（予定賃率）』を使って月中の原価計算をスピーディーに回し、月末に実際額が判明した瞬間にそのズレを『原価差異』として切り出す」**という合理的な仕組みを採用します。

- **材料費の本質**：購入原価（購入代価＋外部・内部付随費用）で資産計上し、出庫（消費）時に初めて「仕掛品」「製造間接費」へ振り替える。棚卸減耗は正常分のみ製造間接費へ、異常分は営業外・特別損失へ処理する。
- **労務費の本質**：現金支給額ではなく「当月の労働消費に対する要支払額（当月支給額＋当月末未払－前月末未払）」が実際発生額となる（発生主義）。
- **差異の本質**：予定消費額（予定単価×実際消費量）と実際消費額の差額は、単価の変動による**純粋な価格・賃率差異**であり、製品原価の計算速度と価格責任の明確化を両立させる。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 費目別計算の3大メカニズムと標準仕訳

| 取引区分 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 材料仕入（付随費込） | 材料 | 208,000 | 買掛金 | 208,000 |
| ② 材料予定消費（直接・間接・減耗） | 仕掛品 | 175,000 | 材料 | 202,500 |
|  | 製造間接費 | 27,500 |  |  |
| ③ 材料消費価格差異（不利） | 材料消費価格差異 | 6,100 | 材料 | 6,100 |
| ④ 労務費支払（要支払発生前） | 賃金・給料 | 420,000 | 現金預金 | 420,000 |
| ⑤ 労務費予定消費 | 仕掛品 | 360,000 | 賃金・給料 | 420,000 |
|  | 製造間接費 | 60,000 |  |  |
| ⑥ 賃率差異（不利） | 賃率差異 | 20,000 | 賃金・給料 | 20,000 |

**【例題】** 上表の仕訳の根拠は以下の通り。
- **材料（先入先出法・予定消費価格@500円/kg）**：月初100kg（@500円＝50,000円）、当月仕入400kg（@520円＝208,000円）。消費は直接350kg（予定175,000円）、間接50kg（予定25,000円）、月末実地棚卸95kgより正常棚卸減耗5kg（予定2,500円→製造間接費へ合算27,500円）。予定消費計405kg×@500＝202,500円。一方、先入先出法による実際消費額は `100kg×500 + 305kg×520 = 50,000 + 158,600 = 208,600円`。よって `予定202,500 － 実際208,600 ＝ -6,100円`（借方差異＝不利差異）。月末材料残高は `95kg × @520 ＝ 49,400円`。
- **労務費（予定賃率@2,000円/時間）**：前月末未払賃金80,000円、当月支給額420,000円、当月末未払賃金100,000円。当月実際発生額＝`420,000 ＋ 100,000 － 80,000 ＝ 440,000円`。直接作業180時間（予定360,000円）、間接作業20時間＋手待時間10時間＝30時間（予定60,000円）。予定消費計420,000円 － 実際440,000円 ＝ **-20,000円（不利差異）**。

### 【1級貫通・標準下書きフォーマット】型02・型03（ボックス＋要支払T勘定）

```text
  [ 材料ボックス (先入先出) ]              [ 賃金・給料 T勘定 (発生主義) ]
  ---------------+---------------          ---------------+---------------
  月初 100kg     | 直接 350kg (予175k)     当月支給  420k | 前月未払   80k
       (@500)50k | 間接  50kg (予 25k)     当月未払  100k | 予定直    360k
  仕入 400kg     | 減耗   5kg (予2.5k)                    | 予定間     60k
       (@520)208k| [実際計405kg=208.6k]    (実際発生計440k| (予定消費計420k)
                 | 価格差異(不利) 6.1k     ---------------+---------------
                 | 月末 95kg (@520)49.4k                  | 賃率差異   20k
  ---------------+---------------
  借方計 258,000 | 貸方計 258,000          ※ 差異 = 予定(基準) - 実際
```

**手順**：
1. 材料は必ず**数量×単価のボックス図**を描き、「月初＋仕入＝消費(直接＋間接)＋減耗＋月末実地」の数量バランスを先に確定する。
2. 労務費は**賃金・給料T勘定**を描き、借方に「当月支給＋当月末未払」、貸方に「前月末未払＋予定消費額」を置き、借方合計－貸方予定合計で差異を機械的に求める（負なら借方＝不利、正なら貸方＝有利）。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
- 材料の購入原価算入（引取運賃等の外部付随費用・材料副費）、移動平均法／先入先出法、および予定消費価格差異の算定。
- 労務費の「当月要支払額（未払の加減・預り金の処理）」と「直接労務費（直接工直接作業のみ）vs 間接労務費（間接作業・手待・間接工給料）」の区分。
- 経費の4分類（支払経費・月割経費・測定経費・発生経費）と、外注加工賃・特許権使用料などの直接経費の識別。

### 【未来の拡張フック（1級への伏線）】
- **受入価格差異法 vs 消費価格差異法（問3で先取り）**：材料購入時点で予定単価を適用して差異を切り出す「受入価格差異法」は、まだ使っていない期末在庫分の価格差異まで当期に認識してしまう点に注意が必要。
- **原価差異の会計処理（`L1I-04`）**：2級では原価差異は原則すべて売上原価に賦課するが、1級では多額な場合などに「売上原価と期末棚卸資産（仕掛品・製品）へ按分する」処理を行う。
- **標準原価計算への直結（`L2I-07`）**：ここでの「予定単価差異・予定賃率差異」は、100%そのまま標準原価計算の「材料価格差異」「賃率差異」の計算構造（`(標準単価 - 実際単価) × 実際数量`）へ進化する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 正しい扱い（本質） | 試験官が仕掛ける典型的な罠 |
|---|---|---|
| **直接工の手待時間・間接作業時間** | 特定製品を作っていないため **間接労務費（製造間接費）** | 「直接工だから」と全額を直接労務費（仕掛品）に入れてしまう罠 |
| **給与から控除した所得税等預り金** | 総支給額（手取＋預り金）が実際支払額のベース | 銀行振込額（手取額）だけで実際賃金を計算してしまう罠 |
| **棚卸減耗費（正常分）** | 予定単価で計算し **製造間接費** へ | 実際単価で計算したり、商業簿記のように販管費へ入れる罠 |
| **引取運賃・買入手数料（材料副費）** | 材料の取得原価に加算（仕入単価が上がる） | 経費（間接経費）として別処理してしまう罠 |

> **出題者の意図**：特に労務費の「手待時間」「健康保険料・源泉所得税の預り金」「前月未払の戻入方向」を複合させることで、発生主義と消費額計算を表面的にしか覚えていない受験生をふるいにかける。

### 問3 解答・解説

1. **受入価格差異法**
   - 仕入1,000kgを受入時に予定@500円で記帳 → 材料勘定借方 500,000円、材料受入価格差異（不利） **50,000円**。
   - 消費700kg × @500 ＝ 350,000円（基本売上原価）。差異全額を売上原価に賦課するため、**売上原価 ＝ 350,000 ＋ 50,000 ＝ 400,000円**、**期末材料 ＝ 300kg × @500 ＝ 150,000円**。
2. **消費価格差異法**
   - 仕入1,000kgを実際@550円で記帳（550,000円）。
   - 消費700kgの予定350,000円 vs 実際385,000円 → 材料消費価格差異（不利） **35,000円**。
   - **売上原価 ＝ 350,000 ＋ 35,000 ＝ 385,000円**、**期末材料 ＝ 300kg × @550 ＝ 165,000円**。
3. **差額と理由**
   - 受入価格差異法の方が消費価格差異法より売上原価が **15,000円多く**、当期売上総利益は **15,000円小さく** なる。
   - 理由：まだ消費されておらず倉庫に残っている期末材料300kgに対応する価格高騰分（`300kg × (@550 - @500) = 15,000円`）までもが受入時に差異として切り出され、当期の売上原価へ先取り費用化されているからである（検算：両法とも `売上原価 ＋ 期末材料 ＝ 550,000円` で一致）。

> **誤答パターン分析**：差異全額を売上原価へ賦課する条件を見落とし、両方法とも「売れた700kg分の原価は同じはず」と誤解する。差異を期末在庫と売上原価に按分しない限り、受入時認識と消費時認識で利益が変わる。

## 7. 復習チェックリスト（定着確認）

- [ ] 材料の購入原価に「外部引取運賃」を含める理由と、予定消費単価を使う実務上の理由を説明できる。
- [ ] 直接工の賃金のうち「直接労務費」になる範囲と「間接労務費（手待・間接作業）」になる範囲を明確に区別できる。
- [ ] 当月支給額と前後月末の未払賃金から、なぜ「当月支給＋当月末未払－前月末未払」で当月実際発生額が出るのか発生主義で説明できる。
- [ ] 予定単価差異（有利・不利）の符号判定を「予定（標準）－ 実際」で即答でき、仕訳の借方・貸方を迷わず決定できる。
