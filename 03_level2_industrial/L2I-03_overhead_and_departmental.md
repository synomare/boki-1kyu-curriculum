## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

製造間接費（工場の電気代、機械の減価償却費、工場長の給料など）は、どの製品にいくら掛かったか直接跡づけできません。しかし、これを適当に製品へ割り振ると、**「実は赤字の製品の原価が安く見えたり、工場が暇で稼働率が落ちた損失を特定の製品原価に押し付けたりする」**という経営上の致命的な歪みが起きます。

さらに、製造間接費には**「稼働時間に比例して増減する変動費（電力料・補助材料）」**と**「稼働時間に関わらず毎月一定額が発生する固定費（機械の減価償却費・工場家賃）」**が混在しています。もし1本の直線だけで予算を組む（固定予算）と、操業度が落ちたときに変動費が減った分まで「予算を節約した優秀な成果」と誤認してしまいます。これを防ぐため、**変動費と固定費を分離する「公式法変動予算（シュラッター図）」**と、サービス部門から製造部門へ合理的にコストを流す**「部門別計算」**が不可欠となります。

- **予定配賦の意義**：年間または月間の基準操業度に基づく予定配賦率を使い、期中の製品原価計算の迅速化と「操業度変化による単位原価の乱高下（遊休キャパシティの製品原価への混入）」を防ぐ。
- **予算差異の本質**：実際操業度の下で許された予算額（変動予算許容額）と実際発生額の差額であり、**現場のコスト管理（無駄遣い・節約）の責任**を表す。
- **操業度差異の本質**：固定費のキャパシティ（基準操業度）をどれだけ有効活用できたかを表す、**稼働率の過不足（遊休損失または超過稼働利益）**である。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 公式法変動予算と差異分解の標準仕訳

**【例題】** 基準操業度 1,000時間、月間固定費予算 600,000円（固定費率@600円/h）、変動費率 @400円/h（予定配賦率計 @1,000円/h）。当月の実際操業度は900時間、製造間接費実際発生額は990,000円であった。

- 予定配賦額 ＝ `@1,000円 × 900h ＝ 900,000円`
- 予算許容額 ＝ `固定費600,000 ＋ (@400 × 900h) ＝ 960,000円`
- 予算差異 ＝ `予算許容960,000 － 実際990,000 ＝ -30,000円`（借方＝不利差異）
- 操業度差異 ＝ `予定配賦900,000 － 予算許容960,000 ＝ -60,000円`（または `固定費率600 × (実際900h - 基準1,000h) ＝ -60,000円`、不利差異）

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 予定配賦 | 仕掛品 | 900,000 | 製造間接費 | 900,000 |
| ② 実際発生（諸口） | 製造間接費 | 990,000 | 諸口（材料・賃金等） | 990,000 |
| ③ 配賦差異の把握 | 製造間接費配賦差異 | 90,000 | 製造間接費 | 90,000 |
| ④ 差異分析・分解 | 予算差異 | 30,000 | 製造間接費配賦差異 | 90,000 |
|  | 操業度差異 | 60,000 |  |  |

### 【1級貫通・標準下書きフォーマット】型05：シュラッター図

製造間接費の差異分析は、公式の丸暗記ではなく、必ず次の**シュラッター図（型05）**を40秒で描いて「上から下を引く」のではなく**「下の線（許容額・配賦額）から上の点（実際・許容額）を引く」**で符号を確定させます。

```text
  発生額
    ^
    |                        * 実際発生額 (990,000)
    |                       /|
    |            +---------*-| <-- 予算許容額 (960,000 = 600k + 400×900)
    |           /|  -30k   | |     [予算差異 = 960k - 990k = -30,000(不利)]
    |          / | (不利)  | |
    |---------*--+---------*-| <-- 固定費ライン (600,000)
    |  固定費 |  |  -60k   | |     [操業度差異 = 900k - 960k = -60,000(不利)]
    |  (600k) |  | (不利)  * | <-- 予定配賦額 (900,000 = 1,000×900)
    +---------+--+---------+-----> 操業度(時間)
              0  900h     1,000h
                (実際)    (基準)
```

**手順**：
1. 縦に「基準操業度（1,000h）」と「実際操業度（900h）」の2本の柱を立てる（実際 < 基準なら実際が左側）。
2. 固定費ライン（600k）、変動予算斜線（傾き@400）、予定配賦斜線（傾き@1,000）の3本を引き、実際操業度の柱との交点に「予算許容額」「予定配賦額」を書き込む。
3. 実際発生額（990k）の点をプロットし、**必ず「予定配賦点 → 予算許容点 → 実際点」の順に比較**する（下がプラス・上がマイナス＝不利）。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
- **公式法変動予算（シュラッター図・型05）**による予算差異・操業度差異の正確な分解（基準超過で操業度差異が**有利**になるケースも含む）。
- **部門別計算の第1次集計（部門個別費・部門共通費）と第2次集計（直接配賦法・簡便法としての相互配賦法）**の完全計算。
- 複数製造部門ごとの部門別予定配賦率の設定と配賦計算。

### 【未来の拡張フック（1級への伏線）】
- **複数基準配賦法（`L1I-01`）**：補助部門費を「変動費（実際消費量基準）」と「固定費（最大消費能力＝設備能力基準）」に分けて配賦する1級の王道論点。固定費を使わない部門に固定費を押し付けないための進化形である。
- **連立方程式法による完全相互配賦法（`L1I-01`）**：2級は「第1次で相互配賦し、第2次は直接配賦で打ち切る簡便法」だが、1級では連立方程式を解いて補助部門間の無限ループを完全に清算する。
- **標準原価計算における3分法・4分法（`L2I-07` / `L1I-04`）**：シュラッター図に「標準操業度（S）」の柱を1本追加するだけで、そのまま能率差異が切り出せる（型05の完全拡張）。

## 4. 試験官の罠・混同しやすい論点の対比表

| 比較項目 | 直接配賦法 | 相互配賦法（2級：簡便法） | 相互配賦法（1級：連立方程式法） |
|---|---|---|---|
| **補助部門間の用役授受** | 完全に無視する | 第1次配賦のみ考慮し、第2次配賦は直接配賦法で打ち切る | 補助部門間の用役授受を100%厳密に連立方程式で解く |
| **計算上の注意（罠）** | 製造部門の割合の合計を100%に直し直す（分母を製造部門計にする） | 第1次は補助部門を含めた全割合（計100%）で配賦し、第2次は製造部門だけの比で割り切る | 配賦前の自己消費を除く場合と含む場合の処理区別 |

> **出題者の意図**：直接配賦法で「動力部門から修繕部門への20%を無視する際、切削40%・組立40%をそのまま使ってしまい配賦額の合計が80%で止まって20%消えるミス」や、相互配賦法の第2次配賦で「また補助部門へ配賦して無限ループに陥るミス」を誘う。配賦前後で**部門費総額が1円も増減しないこと**を必ず検算せよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

**【下書き再現：型05 シュラッター図（実際2,100h ＞ 基準2,000h）】**
```text
  発生額
    ^                            * 予定配賦額 (2,310,000)
    |                           /|
    |            +-------------*-| <-- 予算許容額 (2,250,000)
    |           /|      +60k   | |     [操業度差異 = 2,310k - 2,250k = +60k(有利)]
    |          / |     (有利)  * | <-- 実際発生額 (2,220,000)
    |---------*--+-------------+-|     [予算差異 = 2,250k - 2,220k = +30k(有利)]
    |  固定費 |  |             | |
    | (1,200k)|  |             | |
    +---------+--+-------------+----> 操業度
              0 2,000h       2,100h
                (基準)       (実際)
```

**1. 各金額**
- 固定費率 ＝ `1,200,000 ÷ 2,000h ＝ @600円/h` → **予定配賦率** ＝ `600 ＋ 500` ＝ **@1,100円/h**
- **予定配賦額** ＝ `@1,100 × 2,100h` ＝ **2,310,000円**
- **予算許容額** ＝ `1,200,000 ＋ (@500 × 2,100h)` ＝ **2,250,000円**
- **予算差異** ＝ `2,250,000 － 2,220,000` ＝ **30,000円（有利差異／貸方差異）**
- **操業度差異** ＝ `2,310,000 － 2,250,000` ＝ **60,000円（有利差異／貸方差異）**
  （検算：`@600 × (2,100h - 2,000h) = +60,000円`）

**2. 仕訳**
| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 予定配賦 | 仕掛品 | 2,310,000 | 製造間接費 | 2,310,000 |
| ② 実際発生 | 製造間接費 | 2,220,000 | 諸口 | 2,220,000 |
| ③ 総差異把握 | 製造間接費 | 90,000 | 製造間接費配賦差異 | 90,000 |
| ④ 差異分解 | 製造間接費配賦差異 | 90,000 | 予算差異 | 30,000 |
|  |  |  | 操業度差異 | 60,000 |

> **誤答パターン分析**：実際操業度が基準を超えた場合に、操業度差異を有利（貸方）ではなく不利（借方）と逆にしてしまうミス。基準より多く稼働して固定費を有効活用したのだから「有利」である。

### 問2 解答・解説

**1. 直接配賦法**
- 動力費200,000円 → 切削40% : 組立40% ＝ **1 : 1** で配賦（切削100,000円、組立100,000円）。
- 修繕費160,000円 → 切削50% : 組立30% ＝ **5 : 3** で配賦（切削100,000円、組立60,000円）。
- **切削部門費** ＝ `500,000 ＋ 100,000 ＋ 100,000` ＝ **700,000円**
- **組立部門費** ＝ `400,000 ＋ 100,000 ＋ 60,000` ＝ **560,000円**
- （検算：`700,000 ＋ 560,000 ＝ 1,260,000円`）

**2. 相互配賦法（簡便法）**
- **第1次配賦**（補助部門間も含めた全割合で配賦）：
  - 動力200,000円 → 切削40%(80,000)、組立40%(80,000)、修繕20%(40,000)
  - 修繕160,000円 → 切削50%(80,000)、組立30%(48,000)、動力20%(32,000)
- **第2次配賦**（他部門から受け入れた額のみを製造部門へ直接配賦）：
  - 動力受入32,000円 → 切削:組立(1:1) ＝ 切削16,000円、組立16,000円
  - 修繕受入40,000円 → 切削:組立(5:3) ＝ 切削25,000円、組立15,000円
- **合計**：
  - **切削部門費** ＝ `500,000 ＋ 80,000 ＋ 80,000 ＋ 16,000 ＋ 25,000` ＝ **701,000円**
  - **組立部門費** ＝ `400,000 ＋ 80,000 ＋ 48,000 ＋ 16,000 ＋ 15,000` ＝ **559,000円**
  - （検算：`701,000 ＋ 559,000 ＝ 1,260,000円`）

> **誤答パターン分析**：相互配賦法の第2次配賦で、元の自部門費（動力200k・修繕160k）と受入額（32k・40k）を合算して二重配賦してしまうミス。第2次で配賦するのは「他部門から受け入れた分だけ」である。

### 問3 解答・解説

**1. 逆算プロセス**
- **予定配賦率** ＝ `予定配賦額 880,000 ÷ 実際 800h` ＝ **@1,100円/h**
- 操業度差異 ＝ `固定費率 × (実際800h － 基準1,000h) ＝ -140,000` → 固定費率 ＝ `140,000 ÷ 200h` ＝ **@700円/h**
- **固定費予算額（月額）** ＝ `@700 × 基準1,000h` ＝ **700,000円**
- **変動費率** ＝ `予定配賦率1,100 － 固定費率700` ＝ **@400円/h**
- **予算許容額** ＝ `700,000 ＋ (@400 × 800h)` ＝ **1,020,000円**
- **予算差異** ＝ `予算許容1,020,000 － 実際発生960,000` ＝ **60,000円（有利差異／貸方差異）**
  （検算：`総差異 = 880,000 - 960,000 = -80,000 = 予算(+60,000) + 操業度(-140,000)` で完全一致）

**2. 固定予算の致命的欠陥**
- 基準1,000hの固定予算額 ＝ `@1,100 × 1,000h ＝ 1,100,000円`。これを用いると予算差異は `1,100,000 － 960,000 ＝ +140,000円（有利差異）` と算定される。
- **欠陥の本質**：実際操業度が200h減ったため本来なら変動費が `200h × @400 ＝ 80,000円` 減って当然なのに、固定予算ではこの「操業度低下による自然な変動費減少分80,000円」までもが現場の予算節約成果（+60,000＋80,000＝+140,000）として過大評価されてしまい、正しい原価管理ができなくなる。

> **誤答パターン分析**：固定予算の予算額を1,100,000円ではなく固定費予算700,000円と混同するミス。「固定予算」とは「操業度が変わっても基準操業度時の総予算（固定＋変動）を動かさずに比較する予算」のことである。
