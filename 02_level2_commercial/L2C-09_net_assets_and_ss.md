## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

純資産は「企業の正味財産」ですが、その中身は**「株主から預かった元手（払込資本＝資本金・資本剰余金）」**と**「事業で稼いで蓄積した利益（留保利益＝利益剰余金）」**という性質のまったく異なる2つの資金源から成ります。

もし「元手」と「稼ぎ」をごちゃ混ぜにしたらどうなるでしょうか？ たとえば株主から払い込まれた出資金を切り崩して配当しているのに、投資家から見れば「事業で儲けて配当している」ように錯覚してしまいます。また、期首から期末にかけて純資産がなぜ増減したのか（増資したのか、稼いだのか、配当で流出したのか）を一目で見せるために、B/Sの純資産の部の1年間の動きを一覧表にしたものが**株主資本等変動計算書（S/S）**です。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **増資（資本準備金の計上）**：株式を発行し、払込金 10,000,000円が普通預金に入金された。会社法の規定により、最低限度額（2分の1）を資本金とし、残額を資本準備金とした（株式発行手数料 100,000円を普通預金から支払った）。
> 2. **剰余金の配当と1/4上限**：資本金 8,000,000円、既存資本準備金 1,200,000円、既存利益準備金 700,000円の会社が、繰越利益剰余金から配当 1,500,000円（未払配当金）を決議した。会社法の規定により、準備金合計が資本金の1/4に達するまで配当の1/10を積み立てる。
> 3. **吸収合併（2級入口）**：B社（諸資産時価 4,000,000円、諸負債時価 1,500,000円）を吸収合併し、対価として時価 3,000,000円の新株を発行した（全額を資本金とする）。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①増資 | 普通預金 | 10,000,000 | 資本金 | 5,000,000 |
|  |  |  | 資本準備金 | 5,000,000 |
| ①発行費 | 株式交付費 | 100,000 | 普通預金 | 100,000 |
| ②配当 | 繰越利益剰余金 | 1,600,000 | 未払配当金 | 1,500,000 |
|  |  |  | 利益準備金 | 100,000 |
| ③合併 | 諸資産 | 4,000,000 | 諸負債 | 1,500,000 |
|  | のれん | 500,000 | 資本金 | 3,000,000 |

- **①の論理**：新株発行時の株式交付費100,000円は払込資本から差し引かず、営業外費用「株式交付費（費用＋）」として独立処理する（繰延資産処理もあるが2級原則は費用）。
- **②の論理（1/4上限ルール）**：積立上限は `資本金 8,000,000 × 1/4 = 2,000,000円`。既存の準備金合計は `1,200,000 + 700,000 = 1,900,000円` ゆえ、残枠は `100,000円`。配当の1/10（150,000円）と残枠（100,000円）のいずれか小さい方 **100,000円** を積み立てる。
- **③の論理（のれん）**：純資産時価 `4,000,000 - 1,500,000 = 2,500,000円` に対して3,000,000円を支払った差額500,000円は、相手企業のブランド力・超過収益力に対する対価「**のれん（無形固定資産）**」となる。

### 【1級貫通・標準下書きフォーマット】

型03（T勘定連結）による1/4上限判定ボックスと、S/S変動マトリクスです。

```text
  【準備金 1/4 上限判定ボックス】
  上限額: 資本金 8,000,000 × 1/4 = 2,000,000円
  既存計: 資本準備金 1,200,000 + 利益準備金 700,000 = 1,900,000円
  残枠  : 2,000,000 - 1,900,000 = 100,000円
  判定  : min(配当 1,500,000 × 1/10 = 150,000, 残枠 100,000) = 100,000円
```

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **準備金1/4上限ルール**：必ず「資本準備金＋利益準備金」の合計と「資本金の1/4」を比較して残枠を出す。
2. **S/S（株主資本等変動計算書）の読み書き**：期首残高 ± 当期変動額（増資・配当・準備金積立・当期純利益・任意積立金）＝ 期末残高の縦横検算。
3. **合併ののれんと負ののれん**：取得原価 ＞ 純資産時価なら「のれん（資産、20年以内償却）」、取得原価 ＜ 純資産時価なら「負ののれん発生益（特別利益）」。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-10`, `L1C-15`）**：自己株式の取得・処分・消却（払込資本の払戻としての性質）、新株予約権・ストック・オプション、会社法上の分配可能額、さらに企業結合・事業分離における「投資の継続と清算」へと接続する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 資本剰余金グループ | 利益剰余金グループ |
|---|---|---|
| 法定準備金 | **資本準備金** | **利益準備金** |
| その他区分 | その他資本剰余金 | 繰越利益剰余金・別途積立金等 |
| 欠損填補の原則 | その他資本剰余金等から繰越利益剰余金へ振替可 | 別途積立金等を取り崩して繰越利益剰余金へ |
| 配当財源にした時の準備金 | 資本準備金を積み立てる | 利益準備金を積み立てる |

> **出題者の意図**：1/4上限の計算において「利益準備金だけ」を見て資本準備金を合算し忘れる罠、および「その他資本剰余金」を財源として配当したのに誤って「利益準備金」を積み立てさせる罠が頻出です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社の以下の純資産および企業結合取引について仕訳を示せ。
1. 新株を発行し、払込金 4,000,000円が普通預金に入金された（会社法の最低限度額を資本金とし、残額を資本準備金とする）。
2. 資本金 4,000,000円、資本準備金 650,000円、利益準備金 320,000円の状態で、繰越利益剰余金を財源とする配当金 600,000円（未払配当金）を決議した（1/4上限に留意）。
3. 株主総会の決議により、別途積立金 300,000円を取り崩して繰越利益剰余金の欠損を填補した。
4. 乙社（諸資産時価 2,200,000円、諸負債時価 700,000円）を吸収合併し、対価として時価 1,800,000円の新株を発行した（全額を資本金とする）。

### 問2（本試験標準・ひっかけ対応）
乙社の期首純資産残高および当期中の変動は以下のとおりである。S/Sの縦横集計を行い、**期末の繰越利益剰余金残高**および**期末純資産合計**を求めよ。
- **期首残高（合計 7,000,000円）**：資本金 4,000,000円、資本準備金 1,000,000円、利益準備金 200,000円、別途積立金 1,000,000円、繰越利益剰余金 800,000円
- **当期中の変動**：
  1. 新株発行により 2,000,000円を増資（全額資本金）。
  2. 繰越利益剰余金から配当金 400,000円および利益準備金 40,000円の積立を決議。
  3. 当期純利益 950,000円を計上。

### 問3（1級視点・応用思考）
丙社（資本金 4,000,000円、資本準備金 610,000円、利益準備金 300,000円）は、株主総会で「その他資本剰余金を財源とする配当 400,000円」と「繰越利益剰余金を財源とする配当 800,000円」を**同時に**決議した。
1. 会社法に基づき積み立てるべき**資本準備金**および**利益準備金**の金額をそれぞれ計算せよ（1/4上限の残枠を配当金額の比率で按分する）。
2. 別の取引で、丁社（諸資産時価 2,500,000円、諸負債時価 700,000円）を吸収合併し、対価として時価 1,500,000円の新株（全額資本金）を発行した。この合併仕訳を示し、差額300,000円の会計上の意味を1行で述べよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1 | 普通預金 | 4,000,000 | 資本金 | 2,000,000 |
|  |  |  | 資本準備金 | 2,000,000 |
| 2 | 繰越利益剰余金 | 630,000 | 未払配当金 | 600,000 |
|  |  |  | 利益準備金 | 30,000 |
| 3 | 別途積立金 | 300,000 | 繰越利益剰余金 | 300,000 |
| 4 | 諸資産 | 2,200,000 | 諸負債 | 700,000 |
|  | のれん | 300,000 | 資本金 | 1,800,000 |

- 2の上限判定：`資本金 4,000,000 × 1/4 = 1,000,000円`、既存計 `650,000 + 320,000 = 970,000円`、残枠 `30,000円`。配当の1/10（60,000円）より小さい **30,000円** のみ積立。
- 4ののれん：`1,800,000 - (2,200,000 - 700,000) = 300,000円`。

> **誤答パターン分析**：2番で既存の「資本準備金650,000円」を合計し忘れて、利益準備金だけで1/4上限を計算してしまい60,000円を積み立ててしまうミスが定番です。

### 問2の解答と解説

```text
| 項目 | 資本金 | 資本準備金 | 利益準備金 | 別途積立金 | 繰越利益剰余金 | 純資産合計 |
|---|---:|---:|---:|---:|---:|---:|
| 期首残高 | 4,000,000 | 1,000,000 | 200,000 | 1,000,000 | 800,000 | 7,000,000 |
| 新株発行 | +2,000,000 | 0 | 0 | 0 | 0 | +2,000,000 |
| 剰余金配当 | 0 | 0 | +40,000 | 0 | -440,000 | -400,000 |
| 当期純利益 | 0 | 0 | 0 | 0 | +950,000 | +950,000 |
| 期末残高 | 6,000,000 | 1,000,000 | 240,000 | 1,000,000 | 1,310,000 | 9,550,000 |
```

- **期末繰越利益剰余金**：`800,000 - 440,000 + 950,000 = 1,310,000円`
- **期末純資産合計**：`7,000,000 + 2,000,000 - 400,000 + 950,000 = 9,550,000円`

> **誤答パターン分析**：利益準備金40,000円の積立を純資産全体の増加（社外流入）と誤認し、期末純資産合計を9,590,000円としてしまう誤答が多く見られます（内部振替なので純資産合計は動かない！）。

---

### 問3の解答と解説

1. **同時配当の準備金計算**：
   - 1/4上限：`4,000,000 × 1/4 = 1,000,000円`、既存計 `610,000 + 300,000 = 910,000円`、残枠 `90,000円`。
   - 原則積立額計：`400,000×1/10 + 800,000×1/10 = 120,000円` ＞ 残枠 `90,000円` ゆえ、残枠90,000円を配当比率（`400,000 : 800,000 = 1 : 2`）で按分する。
   - **資本準備金**：`90,000 × 1/3 = 30,000円`、**利益準備金**：`90,000 × 2/3 = 60,000円`。
2. **バーゲンパーチェス（負ののれん）の合併仕訳**：

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 2合併 | 諸資産 | 2,500,000 | 諸負債 | 700,000 |
|  |  |  | 資本金 | 1,500,000 |
|  |  |  | 負ののれん発生益 | 300,000 |

- **意味**：被取得企業の識別可能純資産時価（1,800,000円）よりも低い対価（1,500,000円）で割安取得したため、差額300,000円を即時の特別利益「負ののれん発生益」とする。

> **誤答パターン分析**：1番でその他資本剰余金の配当に対する積立金まで「利益準備金」として90,000円全額を積み立ててしまうミスが定番です。
