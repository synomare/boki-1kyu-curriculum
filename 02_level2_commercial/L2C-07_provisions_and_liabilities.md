## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

3級で学んだ「貸倒引当金」は資産のマイナス（評価性引当金）でしたが、2級では**「将来のお金の支出（負債）」を見越して計上する負債性引当金**を学びます。たとえば「12月〜5月の労働に対して6月に夏期賞与600,000円を払う」会社が、3月31日決算で1円も費用にせず6月に全額費用にしたらどうなるでしょうか？
- **労働期間のミスマッチ**：従業員は12〜3月の4ヶ月間すでに当期のために働いて売上を生んでいるのに、その人件費（400,000円）が翌期に押し付けられ、当期の利益が水増しされる。

一方で、「将来の大儲けの年に備えて何でも引当金にして利益を隠す」利益操作も防がなければなりません。そこで企業会計原則（注解18）は、引当金として計上できる厳格な**4要件**を定めています。
1. **将来の特定の費用または損失**であること
2. その発生が**当期以前の事象に起因**していること
3. 発生の**可能性が高い**こと
4. その金額を**合理的に見積もる**ことができること

---

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **賞与引当金**：決算日（3月31日）において、翌6月支給予定の賞与見込額 600,000円（対象期間：12月〜5月の6ヶ月）のうち当期帰属分（4ヶ月）を計上し、翌6月に実際額 620,000円を普通預金から支給した。
> 2. **商品保証引当金**：当期売上に対する翌期の無償修理見積額 100,000円を引当計上し、翌期に実際修理費 85,000円を現金で支払った。
> 3. **修繕引当金**：4年ごとに行う定期大規模修繕（見積 1,200,000円）に備え、毎年 300,000円ずつ積み立てていた（3年目末残高 900,000円）。4年目に実際修繕費 1,250,000円を普通預金から支払った。
> 4. **退職給付引当金（2級基礎）**：当期の退職給付費用が 350,000円と計算され、同期間に企業年金基金へ現金 200,000円を拠出した。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①決算 | 賞与引当金繰入 | 400,000 | 賞与引当金 | 400,000 |
| ①支給 | 賞与引当金 | 400,000 | 普通預金 | 620,000 |
|  | 賞与 | 220,000 |  |  |
| ②決算 | 商品保証引当金繰入 | 100,000 | 商品保証引当金 | 100,000 |
| ②修理 | 商品保証引当金 | 85,000 | 現金 | 85,000 |
| ③修繕 | 修繕引当金 | 900,000 | 普通預金 | 1,250,000 |
|  | 修繕費 | 350,000 |  |  |
| ④退職 | 退職給付費用 | 350,000 | 現金 | 200,000 |
|  |  |  | 退職給付引当金 | 150,000 |

- **①〜③の共通論理**：引当金は「前期までに費用計上済みの負債プール」。実際に支出が起きたときはまず引当金を取り崩し（借方）、引当金で足りない分（4〜5月分の賞与220,000円や超過修繕費350,000円）だけを当期の費用とする。
- **④の論理（退職給付）**：退職金は「従業員の労働に対する後払いの賃金」。当期発生コスト350,000円のうち、外部の年金基金へ積み立てた200,000円を差し引いた未積立分150,000円が会社の将来の支払義務（退職給付引当金＝固定負債）として増加する。

### 【1級貫通・標準下書きフォーマット】

型01（タイムライン型）で賞与の対象期間を区切り、型08（退職給付ワークシート型の入口）で負債残高の増減を追います。

```text
【型01：賞与引当金の期間帰属】
  ×1/12/1           ×2/3/31(決算)        ×2/5/31(6月支給)
----+------------------+--------------------+----->
    |<-- 当期 4ヶ月 -->|<--- 翌期 2ヶ月 --->|
    600,000×4/6=400,000  支給620,000 - 引当400,000 = 翌期賞与220,000
```

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **引当金の4要件の暗記ではなく理解**：なぜ「将来の工場新設資金」が引当金にならず（当期以前の事象に起因しない＝利益処分の任意積立金）、賞与や修繕が引当金になるのかを判定できること。
2. **引当金の取り崩しと不足分の費用化**：目的外使用の禁止、不足分は通常の費用科目（賞与・修繕費・商品保証費等）。
3. **退職給付引当金の基本構造**：`退職給付費用 － 年金掛金拠出 ＝ 引当金増加`、従業員退職時の「引当金取崩」。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-09`, `L1C-11`）**：2級では問題文からそのまま与えられる「退職給付費用」を、1級では**退職給付債務（PBO）**と**年金資産**の割引現在価値計算から自力で算出し、さらに見積と実績のズレ（数理計算上の差異）を扱う**退職給付ワークシート（型08）**へ完全接続する。また、引当金は税務上損金不算入となるケースが多く、**税効果会計（DTA）**の主役になる。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 引当金（負債）に該当するか？ | 4要件に基づく判定理由 |
|---|---|---|
| 賞与・製品保証・定期修繕 | **該当する** | 当期以前の労働・販売・稼働が原因で支出確率が高い |
| 可能性が低い訴訟の賠償 | **該当しない（偶発債務）** | 「発生の可能性が高い」の要件を満たさない（注記対象） |
| 将来の新工場建設積立 | **該当しない（任意積立金）** | 当期以前の事象に起因する費用・損失ではない（純資産） |

> **出題者の意図**：当期の対象期間以外の月数まで賞与引当金に混ぜさせる罠、および退職給付で従業員が退職して年金基金から支払われた場合（会社現金ではなく年金資産の減額→会社仕訳なし）と会社から直接退職一時金を支払った場合（`退職給付引当金 / 普通預金`）を混同させる罠が定番です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算3月31日）の以下の引当金取引について、それぞれの仕訳を示せ。
1. 決算において、翌6月支給予定の賞与見込額 900,000円（対象期間：12月〜5月の6ヶ月）のうち当期分を引当計上し、翌6月に実際額 880,000円を普通預金から支給した（決算時・支給時の2本）。
2. 5年ごとに行う定期修繕（見積総額 2,000,000円）について、第1期目の決算で当期負担分の修繕引当金を設定した。
3. 当期の退職給付費用が 500,000円と算定され、同期間に企業年金基金へ現金 300,000円を拠出した。

### 問2（本試験標準・ひっかけ対応）
乙社（決算3月31日）の期首における引当金残高は「商品保証引当金 60,000円」「退職給付引当金 1,500,000円」であった。当期中の取引と決算整理仕訳を示し、**期末B/Sの退職給付引当金残高**を求めよ。
1. 期中：前期販売した商品の無償修理を行い、修理費 75,000円を現金で支払った。
2. 期中：定年退職した従業員に対し、退職一時金 400,000円を会社の普通預金から直接支払った。
3. 決算：当期の商品売上高は 8,000,000円であり、過去の経験から売上の 1.5% の無償修理費が発生すると見積もられるため、商品保証引当金を設定する。
4. 決算：当期の退職給付費用は 450,000円と計算された（当期の外部年金掛金拠出はなし）。

### 問3（1級視点・応用思考）
丙社の決算において、以下の3つの将来支出リスクが議論されている。企業会計原則注解18（引当金の4要件）に照らして、①**引当金計上の可否（可／不可）**を判定し、不可の場合はその理由（4要件のどれを満たさないか、代わりにどう扱うか）を説明せよ。
1. 取引先から特許侵害で提訴されており、顧問弁護士から「敗訴する可能性が高く、賠償金 500,000円の支払いが確実視される」と報告を受けた。
2. 3年後に最新鋭の工場を新設する計画があり、資金確保のために利益から 1,000,000円を積み立てたい。
3. 別の軽微な係争案件で 300,000円の請求を受けているが、弁護士から「勝訴の可能性が極めて高く、支払う可能性は低い」と報告を受けた。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1決算 | 賞与引当金繰入 | 600,000 | 賞与引当金 | 600,000 |
| 1支給 | 賞与引当金 | 600,000 | 普通預金 | 880,000 |
|  | 賞与 | 280,000 |  |  |
| 2決算 | 修繕引当金繰入 | 400,000 | 修繕引当金 | 400,000 |
| 3退職 | 退職給付費用 | 500,000 | 現金 | 300,000 |
|  |  |  | 退職給付引当金 | 200,000 |

- 1決算：`900,000 × 4 / 6 = 600,000円`、1支給：不足（翌期4〜5月分）`880,000 - 600,000 = 280,000円`
- 2決算：`2,000,000 ÷ 5 = 400,000円`

> **誤答パターン分析**：1番の支給時に、実際額880,000円が見積900,000円を下回ったからといって貸方に「賞与引当金戻入」を立ててしまうミス（当期4〜5月分の賞与280,000円を無視している！）が定番です。

### 問2の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1修理 | 商品保証引当金 | 60,000 | 現金 | 75,000 |
|  | 商品保証費 | 15,000 |  |  |
| 2退職 | 退職給付引当金 | 400,000 | 普通預金 | 400,000 |
| 3保証 | 商品保証引当金繰入 | 120,000 | 商品保証引当金 | 120,000 |
| 4退職 | 退職給付費用 | 450,000 | 退職給付引当金 | 450,000 |

```text
    [ 退職給付引当金 (固定負債) ]
  ---------------+---------------
   ②支払 400,000 | 期首 1,500,000
                 | ④費用 450,000
  ---------------+---------------
                 | 期末 1,550,000
```

- 3保証：`8,000,000 × 1.5% = 120,000円`
- **期末B/S 退職給付引当金残高**：`1,500,000 - 400,000 + 450,000 = 1,550,000円`

> **誤答パターン分析**：2番の退職一時金支払いを「退職給付費用」で処理してしまい、退職給付引当金を取り崩し忘れるミスが多発します。

---

### 問3の解答と解説

1. **①特許侵害の賠償金 500,000円：計上【可】（訴訟損失引当金）**
   - 当期以前の行為が原因であり、敗訴（発生）の可能性が高く、金額も合理的に見積もられているため4要件をすべて満たす。
2. **②新工場建設積立 1,000,000円：計上【不可】**
   - 将来の新規投資は「当期以前の事象に起因する費用・損失」ではないため要件を満たさない。代わりに純資産の部の「任意積立金（別途積立金等）」として積み立てる。
3. **③軽微な係争 300,000円：計上【不可】（偶発債務）**
   - 「発生の可能性が高い」の要件を満たさないため引当金計上は不可。重要性が乏しくない限り財務諸表の「注記（偶発債務）」で開示する。

> **誤答パターン分析**：②の工場新設を「設備建設引当金」として負債に計上してしまったり、③を保守主義の名目で強制的に引当金計上してしまう誤答（4要件の軽視）が定番です。
