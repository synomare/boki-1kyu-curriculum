## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

かつての旧リース会計基準（企業会計基準第13号）では、リース取引を「ファイナンス・リース」と「オペレーティング・リース」に分け、後者は単なる賃貸借として処理し、**巨額の支払義務（リース料）をB/Sに載せない（オフバランス）**ことが許されていました。その結果、店舗や航空機を長期リースで借りている企業は、実質的に莫大な借金を抱えて資産を使っているにもかかわらず、B/S上は無借金のように見えてしまい、投資家の比較を著しく歪めていました。

そこで**新リース会計基準（企業会計基準第34号）**では、借手側におけるファイナンス／オペレーティングの区分を廃止し、**原則としてすべてのリースについて、資産（使用権資産）と負債（リース負債）をB/Sに計上する（オンバランス化）**ことになりました。
- **使用権資産**：リース期間にわたって原資産（店舗・機械等）を使用する権利＝将来のキャッシュ獲得能力（資産）。
- **リース負債**：リース料を支払う法的義務（負債）。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> A社（決算3月31日）は×1年4月1日に以下のリース契約を締結した。
> - **原則処理（5年機械リース）**：リース期間5年、年間リース料 240,000円（毎年3月31日払、総額 1,200,000円）、リース料総額の割引現在価値は 1,000,000円（利息相当額 200,000円は定額法で毎年 40,000円ずつ配分）、減価償却はリース期間5年の定額法（残存価額ゼロ、間接法）。
>   1. **利子抜き法**（原則）による開始時・第1期支払時・第1期決算時の仕訳を示せ。
>   2. **利子込み法**（簡便）による開始時・第1期支払時・第1期決算時の仕訳を示せ。
> - **簡便処理（短期リース）**：×1年4月1日に期間10ヶ月のイベント用機材リース（月額 30,000円）を契約し、第1回目の30,000円を普通預金から支払った。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①開始(抜) | 使用権資産 | 1,000,000 | リース負債 | 1,000,000 |
| ①支払(抜) | リース負債 | 200,000 | 普通預金 | 240,000 |
|  | 支払利息 | 40,000 |  |  |
| ①償却(抜) | 減価償却費 | 200,000 | 使用権資産減価償却累計額 | 200,000 |
| ②開始(込) | 使用権資産 | 1,200,000 | リース負債 | 1,200,000 |
| ②支払(込) | リース負債 | 240,000 | 普通預金 | 240,000 |
| ②償却(込) | 減価償却費 | 240,000 | 使用権資産減価償却累計額 | 240,000 |
| ③短期 | 支払リース料 | 30,000 | 普通預金 | 30,000 |

- **利子抜き法の論理**：経済的実態は「1,000,000円の資産を借りて使い、毎年元本200,000円＋利息40,000円を返す」取引と同じ。したがって、P/L上は「減価償却費 200,000円（営業費用）」と「支払利息 40,000円（営業外費用）」に分離される。
- **利子込み法の論理**：簡便的に総額1,200,000円で資産・負債を立て、支払利息を分離せず全額を減価償却費（240,000円）に含める。
- **短期・少額リースの例外**：リース期間が12ヶ月以内の「短期リース」や、少額資産の「少額リース」は、オンバランスせず通常の賃貸借処理（支払リース料）が認められる。

### 【1級貫通・標準下書きフォーマット】

型01（タイムライン型）と型04（償却表型）でリース負債と使用権資産を並走させます。

```text
  ×1/4/1(開始)                    ×2/3/31(1年目末)              ×6/3/31(5年満了)
----+-------------------------------+-------------------------------+----->
資産| 使用権資産 1,000,000          | 償却200,000 (簿価 800,000)    | 簿価 0

```

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **新基準の勘定科目**：旧基準の「リース資産・リース債務」ではなく、**「使用権資産」「リース負債」**を使う。
2. **利子抜き法 vs 利子込み法**：元本（現在価値）で立てて利息を分離する利子抜き法と、総額で立てる利子込み法の両方を自在に書けること。
3. **短期リース・少額リース**：期間12ヶ月以内（短期）または少額の場合は、賃貸借処理（支払リース料）ができること。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-08`）**：新リース会計基準の完全版として、①契約が「リースを含むか」の識別、②延長・解約オプションを考慮したリース期間の決定、③定額法ではなく**利息法（実効利子率）**による負債償却表、④契約変更・**セール＆リースバック**・サブリース・借地権・貸手側の処理へと一気に広がる。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 利子抜き法（原則） | 利子込み法（簡便） | 短期・少額リース（例外） |
|---|---|---|---|
| 開始時資産・負債 | **割引現在価値**（1,000,000） | リース料総額（1,200,000） | **計上しない（オフバランス）** |
| 支払時の利息分離 | **あり**（`支払利息`） | なし（全額 `リース負債` 減） | 全額 `支払リース料` |
| P/L上の費用科目 | 減価償却費＋**支払利息** | 減価償却費のみ | 支払リース料のみ |

> **出題者の意図**：新基準では不動産の賃借等も原則オンバランス対象になりますが、「12ヶ月以内の短期リース」や「少額リース」まで誤って使用権資産に計上させる罠、および利子抜き法で支払利息を「営業費用」と混同させる罠に注意してください。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算3月31日）は×1年4月1日に機械のリース契約を締結した（リース期間4年、年間リース料 300,000円、毎年3月31日払、支払総額 1,200,000円、割引現在価値 1,040,000円、利息相当額の配分は定額法、使用権資産の償却は期間4年定額法・残存ゼロ・間接法）。
1. **利子抜き法**による開始時・×2年3月31日（1年目末）の仕訳と、1年目末の**使用権資産帳簿価額およびリース負債残高**を求めよ。
2. **利子込み法**による開始時・×2年3月31日の仕訳と、1年目末の**使用権資産帳簿価額およびリース負債残高**を求めよ。

### 問2（本試験標準・ひっかけ対応）
乙社（決算3月31日）は、×1年10月1日（期首から6ヶ月経過後）に以下の3つのリース契約を同時に締結した。×1年度（×1年10月1日〜×2年3月31日）に必要な仕訳をすべて示せ（すべて普通預金払、利子抜き法・月割計算）。
1. **店舗不動産リース（原則オンバランス）**：リース期間5年、年間リース料 1,200,000円（毎年9月30日払）、割引現在価値 5,400,000円、利息相当額（計600,000円）は定額法（年120,000円）で配分、使用権資産は5年定額法（残存ゼロ・間接法）で償却。
2. **イベント用複合機リース（短期リース特例適用）**：リース期間12ヶ月、月額 20,000円（毎月末払、当期6ヶ月分計120,000円を支払済み）。
3. **少額備品リース（少額リース特例適用）**：年間リース料 60,000円（10/1に1年分を一括前払い）。

### 問3（1級視点・応用思考）
丙社は、ある設備の5年リース（年間リース料 600,000円・毎年末払、割引現在価値 2,500,000円、利息相当額は定額法で年100,000円、使用権資産は5年定額法）を×1年4月1日に締結した。
1. もし旧来の賃貸借処理（年間 600,000円を営業費用「賃借料」として処理・オフバランス）を行った場合と、新基準の**利子抜き法**（オンバランス）を行った場合について、1年目の**①営業利益の差額、②経常利益の差額、③総資産および総負債の増減額**をそれぞれ比較計算せよ。
2. なぜ新リース会計基準では、従来のオペレーティング・リースのような賃貸借処理（オフバランス）を原則禁止し、使用権資産・リース負債の計上を求めたのか、財務諸表の比較可能性の観点から2行以内で説明せよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1開始(抜) | 使用権資産 | 1,040,000 | リース負債 | 1,040,000 |
| 1支払(抜) | リース負債 | 260,000 | 普通預金 | 300,000 |
|  | 支払利息 | 40,000 |  |  |
| 1償却(抜) | 減価償却費 | 260,000 | 使用権資産減価償却累計額 | 260,000 |
| 2開始(込) | 使用権資産 | 1,200,000 | リース負債 | 1,200,000 |
| 2支払(込) | リース負債 | 300,000 | 普通預金 | 300,000 |
| 2償却(込) | 減価償却費 | 300,000 | 使用権資産減価償却累計額 | 300,000 |

- 1（利子抜き法）：1年目末 **使用権資産簿価** `1,040,000 - 260,000 = 780,000円`、**リース負債残高** `1,040,000 - 260,000 = 780,000円`
- 2（利子込み法）：1年目末 **使用権資産簿価** `1,200,000 - 300,000 = 900,000円`、**リース負債残高** `1,200,000 - 300,000 = 900,000円`

> **誤答パターン分析**：利子抜き法で減価償却費を総額1,200,000円÷4＝300,000円としてしまうミス（支払利息40,000円と二重計上になる）が定番です。

### 問3の解答と解説

1. **賃貸借処理（オフバランス）vs 利子抜き法（オンバランス）の比較**：
   - 賃貸借処理：営業費用（賃借料）600,000円、支払利息 0円。
   - 利子抜き法：営業費用（減価償却費 `2,500,000 ÷ 5`）**500,000円**、営業外費用（支払利息）**100,000円**。
   - **①営業利益の差額**：利子抜き法の方が営業費用が100,000円少ないため、**営業利益は 100,000円 増加**する。
   - **②経常利益の差額**：営業外費用（支払利息100,000円）が差し引かれるため、**経常利益の差額は 0円（不変）**。
   - **③開始時総資産・総負債の増減**：オンバランス化により、開始時点で**総資産・総負債がともに 2,500,000円 増加**する（1年目末時点でも `2,000,000円` 増加）。
2. **原則オンバランス化の理由**：借入で購入した場合と実質的に同じ経済的便益の支配（使用権）と支払義務（負債）を負っているにもかかわらず、契約形式の違いだけでB/Sから資産・負債が消えると、自己資本比率や投資効率の企業間比較が歪められるため。

> **誤答パターン分析**：P/Lの費用合計600,000円が同じであることから「営業利益も変わらない」と誤解し、営業利益＋100,000円のシフトを見落とすケースが多く見られます。
