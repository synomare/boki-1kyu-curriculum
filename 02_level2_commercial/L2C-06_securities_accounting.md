## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

同じ「A社の株式」や「B社の社債」を持っていても、**「短期の値上がり益を狙って買ったのか（トレーディング）」「満期まで持って利息をもらうつもりか」「子会社を支配するためか」**によって、投資家にとって意味のある評価額はまったく異なります。

もしすべての有価証券を「期末の時価」で一律に評価してP/Lに損益を出したらどうなるでしょうか？
- **子会社株式の時価評価の罠**：子会社株式は経営支配のために長期保有する事業投資そのものであり、売るつもりがないのに日々の株価変動で本社の当期純利益が乱高下したら、企業の稼ぐ力を見誤る。
- **その他有価証券のP/L直入の罠**：政策保有株などの「すぐには売らないが事業投資でもない株式」の評価差額をP/Lに入れてしまうと、未実現の含み益で配当可能利益が膨らんでしまう。

したがって、金融商品会計基準は有価証券を**保有目的別に4分類**し、それぞれ異なる測定属性（時価・償却原価・取得原価）を適用します。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> A社（決算3月31日）が保有する以下の有価証券について、決算整理仕訳（洗替方式）を示せ。
> 1. **売買目的有価証券**：期中取得 510,000円（本体 500,000円＋手数料 10,000円）、期末時価 540,000円。
> 2. **満期保有目的債券**：×1年4月1日に額面 1,000,000円の社債（償還期間5年）を 950,000円で取得。差額は金利の調整と認められるため定額法で償却原価法を適用する（クーポン利息は省略）。
> 3. **子会社株式**：取得原価 2,000,000円、期末時価 1,850,000円（著しい下落ではない）。
> 4. **その他有価証券**：取得原価 800,000円、期末時価 860,000円（全部純資産直入法、税効果は別単元）。
> - **端数利息（期中購入例）**：額面 1,000,000円（年利 3.65%、利払日 年1回3月31日）の社債を、利払日の翌日から起算して50日経過後に 980,000円で売買目的として購入し、50日分の端数利息とともに普通預金から支払った。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①期末 | 売買目的有価証券 | 30,000 | 有価証券評価益 | 30,000 |
| ②期末 | 満期保有目的債券 | 10,000 | 有価証券利息 | 10,000 |
| ④期末 | その他有価証券 | 60,000 | その他有価証券評価差額金 | 60,000 |
| 端数購入 | 売買目的有価証券 | 980,000 | 普通預金 | 985,000 |
|  | 有価証券利息 | 5,000 |  |  |

- **①の論理**：手数料10,000円は取得原価に算入（計510,000円）。売買目的は現金同等物に近いため、時価差額 `+30,000円` を即時にP/L「有価証券評価益」とする。
- **②の論理（償却原価法）**：950,000円で買って5年後に1,000,000円返ってくる差額50,000円は「利子の前受け（ディスカウント）」。毎年 `50,000 ÷ 5 = 10,000円` ずつ簿価を増やしながら「有価証券利息（収益＋）」を計上する（1年目末簿価 960,000円）。
- **③の論理**：子会社株式は支配目的の投資ゆえ**取得原価評価（仕訳なし）**。
- **④の論理**：その他有価証券はB/Sでは時価860,000円を示すが、P/Lを歪めないよう差額60,000円は純資産の「その他有価証券評価差額金」へ直入する（翌期首に洗替）。
- **端数利息の論理**：`(1,000,000 × 3.65% × 50) / 365 = 5,000円`。売主に前払いした50日分の利息は取得原価に含めず、借方「有価証券利息」で立てておき、次の利払日に1年分（36,500円）を受け取ったときに相殺されて保有期間分（31,500円）が自動計算される。

### 【1級貫通・標準下書きフォーマット】

型01（タイムライン型）で満期保有債券の償却期間・端数利息日数を確定します。

```text
  ×1/4/1(取得)                    ×2/3/31(1年目末)              ×6/3/31(満期)
----+-------------------------------+-------------------------------+----->
    | 簿価 950,000                  | +10,000 -> 簿価 960,000       | 額面 1,000,000
    | (差額 50,000 ÷ 5年 = 年10,000)
```

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **4分類の評価基準テーブルの完全習得**：売買（時価/P/L）、満期（償却原価）、関係会社（取得原価）、その他（時価/純資産直入）。
2. **償却原価法（定額法）と月割計算**：期中取得の場合は必ず月割りで当期分を算定する。
3. **端数利息の計算と処理**：`額面 × 年利率 × 経過日数 / 365`、購入時は借方「有価証券利息」、売却時は貸方「有価証券利息」。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-03`, `L1C-11`, `L1C-14`）**：償却原価法が複利ベースの「**利息法（実効金利法）**」に進化し、その他有価証券評価差額金への**税効果会計（DTL/DTA）**、時価が50%以上下落した際の**減損処理（強制評価減）**、そして包括利益計算書における**リサイクリング（組替調整）**へと直結する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 分類 | B/S評価額 | 評価差額の処理 | 翌期首の洗替 |
|---|---|---|---|
| **売買目的有価証券** | 時価 | **P/L（有価証券評価損益）** | 切放法が原則（2級標準） |
| **満期保有目的債券** | 償却原価（または原価） | 金利調整差額は **有価証券利息** | なし |
| **子会社・関連会社株式** | 取得原価 | なし（著しい下落時は減損） | なし |
| **その他有価証券** | 時価 | **純資産（その他有価証券評価差額金）** | **あり（洗替方式）** |

> **出題者の意図**：端数利息を「有価証券の取得原価」に混ぜてしまう罠、および満期保有目的債券の時価が問題文に書かれている際に誤って時価評価させてしまう罠が最頻出です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算3月31日）が保有する以下の4銘柄について、期末決算整理仕訳を示し、それぞれの**期末B/S計上額**を求めよ（すべて当期首取得）。

4. その他有価証券（D社株式）：取得原価 600,000円、期末時価 650,000円（全部純資産直入法）

### 問2（本試験標準・ひっかけ対応）
乙社（決算3月31日）の当期における以下の有価証券取引の仕訳を示せ（1年365日）。
1. ×1年10月1日に満期保有目的でE社社債（額面 1,000,000円、償還日×5年9月30日＝残存48ヶ月、年利率3.65%、利払日3月末・9月末の年2回）を 952,000円で取得した。×2年3月31日決算において、半期分のクーポン利息を普通預金で受け取るとともに、定額法による償却原価法（6ヶ月分）を適用した（取得時・3/31クーポン受取・3/31償却原価の3本）。
2. F社社債（額面 1,000,000円、年利率3.65%、利払日 年1回3月末）を、前回の利払日の翌日から起算して100日経過後に、額面100円につき99円（計990,000円）で売買目的として購入し、端数利息とともに普通預金から支払った。
3. 保有していた売買目的有価証券（前期末簿価 300,000円）を 340,000円で売却し、代金は普通預金に入金された。

### 問3（1級視点・応用思考）
丙社は×1年4月1日に株式を 1,000,000円で取得し、×2年3月31日（第1期末）の時価が 1,150,000円、×3年3月31日（第2期中）に 1,220,000円で全株売却した。

2. 当該株式を**「その他有価証券（全部純資産直入法・洗替方式）」**として保有していた場合の、第1期P/L損益・第1期末純資産直入額・第2期P/L損益・2年間合計P/L損益を求めよ。
3. 上記1.と2.を比較し、その他有価証券の2年間合計P/L損益が売買目的と一致する理由（リサイクリングの本質）を2行以内で説明せよ。

### 問2の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1取得 | 満期保有目的債券 | 952,000 | 普通預金 | 952,000 |
| 1利息 | 普通預金 | 18,250 | 有価証券利息 | 18,250 |
| 1償却 | 満期保有目的債券 | 6,000 | 有価証券利息 | 6,000 |
| 2購入 | 売買目的有価証券 | 990,000 | 普通預金 | 1,000,000 |
|  | 有価証券利息 | 10,000 |  |  |
| 3売却 | 普通預金 | 340,000 | 売買目的有価証券 | 300,000 |
|  |  |  | 有価証券売却益 | 40,000 |

- 1クーポン：`1,000,000 × 3.65% × 6 / 12 = 18,250円`
- 1償却：`48,000 × 6 / 48 = 6,000円`（1年目末簿価 `958,000円`）
- 2端数利息：`(1,000,000 × 3.65% × 100) / 365 = 10,000円`

> **誤答パターン分析**：1番の償却原価法で残存月数48ヶ月ではなく12ヶ月で割って48,000円を1年で償却してしまうミス、および2番の端数利息10,000円を取得原価990,000円に混ぜて1,000,000円にするミスが多発します。

### 問3の解答と解説

```text
  【P/L損益の期間配分比較】
  区分         | 第1期 P/L     | 第1期末純資産 | 第2期 P/L     | 2年間P/L合計
  -------------+---------------+---------------+---------------+-------------
  売買目的     | +150,000 (評) |             0 |  +70,000 (売) |    +220,000
  その他有価   |        0      |      +150,000 | +220,000 (売) |    +220,000
```

1. **売買目的有価証券**：第1期 **+150,000円**（評価益）、第2期 **+70,000円**（売却益 `1,220,000 - 1,150,000`）、合計 **+220,000円**。
2. **その他有価証券**：第1期P/L **0円**（純資産直入 **+150,000円**）、第2期P/L **+220,000円**（洗替で原価1,000,000円に戻るため売却益 `1,220,000 - 1,000,000`）、合計 **+220,000円**。
3. **合計一致の理由**：その他有価証券の評価差額は、保有中は未実現の損益として純資産に留保されるが、売却してキャッシュが確定（実現）した瞬間に洗替・売却を通じてP/Lへ組み替えられる（リサイクリング）ため、投資期間全体のP/L利益合計は必ず一致する。

> **誤答パターン分析**：その他有価証券の第2期売却益を、第1期末の時価1,150,000円との差額70,000円としてしまい、第1期の純資産直入150,000円がP/Lから永久に抜け落ちてしまうミスが定番です。
