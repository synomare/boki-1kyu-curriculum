## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

期末日において、会社の帳簿上の「当座預金残高」と銀行が発行する「残高証明書」が一致しないことは実務上ごく普通に起きます。その理由は、①銀行側がまだ処理していない（時間外預入など）のか、②会社側が銀行の動きを知らずに未記帳（振込手数料の引き落としや未通知入金）または誤記帳しているのか、の2つに大別されます。もし原因を突き止めずに放置すれば、B/Sの預金残高が不正確になるだけでなく、横領や記帳漏れの温床になります。

また、資金繰りのために「電子記録債権」や「売掛金」を満期前に現金化する取引（**割引・ファクタリング**）では、**「単なる借金（担保融資）なのか、債権そのものを手放して現金化した（売却）のか」**という経済的実態を見極めることが核心です。

※2027年4月改定により紙の小切手・手形は廃止されたため、銀行勘定調整表の調整項目も電子決済・時間外預入・未通知項目が中心となり、債権流動化も**電子記録債権の割引・譲渡**および**ファクタリング（2社間・3社間）**が中核となります。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **銀行勘定調整表（両者区分調整法）**：決算日の企業側当座預金残高は 1,200,000円、銀行側残高証明書は 1,280,000円であった。不一致原因：①銀行振込手数料 5,000円の引落未記帳、②得意先からの売掛金入金 150,000円の未通知、③買掛金支払 45,000円を 54,000円と誤記帳（+9,000円の修正要）、④決算日夕方の時間外預入 74,000円（銀行未処理）。
> 2. **電子記録債権の譲渡・割引**：買掛金決済のため電子記録債権 300,000円を譲渡し、また別の電子記録債権 600,000円（満期まで73日、年割引率5%、1年365日）を銀行で割り引き、手取金を当座預金に受け入れた。
> 3. **2社間ファクタリング**：売掛金 500,000円をファクタリング会社へ譲渡し（手数料4%）、手取金を普通預金で受け取った。後日、得意先から当社口座へ 500,000円が入金され、ただちにファクタリング会社へ送金した。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①修正 | 支払手数料 | 5,000 | 当座預金 | 5,000 |
|  | 当座預金 | 150,000 | 売掛金 | 150,000 |
|  | 当座預金 | 9,000 | 買掛金 | 9,000 |
| ②譲渡 | 買掛金 | 300,000 | 電子記録債権 | 300,000 |
| ②割引 | 当座預金 | 594,000 | 電子記録債権 | 600,000 |
|  | 債権売却損 | 6,000 |  |  |
| ③契約 | 普通預金 | 480,000 | 売掛金 | 500,000 |
|  | 債権売却損 | 20,000 |  |  |
| ③回収 | 普通預金 | 500,000 | 預り金 | 500,000 |
| ③送金 | 預り金 | 500,000 | 普通預金 | 500,000 |

- **銀行勘定調整表の論理**：企業側の修正仕訳が必要なのは**「企業側の未記帳・誤記帳（①〜③）」だけ**。銀行側の未処理（④時間外預入）は翌営業日に銀行側で自動反映されるため、**企業側では一切仕訳を切らない**。
- **電債割引の論理**：`600,000 × 5% × 73 / 365 = 6,000円` の利息相当額が「債権売却損（費用＋）」となり、債権600,000円（資産－）が消滅する。
- **2社間ファクタリングの論理**：得意先に譲渡を通知しない2社間契約では、後日いったん当社の口座に500,000円が振り込まれるが、そのお金はすでにファクタリング会社の所有物であるため「売上や売掛金回収」ではなく**「預り金（負債＋）」**として受け入れ、送金時に消込する。

### 【1級貫通・標準下書きフォーマット】

型03（T勘定連結）による両者区分調整表で、**必ず企業側正残高 ＝ 銀行側正残高**を一致検算します。

```text
  【企業側残高の調整】               【銀行側残高の調整】
  修正前残高      1,200,000          残高証明書      1,280,000
  (-) 手数料未記帳   -5,000          (+) 時間外預入    +74,000
  (+) 未通知入金   +150,000
  (+) 誤記訂正       +9,000
  -------------------------          -------------------------
  企業側正残高    1,354,000   ===    銀行側正残高    1,354,000
```

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **両者区分調整法と修正仕訳の切り分け**：銀行側の調整項目は仕訳不要、企業側の調整項目のみ修正仕訳を切る。
2. **電子記録債権の割引・譲渡**：日割計算（`元本 × 年率 × 日数 / 365`）と「債権売却損」の認識。
3. **2社間 vs 3社間ファクタリング**：契約時の「債権売却損」と、2社間における回収時の「預り金」処理。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-02`）**：債権の流動化において「買戻特約（リコース義務）」が付いている場合、資産の消滅要件（**財務構成要素アプローチ**）に基づき、消滅する部分と新たに負う「保証債務」を時価で分離認識する処理へと進化する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 取引形態 | 得意先への通知 | 譲渡時の勘定 | 得意先からの入金時 |
|---|---|---|---|
| **3社間ファクタリング** | あり（同意） | `普通預金 / 売掛金`（差額：債権売却損） | 得意先はファクタリング会社へ直接払う（当社仕訳なし） |
| **2社間ファクタリング** | なし | `普通預金 / 売掛金`（差額：債権売却損） | 当社口座へ入金 → **`普通預金 / 預り金`**（後日送金消込） |

> **出題者の意図**：銀行勘定調整表の「時間外預入」に対して誤って企業側の修正仕訳を切らせる罠、および2社間ファクタリングで得意先から入金があった際に「売掛金」を二重に減額させてしまう罠が頻出です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算3月31日）の当座預金勘定残高は 850,000円、銀行の残高証明書は 910,000円であった。調査の結果、以下の不一致原因が判明した。両者区分調整法により**修正後の当座預金正残高**を求め、**企業側で必要な修正仕訳**をすべて示せ。
1. 銀行口座維持手数料 3,000円が引き落とされていたが、当社で未記帳であった。
2. 得意先から売掛金 120,000円の振込入金があったが、当社へ未通知であった。
3. 買掛金 60,000円の支払いを、誤って `(借) 買掛金 114,000 / (貸) 当座預金 114,000` と過大に記帳していた。
4. 3月31日営業時間終了後に現金 111,000円を夜間金庫へ預け入れたが、銀行の翌営業日扱いとなっていた。

### 問2（本試験標準・ひっかけ対応）
乙社の以下の債権流動化取引について、一連の仕訳をすべて示せ（1年は365日として日割計算すること）。
1. 保有する電子記録債権 1,000,000円（支払期日まで残り146日）を銀行で割り引き、年割引率 2.5% の割引料を差し引かれた残額が当座預金に入金された。
2. 売掛金 400,000円について、得意先に通知しない契約（2社間ファクタリング）でファクタリング会社へ譲渡し、手数料5%を差し引かれた手取額が普通預金に入金された（契約時）。
3. 上記2.について、後日得意先から 400,000円が当社の普通預金口座へ振り込まれ、その全額をファクタリング会社へ普通預金から送金した（回収時・送金時の2本）。

### 問3（1級視点・応用思考）
丙社（決算3月31日）の銀行残高証明書は 1,500,000円、調査後に確定したB/S記載の正しい当座預金残高は 1,620,000円であった。不一致原因は以下の4点のみであった。
- ①決算日夕方の時間外預入 **X円**（銀行側未処理）
- ②当座預金からの電気代自動引落 12,000円の未記帳
- ③得意先からの売掛金入金 80,000円の未通知
- ④買掛金 20,000円の振込を 38,000円と誤記帳
1. **X（時間外預入額）** および **修正前の企業側当座預金帳簿残高 Y** をそれぞれ逆算せよ。
2. 2社間ファクタリングにおいて、得意先から後日回収した代金を「売上」や「仮受金」ではなく「預り金」で処理する会計上の理由を1〜2行で説明せよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

```text
  【企業側】                      【銀行側】
  修正前        850,000           証明書        910,000
  (-) 手数料     -3,000           (+) 時間外   +111,000
  (+) 未通知   +120,000
  (+) 誤記訂正  +54,000
  ---------------------           ---------------------
  正残高      1,021,000    ===    正残高      1,021,000
```

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1 | 支払手数料 | 3,000 | 当座預金 | 3,000 |
| 2 | 当座預金 | 120,000 | 売掛金 | 120,000 |
| 3 | 当座預金 | 54,000 | 買掛金 | 54,000 |

- **当座預金正残高**：1,021,000円（4.の時間外預入111,000円は銀行側調整項目のため企業側仕訳なし）

> **誤答パターン分析**：3番の誤記訂正で差額 `114,000 - 60,000 = 54,000円` ではなく、誤った額114,000円や正額60,000円を仕訳してしまうミスが定番です。

### 問2の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1割引 | 当座預金 | 990,000 | 電子記録債権 | 1,000,000 |
|  | 債権売却損 | 10,000 |  |  |
| 2契約 | 普通預金 | 380,000 | 売掛金 | 400,000 |
|  | 債権売却損 | 20,000 |  |  |
| 3回収 | 普通預金 | 400,000 | 預り金 | 400,000 |
| 3送金 | 預り金 | 400,000 | 普通預金 | 400,000 |

- 1割引料：`(1,000,000 × 2.5% × 146) / 365 = 10,000円`、手取額 `990,000円`
- 2手数料：`400,000 × 5% = 20,000円`、手取額 `380,000円`

> **誤答パターン分析**：3回収の時点で売掛金400,000円を再び貸方に立ててしまうミス（契約時にすでに消滅済み）が多く見られます。

---

### 問3の解答と解説

1. **X と Y の逆算**：
   - 銀行側：`1,500,000 + X = 1,620,000` より、**X（時間外預入）＝ 120,000円**。
   - 企業側：`Y - 12,000 + 80,000 + (38,000 - 20,000) = 1,620,000` → `Y + 86,000 = 1,620,000` より、**Y（修正前帳簿残高）＝ 1,534,000円**。
2. **預り金とする理由**：売掛金はすでにファクタリング会社へ売却済みであるため、得意先からの入金は当社の収益や債権回収ではなく、他社（ファクタリング会社）の資金を一時的に預かって引き渡す法的義務（負債）に該当するため。

> **誤答パターン分析**：④の誤記訂正 `38,000 - 20,000 = +18,000円` の符号をマイナスにしてしまい、Yを1,570,000円と逆算するミスが多発します。
