## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

日本の企業は、財務諸表をすべて「日本円」で報告しなければなりません。しかし、海外企業から1,000ドルで商品を仕入れたり、1,000ドルで販売したりすると、**「取引日のレート（1ドル＝140円）」と「決算日や決済日のレート（1ドル＝145円）」が日々変動する**ため、円建ての支払額・受取額が刻々と変化します。

もし決算日に外貨建の売掛金や買掛金を「取引日の古いレート（140円）」のまま放置したらどうなるでしょうか？
- **実態と乖離した資産・負債**：今まさに決済したら145,000円もらえる（または払わねばならない）のに、B/Sに140,000円と載せることになり、為替変動リスクによる損益が隠蔽される。
- **為替予約の本質**：逆に、将来の為替変動リスクを消すために銀行と「1ドル＝146円で交換する」と約束（**為替予約**）した瞬間、将来のキャッシュ・フローは円ベースで完全に固定される。したがって、決算日のスポットレートで再評価する必要がなくなる（**振当処理**）。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **基本の外貨換算**：×1年11月1日に商品 1,000ドルを掛けで販売した（直物レート HR＝140円）。×2年3月31日決算日の直物レート（CR）は 145円、翌期×2年4月20日の回収日の直物レートは 142円であった（普通預金入金）。
> 2. **為替予約（振当処理）**：×1年12月1日に商品 2,000ドルを掛け仕入した（HR＝140円、280,000円）。×2年1月15日に買掛金決済のため 1ドル＝146円の先物為替予約（FR）を付し、振当処理を適用した。×2年3月31日決算（CR＝150円）を経て、×2年5月31日に普通預金で決済した。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①販売 | 売掛金 | 140,000 | 売上 | 140,000 |
| ①決算 | 売掛金 | 5,000 | 為替差損益 | 5,000 |
| ①回収 | 普通預金 | 142,000 | 売掛金 | 145,000 |
|  | 為替差損益 | 3,000 |  |  |
| ②仕入 | 仕入 | 280,000 | 買掛金 | 280,000 |
| ②予約 | 為替差損益 | 12,000 | 買掛金 | 12,000 |
| ②決済 | 買掛金 | 292,000 | 普通預金 | 292,000 |

- **①の論理**：外貨建の「売掛金（金銭債権＝貨幣項目）」は、決算日レート（CR）145円で評価替えし、差額 `+5,000円` を「為替差損益（収益）」とする。回収時は142円（142,000円）で入金されるため、簿価145,000円との差額 `3,000円` が為替差損となる。
- **②の論理（振当処理）**：為替予約を付した瞬間に、将来の支払額が `2,000ドル × 146円 = 292,000円` に確定した。よって予約日に買掛金を292,000円へ修正（+12,000円、為替差損12,000円）すれば、その後**決算日レート（CR＝150円）になっても一切評価替えしない**。

### 【1級貫通・標準下書きフォーマット】

型01（タイムライン型）の上に各時点のレート（HR・SR・FR・CR）を書き込みます。

```text
  ×1/12/1(仕入)         ×2/1/15(為替予約)    ×2/3/31(決算)     ×2/5/31(決済)
----+---------------------+--------------------+-----------------+----->
    HR=140円              FR=146円             CR=150円(無視!)   決済 292,000
    買掛 280,000          買掛 292,000 (+12k)  確定済ゆえ変動なし
```

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **貨幣項目 vs 非貨幣項目の換算**：現金預金・売掛金・買掛金・貸付金・借入金（貨幣項目）は決算時 **CR**、前払金・前受金・固定資産（非貨幣項目）は **HRのまま（換算替えしない）**。
2. **為替予約（振当処理）**：予約レート（FR）で円額が確定した後は、決算時CRで再評価しない。
3. **直々差額と直先差額の区別（2級標準〜発展）**：予約時の「直々差額（発生日HR→予約日SR）」は当期損益、「直先差額（予約日SR→予約日FR）」は金利差相当として期間配分する考え方も理解しておく。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-04`, `L1C-12`）**：2級の振当処理は簡便な特例処理であり、1級では予約を独立のデリバティブ資産・負債として時価評価する「**独立処理（ヘッジ会計の原則）**」、外貨建有価証券の換算、さらに海外子会社の財務諸表を円換算する「**在外子会社換算（CR法・為替換算調整勘定）**」へと進化する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 外貨建項目 | 決算時の換算レート | 理由 |
|---|---|---|
| **売掛金・買掛金・貸付金・借入金**（未予約） | **決算時直物レート (CR)** | 将来外貨で決済される金銭債権債務（為替リスクあり） |
| **為替予約済みの売掛金・買掛金** | **予約レート (FR) のまま** | 円建てキャッシュ・フローがすでに確定済み |
| **前払金・前受金** | **発生時レート (HR) のまま** | 商品を引き取る/渡す権利義務であり為替決済しない（非貨幣項目） |

> **出題者の意図**：前払金や前受金を決算日レート（CR）で評価替えさせてしまう罠、および為替予約済みの買掛金を決算日にCRで再度評価替えさせてしまう罠が定番です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算3月31日）の以下の外貨建取引について、発生時・決算時・決済時の仕訳をすべて示せ（すべて為替予約なし）。
1. ×1年10月1日に商品 3,000ドルを掛け仕入し（HR＝145円）、×1年12月10日に普通預金から決済した（決済日HR＝140円）。
2. ×2年2月1日に商品 4,000ドルを掛け販売した（HR＝148円）。×2年3月31日決算日のCRは 152円であり、翌期×2年5月10日に普通預金で回収した（回収日HR＝150円）。

### 問2（本試験標準・ひっかけ対応）
乙社（決算3月31日）の以下の輸入取引および為替予約取引の仕訳を示せ（振当処理）。
1. ×1年11月1日に海外取引先へ商品代金の手付金として 1,000ドルを普通預金から前払いした（HR＝140円）。
2. ×1年12月1日に商品 5,000ドルを輸入して仕入を計上し、上記手付金 1,000ドルを充当した残額 4,000ドルを掛けとした（仕入日HR＝146円）。
3. ×2年2月1日に上記買掛金 4,000ドルについて、決済日（×2年4月30日）を満期とする 1ドル＝148円の予約（FR）を付した（2級基本の一括振当処理とする）。
4. ×2年3月31日（決算）を迎えた（決算日CR＝155円）。決算整理仕訳の要否を判定し、必要な場合は仕訳を示せ（不要なら「仕訳なし」と明記）。

### 問3（1級視点・応用思考）
丙社（決算3月31日）は×1年11月1日に商品 5,000ドルを掛け販売した（取引日HR＝140円）。×1年12月1日（決算日まで残り4ヶ月、決済日×2年5月31日まで6ヶ月）に、この売掛金 5,000ドルについて為替予約を付した（予約日の直物レート SR＝143円、予約レート FR＝149円）。
振当処理における原則法（直々差額と直先差額の区分処理：直先差額は予約日から決済日までの6ヶ月で月割期間配分）を適用した場合、
1. 予約日（×1年12月1日）および決算日（×2年3月31日）の仕訳を示せ。
2. ×1年度P/Lおよび×2年度P/Lに計上される**為替差損益**と、2年間通算の為替差損益合計を求めよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1仕入 | 仕入 | 435,000 | 買掛金 | 435,000 |
| 1決済 | 買掛金 | 435,000 | 普通預金 | 420,000 |
|  |  |  | 為替差損益 | 15,000 |
| 2販売 | 売掛金 | 592,000 | 売上 | 592,000 |
| 2決算 | 売掛金 | 16,000 | 為替差損益 | 16,000 |
| 2回収 | 普通預金 | 600,000 | 売掛金 | 608,000 |
|  | 為替差損益 | 8,000 |  |  |

- 1決済：円高により支払額が減ったため為替差益 `(145 - 140) × 3,000 = 15,000円`
- 2決算：`(152 - 148) × 4,000 = 16,000円`、2回収：`(150 - 152) × 4,000 = -8,000円`

> **誤答パターン分析**：買掛金において円高（145円→140円）になった際、売掛金と混同して「為替差損」にしてしまう符号ミスが定番です。負債はレートが下がるほど返済負担が減るので「益」になります。

### 問2の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1前払 | 前払金 | 140,000 | 普通預金 | 140,000 |
| 2仕入 | 仕入 | 724,000 | 前払金 | 140,000 |
|  |  |  | 買掛金 | 584,000 |
| 3予約 | 為替差損益 | 8,000 | 買掛金 | 8,000 |

- 2仕入：前払金充当分は発生時レート（140,000円）のまま固定し、残額4,000ドルのみ仕入日HR（146円＝584,000円）で換算して合算する（`140,000 + 584,000 = 724,000円`）。
- 3予約：`(148 - 146) × 4,000 = 8,000円`（買掛金確定額 `592,000円`）。
- 4決算：**仕訳なし**（為替予約により円額が確定済みのため、CR＝155円で評価替えしない）。

> **誤答パターン分析**：2仕入で5,000ドル全体に146円を掛けて仕入を730,000円とし、前払金140,000円との差額6,000円を無理やり為替差損益にしてしまうミス（前払金は非貨幣項目なので換算差額を出さない！）が多発します。

### 問3の解答と解説

```text
  ×1/11/1(発生)       ×1/12/1(予約)        ×2/3/31(決算)     ×2/5/31(決済)
----+-------------------+--------------------+-----------------+----->
  HR=140円           SR=143 / FR=149      |<--- 4ヶ月 --->|<--- 2ヶ月 --->|
  700,000            直々: +15,000 (即益)  直先: +30,000を6ヶ月で配分
                     直先: +30,000 (前受)  当期 +20,000 / 翌期 +10,000
```

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 予約(直々) | 売掛金 | 15,000 | 為替差損益 | 15,000 |
| 予約(直先) | 売掛金 | 30,000 | 前受収益 | 30,000 |
| 決算(配分) | 前受収益 | 20,000 | 為替差損益 | 20,000 |

- 1：直々差額 `(143 - 140) × 5,000 = 15,000円`（予約までの為替変動＝当期損益）。直先差額 `(149 - 143) × 5,000 = 30,000円`（予約日〜決済日の金利差相当＝前受収益として期間配分）。
- 2：**×1年度為替差益**：`15,000 + (30,000 × 4 / 6) = 35,000円`、**×2年度為替差益**：`30,000 × 2 / 6 = 10,000円`、**2年間合計**：**45,000円**（`745,000 - 700,000` と完全一致！）。

> **誤答パターン分析**：直先差額30,000円の月割起算点を「取引発生日（11/1）」からの7ヶ月としてしまうミス（正しくは「予約日（12/1）から決済日（5/31）の6ヶ月」で按分！）が典型です。
