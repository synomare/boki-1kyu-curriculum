## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

3級では「期末の帳簿在庫＝実地在庫」「期末在庫の単価＝取得原価そのまま」という理想的な前提で解いてきました。しかし現実の倉庫では、①盗難・紛失・蒸発等で帳簿より実物の数が減っている（**棚卸減耗**）、②型落ちや流行遅れで、1,000円で買った商品が900円でしか売れなくなっている（**収益性の低下**）、という2つの価値毀損が必ず起きます。

もしこれらを放置して「帳簿数量300個×取得原価1,000円＝300,000円」のままB/Sに載せたらどうなるでしょうか？
- **存在しない在庫の資産計上**：すでに紛失した20個をB/Sに資産として残す虚偽表示になる。
- **回収不能コストの翌期繰延**：900円でしか売れない商品を1,000円の資産として翌期へ繰り越せば、損失を翌期へ先送りすることになる。

したがって、棚卸資産の評価基準（企業会計基準第9号）は、**「正味売却価額（売価－見積販売経費）が取得原価より下落しているときは、収益性が低下したとみて正味売却価額まで切り下げる（低価法）」**ことを強制しています。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> A社（三分法、決算3月31日）の期首商品は 200,000円、当期仕入高は 1,000,000円、当期売上高は 1,500,000円であった。期末商品の内訳は以下のとおりである（減耗損・評価損はともに売上原価の内訳項目とする）。
> - 帳簿棚卸数量：300個（取得原価 ＠1,000円 ＝ 300,000円）
> - 実地棚卸数量：280個
> - 期末正味売却価額：＠900円

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 期首振替 | 仕入 | 200,000 | 繰越商品 | 200,000 |
| 期末計上 | 繰越商品 | 300,000 | 仕入 | 300,000 |
| 減耗・評価 | 棚卸減耗損 | 20,000 | 繰越商品 | 48,000 |
|  | 商品評価損 | 28,000 |  |  |
| 原価振替 | 仕入 | 48,000 | 棚卸減耗損 | 20,000 |
|  |  |  | 商品評価損 | 28,000 |

- **論理の核心（なぜ評価損は「実地数量280個」に掛けるのか）**：
  - 減耗した20個（20,000円）はそもそも倉庫に存在しないため、まず全額が「棚卸減耗損」として消える。今倉庫に**実在している280個**だけが単価1,000円から900円へ値下がりしているため、評価損は `(1,000 - 900) × 280個 = 28,000円` となる（300個に掛けると減耗20個分の損失を二重計上してしまう）。
- **最終数値**：B/S商品 `280個 × @900 = 252,000円`、P/L売上原価 `(200,000 + 1,000,000 - 300,000) + 48,000 = 948,000円`、売上総利益 `1,500,000 - 948,000 = 552,000円`。

### 【1級貫通・標準下書きフォーマット】

3級で習得した**型02（ボックス図型）**の右下に「減耗・評価の2段面積図」を直結させます。これが1級の売価還元法までそのまま使える最強の型です。

```text
  単価 ^
       |-----------------------------+-----+
1,000円|  B/S商品評価額              | 棚  |
       |  280個 × @900 = 252,000円   | 卸  |
  900円|-----------------------------| 減  | @1,000 × 20個
       |  商品評価損 (100×280)       | 耗  | = 20,000円
       |  = 28,000円                 | 損  |
       +-----------------------------+-----+--> 数量
       0                           280    300
```
- 検算等式：`B/S商品 252,000 + 評価損 28,000 + 減耗損 20,000 = 帳簿棚卸高 300,000円`（100%一致！）

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **L字型面積ボックスの描画**：必ず縦＝単価（取得原価 vs 正味売却価額）、横＝数量（実地 vs 帳簿）でL字図を描き、減耗損・評価損・B/S商品の3面積を分離する。
2. **評価益の計上禁止**：正味売却価額が取得原価を上回っている場合（`NRV > 原価`）、評価損はゼロ（切り上げは取得原価主義により禁止）。
3. **P/Lの表示区分**：問題文の指示に従い、原価性がある場合は「売上原価の内訳（仕入へ振替）」、原価性がない異常な減耗等は「販売費及び一般管理費（または営業外・特別損失）」とする。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-05`）**：多品種を扱う小売業・百貨店で用いる「**売価還元法**（売価ベースでボックス図を描き、原価率を掛けて期末在庫を出す手法）」へ進化し、原価率算定に値下額を含めるか（売価還元低価法）どうかという1級最頻出論点に繋がる。

## 4. 試験官の罠・混同しやすい論点の対比表

| 比較項目 | 棚卸減耗損 | 商品評価損 |
|---|---|---|
| 発生原因 | 数量の減少（盗難・紛失・破損） | 単価の下落（型落ち・陳腐化） |
| 計算式 | `(帳簿数量 － 実地数量) × 取得原価` | `(取得原価 － 正味売却価額) × 実地数量` |
| NRV ＞ 原価のとき | 実地が少なければ発生し得る | **発生しない（0円）** |
| P/L上の表示 | 売上原価 または 販管費等 | 原則として**売上原価**（臨時は特別損失） |

> **出題者の意図**：`NRV > 取得原価` の商品で評価益を計上させてしまう罠、およびA商品（評価損あり）とB商品（値上がり益あり）の2商品を合算して相殺させてしまう罠（低価法は原則として個別品目ごとに判定！）が定番です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（三分法、決算3月31日）の期首商品は 150,000円、当期仕入高は 850,000円、当期売上高は 1,200,000円であった。期末の帳簿棚卸数量は 200個（取得原価 ＠1,200円）、実地棚卸数量は 190個、期末正味売却価額は ＠1,100円であった。なお、棚卸減耗損および商品評価損はともに売上原価に算入する。
1. 決算整理仕訳（売上原価算定・減耗/評価・原価振替）を示せ。
2. 期末B/Sの**商品**、P/Lの**売上原価**および**売上総利益**を求めよ。

### 問2（本試験標準・ひっかけ対応）
乙社はA商品とB商品の2種類を取り扱っている。期末（3月31日）のデータは以下のとおりである。棚卸減耗損は「A商品は販売費及び一般管理費（原価性なし）、B商品は売上原価の内訳（原価性あり）」とし、商品評価損は売上原価の内訳とする。
- **A商品**：帳簿 100個（＠2,000円）、実地 95個、期末正味売却価額 ＠1,800円
- **B商品**：帳簿 100個（＠1,500円）、実地 98個、期末正味売却価額 ＠1,700円
1. A商品・B商品それぞれの**棚卸減耗損**と**商品評価損**を求めよ。
2. 期末B/Sに計上される**商品合計額**、およびP/L上で**売上原価に算入される減耗・評価損の合計額**と**販管費に計上される額**をそれぞれ求めよ。

### 問3（1級視点・応用思考）
丙社（決算3月31日）の期末帳簿棚卸高は 500個（取得原価 ＠1,000円 ＝ 500,000円）であった。期末における予想販売価格は ＠1,100円であるが、販売にあたって1個あたり ＠180円 の荷造発送費・販売手数料がかかる見込みである。実地棚卸を行った結果、期末B/Sに計上すべき商品の評価額が **441,600円** となった。
1. 1個あたりの**正味売却価額（NRV）**を求めよ。
2. **実地棚卸数量 X個**、**棚卸減耗損**、および **商品評価損** をそれぞれ逆算せよ。
3. なぜ商品評価損を「帳簿数量500個」ではなく「実地数量 X個」に掛けて計算しなければならないのか、1〜2行で説明せよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 期首振替 | 仕入 | 150,000 | 繰越商品 | 150,000 |
| 期末計上 | 繰越商品 | 240,000 | 仕入 | 240,000 |
| 減耗・評価 | 棚卸減耗損 | 12,000 | 繰越商品 | 31,000 |
|  | 商品評価損 | 19,000 |  |  |
| 原価振替 | 仕入 | 31,000 | 棚卸減耗損 | 12,000 |
|  |  |  | 商品評価損 | 19,000 |

- 棚卸減耗損：`(200 - 190) × 1,200 = 12,000円`
- 商品評価損：`(1,200 - 1,100) × 190 = 19,000円`
- **B/S商品**：`190 × 1,100 = 209,000円`（検算：`240,000 - 31,000 = 209,000円`）
- **P/L売上原価**：`(150,000 + 850,000 - 240,000) + 31,000 = 791,000円`
- **P/L売上総利益**：`1,200,000 - 791,000 = 409,000円`

> **誤答パターン分析**：商品評価損を帳簿数量200個に掛けて20,000円としてしまうミス（1,000円二重計上）が最も頻出します。

---

### 問2の解答と解説

```text
  【A商品】                        【B商品 (NRV 1,700 > 原価 1,500)】
  減耗: (100-95)×2,000 = 10,000     減耗: (100-98)×1,500 = 3,000
  評価: (2,000-1,800)×95 = 19,000   評価: 0円 (切り上げ禁止！)
  B/S : 95 × 1,800 = 171,000        B/S : 98 × 1,500 = 147,000
```

1. **A商品**：棚卸減耗損 10,000円、商品評価損 19,000円。**B商品**：棚卸減耗損 3,000円、商品評価損 **0円**。
2. **B/S商品合計**：`171,000 + 147,000 = 318,000円`
   - **売上原価算入額**：`A評価損 19,000 + B減耗損 3,000 = 22,000円`
   - **販管費計上額**：`A減耗損 10,000円`

> **誤答パターン分析**：B商品の `NRV 1,700 > 原価 1,500` を用いて評価益19,600円を計上し、A商品の評価損と相殺してしまう誤答が典型です。

### 問3の解答と解説

1. **正味売却価額（NRV）**：`予想販売価格 1,100 - 見積販売経費 180 = @920円`
2. **実地数量 X と減耗・評価損**：
   - B/S商品計上額は `実地数量 X × NRV @920 = 441,600円` より、**X ＝ 480個**（`441,600 ÷ 920`）。
   - **棚卸減耗損**：`(500 - 480) × 1,000 = 20,000円`
   - **商品評価損**：`(1,000 - 920) × 480 = 38,400円`
   - 検算：`441,600 + 20,000 + 38,400 = 500,000円`（帳簿額と一致！）
3. **実地数量に掛ける理由**：減耗した20個はすでに現存せず「棚卸減耗損（＠1,000円）」として全額費用処理されるため、単価下落の評価損は実在する480個に対してのみ認識しないと損失が二重計上されるから。

> **誤答パターン分析**：正味売却価額の算定時に見積販売経費180円を引き忘れて予想売価1,100円のまま判定してしまうミスが多発します。
