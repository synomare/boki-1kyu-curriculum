## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

かつての収益認識は「出荷したから売上（実現主義）」といった慣行に頼っており、同じような取引でも会社によって売上計上のタイミングや金額がバラバラでした。たとえば「パソコンと2年間の保守サポート」をセットで販売したのに、引渡初日に全額を売上にしてしまったら、今後2年間タダ働きする義務（負債）を隠して利益を前倒しすることになります。

そこで現行の**収益認識に関する会計基準（企業会計基準第29号）**は、次の**5ステップ**により「約束した財・サービスの**支配が顧客に移転した時点**で、権利を得ると見込む対価の額」を収益認識します。
1. 契約の識別 → 2. **履行義務の識別**（別個の商品や保守サービスを分ける） → 3. 取引価格の算定 → 4. **取引価格の配分**（独立販売価格の比率等で配分） → 5. **履行義務の充足による収益認識**（一時点 vs 一定の期間）。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **返品権付販売**：商品100個（売価計 100,000円、原価計 60,000円）を掛け販売した。過去の経験から10%（10個）の返品が見込まれる（売上原価対立法）。その後、実際に8個が返品され売掛金を減額し、残りの返品権利期間は消滅した。
> 2. **契約資産**：顧客と「商品A（400,000円）と商品B（600,000円）の2点すべてを引き渡したときに代金1,000,000円を請求できる」契約を結び、まず商品Aだけを引き渡した（売上原価は省略）。
> 3. **役務収益・役務原価**：×1年10月1日に保守サービス1年契約（受取額 240,000円、年間見積原価 120,000円）を結び、全額を普通預金で受け取った。×2年3月31日決算（6ヶ月経過、発生原価60,000円・現金払）の仕訳を示せ。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①販売 | 売掛金 | 100,000 | 売上 | 90,000 |
|  |  |  | 返金負債 | 10,000 |
|  | 売上原価 | 54,000 | 商品 | 60,000 |
|  | 返品資産 | 6,000 |  |  |
| ①返品 | 返金負債 | 8,000 | 売掛金 | 8,000 |
|  | 商品 | 4,800 | 返品資産 | 4,800 |
| ①期間満了 | 返金負債 | 2,000 | 売上 | 2,000 |
|  | 売上原価 | 1,200 | 返品資産 | 1,200 |
| ②A引渡 | 契約資産 | 400,000 | 売上 | 400,000 |
| ②B引渡 | 売掛金 | 1,000,000 | 契約資産 | 400,000 |
|  |  |  | 売上 | 600,000 |
| ③契約時 | 普通預金 | 240,000 | 契約負債 | 240,000 |
| ③原価発生 | 仕掛品 | 60,000 | 現金 | 60,000 |
| ③決算 | 契約負債 | 120,000 | 役務収益 | 120,000 |
|  | 役務原価 | 60,000 | 仕掛品 | 60,000 |

- **①の論理**：返品見込10%分（売価10,000円）は実質的に返す義務があるため売上とせず**返金負債（負債）**とし、対応する原価6,000円は取り戻せる権利として**返品資産（資産）**とする。最終的に返品されなかった2個分は期間満了時に売上・原価へ確定させる（最終粗利 `92,000 - 55,200 = 36,800円`）。
- **②の論理**：Aを引き渡した時点で履行義務は充足（売上400,000）したが、Bを引渡すまで代金を請求する無条件の権利がないため、売掛金ではなく**契約資産**とする。
- **③の論理**：保守契約のように一定の期間にわたり充足される履行義務は、前受額を**契約負債**にプールし、期間経過（6/12）に応じて**役務収益**へ振り替え、発生した作業原価（仕掛品）を**役務原価**へ対応させる。

### 【1級貫通・標準下書きフォーマット】

型01（タイムライン型）と型03（T勘定連結型）で契約負債・返金負債の消込を管理します。

```text
  【返品権付販売のフロー】
  販売100個 ──(90個確定)──> 売上 90,000 / 売上原価 54,000
      └────(10個見込)──> 返金負債 10,000 / 返品資産 6,000
                            ├─ 実際返品 8個: 売掛金・商品と相殺
                            └─ 非返品   2個: 売上+2,000 / 原価+1,200
```

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（2級）】
1. **契約資産・契約負債・売掛金の3区別**：対価を受取る無条件の権利＝売掛金、条件付き権利＝契約資産、対価受取済で未履行＝契約負債。
2. **返品権付販売**：返金負債（売価）と返品資産（原価）の両建て、実際返品時・期間満了時の精算。
3. **役務収益・役務原価**：サービス提供原価を「仕掛品」で集計し、収益認識と同時に「役務原価」へ振り替える対応原則。

### 【未来の拡張フック（1級への伏線・一読でOK）】
- **1級への接続（`L1C-05`）**：5ステップがさらに深まり、リベート等の「**変動対価**」、手数料のみ売上計上する「**本人と代理人の区分**」、顧客ポイント付与の「**契約負債への配分**」、長期分割払の「**重要な金融要素（割引現在価値）**」へと発展する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 勘定科目 | 経済的実態 | B/S区分 |
|---|---|---|
| **売掛金** | 時の経過のみで支払いを受けられる**無条件の権利** | 流動資産 |
| **契約資産** | 他の履行義務（商品B引渡等）を果たして初めて請求できる**条件付権利** | 流動資産 |
| **契約負債** | すでに対価を受け取ったが、まだ財・サービスを引き渡していない義務 | 流動負債 |

> **出題者の意図**：商品Aのみ引き渡した段階（B引渡が代金請求条件）で「売掛金」を使ってしまう罠、および返品権付販売で返品資産を「売価」で計上してしまう罠が頻出です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算3月31日）の以下の収益認識取引について、一連の仕訳を示せ（売上原価は考慮外、または指示どおり処理）。
1. 商品A（独立販売価格 300,000円）と商品B（同 500,000円）の2点を引き渡して初めて代金 800,000円を請求できる契約を結び、まず商品Aを引き渡した。その後、商品Bを引き渡し、代金請求権が確定した（A引渡時・B引渡時の2本）。
2. 顧客から注文を受け、手付金 150,000円を普通預金で受け取った。その後、商品 500,000円を引き渡し、手付金を充当した残額は掛けとした（受取時・引渡時の2本）。
3. ×1年12月1日に1年間のシステム保守契約（対価 360,000円）を結び、全額を普通預金で受け取った。当期中に保守作業原価 60,000円を現金で支出し、×2年3月31日（4ヶ月経過）に決算を迎えた（契約時・原価支出時・決算時の仕訳を示せ）。

### 問2（本試験標準・ひっかけ対応）
乙社（売上原価対立法）は、商品200個（売価計 400,000円、原価計 240,000円）を掛け販売した。過去の統計から返品率は5%（10個）と見込まれる。その後、返品可能期間内に実際に **12個** が返品されて売掛金を減額し、返品可能期間が満了した。販売時・実際返品時・期間満了時の仕訳をすべて示し、この取引による最終的な**売上高・売上原価・売上総利益**を求めよ。

### 問3（1級視点・応用思考）
丙社（決算3月31日）は従来「出荷基準」で売上を計上していたが、当期末（×2年3月31日）に「顧客の検収時点で支配が移転する契約（検収基準）」へ正しく整理することとした。×2年3月30日に商品（売価 500,000円、原価 300,000円）を出荷し、誤って当期の売掛金・売上（および売上原価対立法により売上原価・商品減少）を計上していたが、実際の顧客検収日は×2年4月2日であった。
1. 当期末（×2年3月31日）に行うべき**修正仕訳**を示し、この修正によって当期の**売上総利益はいくら増減するか**答えよ。
2. 「出荷しただけでは収益を認識してはならない（契約条件により検収基準となる）」理由を、収益認識会計基準のキーワードである「支配の移転」を用いて2行以内で説明せよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1 A引渡 | 契約資産 | 300,000 | 売上 | 300,000 |
| 1 B引渡 | 売掛金 | 800,000 | 契約資産 | 300,000 |
|  |  |  | 売上 | 500,000 |
| 2 受取 | 普通預金 | 150,000 | 契約負債 | 150,000 |
| 2 引渡 | 契約負債 | 150,000 | 売上 | 500,000 |
|  | 売掛金 | 350,000 |  |  |
| 3 契約 | 普通預金 | 360,000 | 契約負債 | 360,000 |
| 3 支出 | 仕掛品 | 60,000 | 現金 | 60,000 |
| 3 決算 | 契約負債 | 120,000 | 役務収益 | 120,000 |
|  | 役務原価 | 60,000 | 仕掛品 | 60,000 |

- 3決算：12/1〜3/31の4ヶ月経過 `360,000 × 4 / 12 = 120,000円`

> **誤答パターン分析**：取引2で3級の「前受金」のまま書いてしまうケースや、取引3で作業支出時に「仕掛品」を使わず即時に「役務原価」や「給料」にしてしまい、決算での費用収益対応が崩れるケースが定番です。

### 問2の解答と解説

```text
  販売200個 ─┬─ 190個(確定) -> 売上 380,000 / 原価 228,000
             └─  10個(見込) -> 返金負債 20,000 / 返品資産 12,000
                  実際返品12個: 10個は返金負債・返品資産と相殺
                                超過2個は売上-4,000 / 原価-2,400で直接取消
```

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 販売時 | 売掛金 | 400,000 | 売上 | 380,000 |
|  |  |  | 返金負債 | 20,000 |
|  | 売上原価 | 228,000 | 商品 | 240,000 |
|  | 返品資産 | 12,000 |  |  |
| 実際返品 | 返金負債 | 20,000 | 売掛金 | 24,000 |
|  | 売上 | 4,000 |  |  |
|  | 商品 | 14,400 | 返品資産 | 12,000 |
|  |  |  | 売上原価 | 2,400 |

※実際返品が12個（売価24,000円、原価14,400円）であり、見積の10個を2個上回っているため、超過2個分は売上・売上原価を直接減額し、期間満了時の追加仕訳は不要（返金負債・返品資産は0）。
- **最終売上高**：`380,000 - 4,000 = 376,000円`（188個×@2,000）
- **最終売上原価**：`228,000 - 2,400 = 225,600円`（188個×@1,200）
- **最終売上総利益**：`376,000 - 225,600 = 150,400円`

> **誤答パターン分析**：実際返品12個が見積10個を上回ったときに、返金負債をマイナス残高にしたり、超過2個の原価2,400円を売上原価から引き忘れるミスが多発します。

### 問3の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 修正 | 売上 | 500,000 | 売掛金 | 500,000 |
|  | 商品 | 300,000 | 売上原価 | 300,000 |

1. **売上総利益の増減**：売上500,000円が取り消され、売上原価300,000円が戻されるため、**売上総利益は 200,000円 減少**する（誤って200,000円過大計上されていた）。
2. **支配の移転による理由**：検収基準の契約では、顧客が検収を完了して商品を使用・収益できる能力を獲得した時点（4月2日）で初めて商品に対する支配が顧客に移転するため、3月30日の出荷時点では履行義務は充足されていない。

> **誤答パターン分析**：売上500,000円だけを取り消して「売上原価300,000円の取消（商品の戻し）」を忘れ、利益が500,000円減少すると誤答するケースが定番です。
