## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

株式会社は「株主が拠出した元手（**払込資本＝資本金等**）」と「事業で稼いで会社に貯めた利益（**留保利益＝繰越利益剰余金等**）」を厳格に区別します。もし会社が「株主への配当金」を費用に混ぜたり、逆に「株主からの出資」を売上に混ぜたらどうなるでしょうか？
- **元手と稼ぎの混同**：投資家は「この会社が本業でいくら稼いだか」と「株主が追加出資しただけか」を区別できなくなる。
- **債権者保護の破綻**：株式会社の株主は有限責任であるため、会社が利益をすべて配当で社外流出させると銀行などの債権者が回収不能に陥る。そのため会社法は、配当のたびに一定額を「**利益準備金**」として社内に強制積立させる（配当制限）。

また税金面では、法人の儲けに課される**法人税等**（企業の費用）と、消費者が負担し企業が預かって国へ納める**消費税**（税抜方式＝企業の損益に影響しない預り債務）を明確に区別することが不可欠です。

### 会社法・税制の背景と実務の現場（なぜこのルールがあるのか）
- **利益準備金「配当の1/10・資本金の1/4」の会社法背景**：個人商店なら借金は店主個人の全財産で返しますが、株式会社は「株主有限責任（出資額以上は責任を負わない）」です。もし会社が稼いだ利益をすべて配当で株主に配りきった直後に業績が悪化したら、銀行や取引先が大損します。そのため会社法（第445条第4項）は、配当という社外流出を行うたびに「その1/10を資本金の1/4に達するまで会社内に強制ロック（準備金積立）せよ」と定めているのです。
- **インボイス制度と消費税「税抜方式」が実務標準である理由**：もし売上や仕入に消費税10%を混ぜて記帳する「税込方式」を使うと、免税事業者との取引や軽減税率（8%と10%の混在）が起きた際にP/L上の売上高・粗利率が歪みます。インボイス制度下の上場企業・多くの課税事業者の実務では、預り税と支払税を「仮受消費税」「仮払消費税」として切り離し、**本業の純粋な売上・粗利を正確に測れる税抜方式**が標準採用されています。
- **投資家の目線**：投資家は「税引前当期純利益」と「法人税等」の比率（実質的な税負担率）を見ることで、特別に税金が軽くなっている一時的要因がないか（来期以降の当期純利益が持続するか）を分析します。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **設立・増資**：A社は株式を発行し、株主から払込金 5,000,000円が普通預金に入金された（全額を資本金とする）。
> 2. **剰余金の配当**：株主総会において、繰越利益剰余金から配当金 400,000円（後日支払＝未払配当金）および利益準備金 40,000円（配当額の1/10）を積み立てる決議を行った。
> 3. **法人税等**：期中に中間納付 150,000円を普通預金から支払い、決算で当期の法人税等が 420,000円と確定した。
> 4. **消費税（税抜方式）**：当期の仮受消費税は 50,000円、仮払消費税は 30,000円であった。決算時に納付額を確定する。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①増資 | 普通預金 | 5,000,000 | 資本金 | 5,000,000 |
| ②配当 | 繰越利益剰余金 | 440,000 | 未払配当金 | 400,000 |
|  |  |  | 利益準備金 | 40,000 |
| ③中間 | 仮払法人税等 | 150,000 | 普通預金 | 150,000 |
| ③決算 | 法人税、住民税及び事業税 | 420,000 | 仮払法人税等 | 150,000 |
|  |  |  | 未払法人税等 | 270,000 |
| ④決算 | 仮受消費税 | 50,000 | 仮払消費税 | 30,000 |
|  |  |  | 未払消費税等 | 20,000 |

- **②の論理**：配当400,000円は株主への還元義務「未払配当金（負債＋）」、40,000円は会社法により社内にロックされた「利益準備金（純資産＋）」。原資はいずれも「繰越利益剰余金（純資産－）」。
- **③の論理**：期中の中間納付は税額確定前の前払ゆえ「仮払法人税等（資産＋）」。決算で年間税額420,000円が確定した瞬間に全額を「法人税、住民税及び事業税（費用＋）」とし、中間分150,000円を差し引いた残額270,000円を「未払法人税等（負債＋）」とする。
- **④の論理（税抜方式）**：顧客から預かった消費税50,000円（仮受＝負債）から、仕入等で支払った消費税30,000円（仮払＝資産）を差し引き、正味の納付義務20,000円を「未払消費税等（負債＋）」とする。**P/Lの利益には1円も影響しない**。

### 💡 独学者が必ず抱く「なぜ？」徹底Q&A

- **Q1：なぜ「法人税、住民税及び事業税」は、給料や固定資産税と同じ「販売費及び一般管理費」に入れないのですか？**
  - **A**：固定資産税や印紙税（租税公課）は「会社が事業を営むために必要なコスト」なので営業利益を計算する段階で差し引きます。一方、法人税等は「事業で利益が出た結果として、最後に国や自治体へ納める分け前」であるため、営業利益や経常利益をすべて計算し終えた後の「税引前当期純利益」の直下に独立して表示します。
- **Q2：配当をするとき、なぜ現金が減っていないのに「未払配当金（負債）」にするのですか？**
  - **A**：株主総会で「配当を払う」と決議した日（効力発生日）と、実際に株主の銀行口座へ振り込む日は別の日になるのが通常だからです。決議した瞬間に会社は株主に対して「配当金を支払う法的な義務（負債）」を負うため、まず「未払配当金」を計上し、後日振り込んだときに消去します。
- **Q3：「仮払法人税等」が確定税額より多かった場合（例：中間納付20万円、年税額15万円）はどうなりますか？**
  - **A**：税金を5万円払いすぎた状態なので、税務署から返してもらう権利（資産）として「**未収還付法人税等** 50,000円」を借方に計上します（消費税で仮払＞仮受になった場合も同様に「未収還付消費税」となります）。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（3級）】
1. **純資産の増資・配当仕訳**：繰越利益剰余金の取り崩しと利益準備金（配当の1/10）の積立。
2. **法人税等の中間納付・確定**：仮払法人税等と未払法人税等の精算（還付なら未収還付法人税等）。
3. **消費税の税抜方式**：仮受と仮払の相殺（納付なら未払消費税等、還付なら未収還付消費税）。
4. **租税公課との区別**：固定資産税・印紙税・自動車税は「租税公課（販管費）」、法人税等は「法人税、住民税及び事業税（税引前利益の下）」。

### 【未来の拡張フック（2級・1級への伏線・一読でOK）】
- **2級への接続（`L2C-09`, `L2C-10`）**：資本金と利益準備金の合計が「資本金の1/4」に達するまでの上限ルール、株主資本等変動計算書（S/S）、そして会計上の利益と税務上の所得のズレを調整する「**税効果会計（繰延税金資産・負債）**」へ進化する。
- **1級への接続（`L1C-10`, `L1C-11`）**：自己株式の取得・処分・消却、新株予約権・ストック・オプション、会社法上の「分配可能額」の厳密計算へと発展する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 税金の種類 | 経済的性格 | P/L上の表示区分 | 決算時の未払/還付勘定 |
|---|---|---|---|
| **法人税・住民税・事業税** | 会社の利益に対する課税 | **税引前当期純利益の直下** | 未払法人税等 / 未収還付法人税等 |
| **固定資産税・印紙税等** | 資産保有や契約に伴うコスト | **販売費及び一般管理費（租税公課）** | 未払金 等 |
| **消費税（税抜方式）** | 最終消費者が負担する預り税 | **P/Lに一切登場しない** | 未払消費税等 / 未収還付消費税 |

> **出題者の意図**：固定資産税を「法人税、住民税及び事業税」に混ぜる罠、および期中に中間納付した法人税150,000円を引き忘れて決算時に確定額420,000円をそのまま「未払法人税等」にしてしまう罠が定番です。

## 5. 思考力ドリル（問題編）

甲社の当期における以下の純資産・税金取引について仕訳を示せ。
1. 株式を追加発行し、払込金額 2,000,000円が普通預金に入金された（会社法上の最低限度額ではなく、全額を資本金とする）。
2. 株主総会にて、繰越利益剰余金から「株主配当金 300,000円（未払）、利益準備金 30,000円、別途積立金 200,000円」を処分・積立する決議を行った。
3. 法人税等について、期中に中間納付額 180,000円を普通預金から支払い、決算時に当期の確定税額が 520,000円と算定された（中間時・決算時の2本）。
4. 消費税（税抜方式）について、決算時に仮受消費税 95,000円と仮払消費税 60,000円を精算した。

### 問2（本試験標準・ひっかけ対応）
乙社（決算3月31日）における以下の4取引について仕訳を示せ（なお、4.については2級の1/4上限ルールも意識した実戦的設定である）。
1. 事業用土地・建物の固定資産税 80,000円を普通預金から納付した。
2. 法人税等の中間納付額 250,000円（仮払法人税等）に対し、決算時の確定税額は 190,000円であった（差額は後日還付される）。
3. 消費税（税抜方式）について、仮払消費税 420,000円、仮受消費税 310,000円であったため、決算精算を行った。
4. 株主総会で配当金 300,000円を決議した。なお、乙社の資本金は 1,000,000円、既存の資本準備金は 150,000円、利益準備金は 80,000円である（会社法の規定により、準備金合計が資本金の1/4に達するまで配当の1/10を積み立てる）。

丙社は年間で商品を税抜 600,000円（消費税10%＝60,000円）で現金仕入し、税抜 1,000,000円（消費税10%＝100,000円）で現金販売した（他の費用はゼロ、期末在庫もゼロ）。

### 問2の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1 | 租税公課 | 80,000 | 普通預金 | 80,000 |
| 2 | 法人税、住民税及び事業税 | 190,000 | 仮払法人税等 | 250,000 |
|  | 未収還付法人税等 | 60,000 |  |  |
| 3 | 仮受消費税 | 310,000 | 仮払消費税 | 420,000 |
|  | 未収還付消費税 | 110,000 |  |  |
| 4 | 繰越利益剰余金 | 320,000 | 未払配当金 | 300,000 |
|  |  |  | 利益準備金 | 20,000 |

- 取引4の積立上限：`資本金 1,000,000 × 1/4 = 250,000円`。既存準備金合計 `150,000 + 80,000 = 230,000円` ゆえ、残枠は `250,000 - 230,000 = 20,000円`。配当の1/10（30,000円）と残枠（20,000円）のいずれか小さい方である **20,000円** のみを積み立てる。

> **誤答パターン分析**：取引2・3で還付（取り戻す権利＝資産）になるべきところを「未払」のままマイナス処理したり、取引4で既存準備金の上限20,000円を見落として30,000円積み立ててしまうミスが定番です。

### 問3の解答と解説

#### (1) 税抜方式の仕訳とP/L

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 仕入 | 仕入 | 600,000 | 現金 | 660,000 |
|  | 仮払消費税 | 60,000 |  |  |
| 売上 | 現金 | 1,100,000 | 売上 | 1,000,000 |
|  |  |  | 仮受消費税 | 100,000 |
| 決算 | 仮受消費税 | 100,000 | 仮払消費税 | 60,000 |
|  |  |  | 未払消費税等 | 40,000 |

- **税抜方式P/L**：売上高 1,000,000円 − 売上原価 600,000円 ＝ 売上総利益 400,000円 ＝ **営業利益 400,000円**

#### (2) 税込方式のP/Lと一致理由
- **税込方式P/L**：売上高 1,100,000円 − 売上原価 660,000円 ＝ 売上総利益 440,000円 − 租税公課（納付消費税）40,000円 ＝ **営業利益 400,000円**
- **一致理由**：税込方式では売上高（+100,000）と仕入（+60,000）の差額40,000円だけ売上総利益が膨らむが、同額の40,000円が販管費の「租税公課」として差し引かれるため、最終的な営業利益は税抜方式と完全に一致する（ただし売上総利益等の段階利益は消費税の影響で歪むため、原則は税抜方式が望ましい）。

> **誤答パターン分析**：税込方式の納付消費税40,000円を「法人税、住民税及び事業税」と混同し、営業利益が440,000円になると誤解するケースが見られます。
