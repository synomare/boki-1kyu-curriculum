## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

商店やメーカーが商品を100,000円で購入（仕入）した瞬間、企業は損をしたでしょうか？ いいえ、**現金という「資産」が、同じ100,000円の価値を持つ商品（将来のキャッシュ獲得能力＝資産）に姿を変えただけ（等価交換）**です。この時点では利益も損失も1円も発生していません。

価値の消費（費用）が起きるのは、その商品が**顧客に引き渡されて「売上（収益）」が実現した瞬間**です。

もし企業が「仕入れた瞬間に全額を費用（損）」にして期末在庫を無視したり、逆に「売れたのに在庫を資産のまま残して（期末在庫を水増しして）」決算書を作ったらどうなるでしょうか？
- **仕入時全額費用処理の罠**：期末に大量の売れ残り在庫を抱えていても費用が過大になり、利益が不当に圧縮される（あるいは翌期に在庫を売ると原価ゼロの異常な利益が出る）。
- **期末在庫水増しの罠**：本来は顧客に渡って消滅した在庫をB/Sに資産として残すことで、売上原価が不当に減り、架空の利益がP/Lに計上される（粉飾決算の最も古典的な手口であり、投資家や銀行を直接欺く行為になる）。

したがって、商品売買の会計は、以下の会計理論から必然的に導かれます。
1. **費用収益対応の原則**：当期に実現した「売上高（収益）」に対して、その売上を獲得するために犠牲となった商品の原価だけを「売上原価（費用）」として対応させる。
2. **取得原価主義**：商品を購入するために直接要した付随費用（引取運賃など）は、商品という資産を取得するための不可避な犠牲であるため、商品の取得原価に算入する。
3. **資産負債アプローチとの整合**：期末時点で倉庫に実在し支配している在庫だけが「将来の経済的便益＝資産（商品）」であり、すでに顧客へ支配が移転した在庫は資産から取り崩して費用化する。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

商品売買の記帳方法には、**「売上原価対立法」**（2027年4月改定で3級に標準追加）と**「三分法」**の2つがあります。アプローチ（記帳のタイミング）は異なりますが、**最終的なB/S（期末商品）とP/L（売上高・売上原価・売上総利益・営業利益）は1円の狂いもなく完全に一致**します。

ここでは、以下の**並走例題**を用いて両者の論理導出を比較します。

> **【並走例題】**
> - 期首商品棚卸高：100個 × ＠1,000円 ＝ 100,000円
> - 取引①（仕入）：商品200個を＠950円（計190,000円）で掛け仕入し、当社負担の引取運賃10,000円を現金で支払った。（取得原価合計 200,000円、1個あたり＠1,000円）
> - 取引②（売上）：商品240個を＠1,500円（計360,000円）で掛け販売し、当社負担の発送費5,000円を現金で支払った。（販売した商品の原価は 240個 × ＠1,000円 ＝ 240,000円）
> - 決算（期末在庫）：実地棚卸の結果、期末商品は 60個（＠1,000円 ＝ 60,000円）であった。

### (1) 売上原価対立法の仕訳導出（経済的実態に最も忠実な方法）

売上原価対立法は、**「仕入＝資産（商品）の増加」「販売＝資産（商品）の減少と費用（売上原価）の発生」**を取引のつどリアルタイムに記録する方法です。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①仕入 | 商品 | 190,000 | 買掛金 | 190,000 |
|  | 商品 | 10,000 | 現金 | 10,000 |
| ②売上 | 売掛金 | 360,000 | 売上 | 360,000 |
|  | 売上原価 | 240,000 | 商品 | 240,000 |
|  | 発送費 | 5,000 | 現金 | 5,000 |

- **取引①の論理**：本体190,000円＋当社負担の引取運賃10,000円＝計200,000円は、倉庫に届くまでの不可避な犠牲であり、すべて「商品（資産）」の増加（借方）となる。対価は将来の支払義務「買掛金（負債）」の増加（貸方）と「現金（資産）」の減少（貸方）。
- **取引②の論理**：売価側では代金請求権「売掛金（資産）」の増加と「売上（収益）」の発生を認識する。同時に原価側では、240,000円分の在庫が倉庫から顧客へ移転したため「商品（資産）」を減少し（貸方）、同額の経済的犠牲「売上原価（費用）」を発生させる（借方）。発送費は販売活動に伴う費用であり、商品の取得原価ではないため独立した販管費「発送費（費用）」とする。
- **決算整理**：期中においてすでに商品勘定の残高が `100,000 + 200,000 - 240,000 = 60,000円`、売上原価勘定が `240,000円` に自動確定しているため、**売上原価算定のための決算整理仕訳は不要**である。

### (2) 三分法の仕訳導出（期中は簡便に記録し、決算で一括整理する方法）

三分法は、期中の販売のたびに原価を調べる手間を省くため、期中の仕入を暫定的に「仕入（費用）」にプールしておき、**決算時に在庫の増減を一括で調整する**方法です。（※「繰越商品」「仕入」「売上」の3勘定を使うため三分法と呼びます）

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①仕入 | 仕入 | 190,000 | 買掛金 | 190,000 |
|  | 仕入 | 10,000 | 現金 | 10,000 |
| ②売上 | 売掛金 | 360,000 | 売上 | 360,000 |
|  | 発送費 | 5,000 | 現金 | 5,000 |
| 決算① | 仕入 | 100,000 | 繰越商品 | 100,000 |
| 決算② | 繰越商品 | 60,000 | 仕入 | 60,000 |

無意味な語呂合わせ暗記を捨て、決算①・②の論理を5要素で理解してください。
- **決算①（期首在庫の投入）**：前期から持ち越した「繰越商品（資産）100,000円」も当期に販売可能な商品プールの一部であるため、資産から取り崩し（貸方：繰越商品）、当期の商品プールである「仕入（費用）100,000円」へ合算（借方：仕入）する。この時点で仕入勘定の残高は `100,000 + 200,000 = 300,000円`（販売可能商品の総額）となる。
- **決算②（期末在庫の資産への引き抜き）**：実地棚卸で判明した売れ残り60,000円は、当期に消費されず翌期にキャッシュを生む「資産」であるため、当期の費用プールである「仕入（費用）」から控除し（貸方：仕入）、B/S資産である「繰越商品（資産）」へ計上（借方：繰越商品）する。結果として、仕入勘定の最終残高は `300,000 - 60,000 = 240,000円`（売上原価）に一致する。

### 【1級貫通・標準下書きフォーマット】

商品売買および原価計算では、**型02（ボックス図型）**と**型03（T勘定連結型）**を組み合わせて解きます。

**ステップ1：型02（ボックス図）を描き、投入＝産出の保存則で全数値を確定する**

```text
+-----------------------------------+-----------------------------------+
|  期首商品      100個    100,000円 |  売上原価      240個    240,000円 |
|               (@1,000)            |               (@1,000)            |
|  当期純仕入    200個    200,000円 |  期末商品       60個     60,000円 |
|  (引取運賃込) (@1,000)            |               (@1,000)            |
+-----------------------------------+-----------------------------------+
|  借方合計      300個    300,000円 |  貸方合計      300個    300,000円 |
+-----------------------------------+-----------------------------------+
```

**ステップ2：型03（T勘定連結）で勘定間の価値フローを確認する**

```text
【売上原価対立法の勘定フロー】
     [ 商品 (資産) ]                     [ 売上原価 (費用) ]
  -----------+-----------             -----------+-----------
  期首 100,000| 売上240,000  =====>   振替 240,000| 損益 240,000
  仕入 200,000| (期末 60,000)

【三分法の勘定フロー】
    [ 繰越商品 (資産) ]                     [ 仕入 (費用→売上原価) ]
  -----------+-----------             -----------+-----------
  期首 100,000| 決算①100,000 =====>  決算①100,000| 決算② 60,000
  決算②60,000| (期末 60,000)         期中 200,000| (原価 240,000)
```

**ステップ3：手順の固定化（3級〜1級共通プロトコル）**
1. まず取引の「仕入諸掛（当社負担）」を本体価格に合算し、正しい単位原価・当期純仕入高を確定する。
2. 型02（ボックス図）の左側（期首＋当期純仕入）と右側（売上原価＋期末商品）を埋め、**左辺合計 ＝ 右辺合計**を検算する。
3. 問題が「三分法」か「売上原価対立法」かを確認し、勘定科目名と決算整理の有無を切り替える。
4. 最終検算：`売上高 360,000 － 売上原価 240,000 ＝ 売上総利益 120,000円`、`売上総利益 120,000 － 発送費 5,000 ＝ 営業利益 115,000円`（両法完全一致）。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（3級）】
1. **三分法と売上原価対立法の自由な切り替え**：同じ取引を見ても、両方の仕訳を即座に書け、最終のB/S・P/Lが一致することを理解している状態。
2. **付随費用の切り分け**：仕入諸掛（当社負担）は商品原価へ算入、発送費（当社負担）は独立した販管費、先方負担の立替は売掛金・買掛金の調整（または立替金）として即判別。
3. **返品・値引とクレジット売掛金**：返品（在庫が戻る）と値引（在庫は戻らない）の区別、クレジット販売時の手数料処理。
4. **ボックス図の徹底**：`期首 ＋ 当期純仕入 ＝ 売上原価 ＋ 期末` の4要素のうち3つが分かれば残り1つを瞬時に逆算できること。

## 4. 試験官の罠・混同しやすい論点の対比表

### 対比表①：三分法 vs 売上原価対立法

| 比較項目 | 三分法 | 売上原価対立法 |
|---|---|---|
| 仕入時の借方勘定 | `仕入`（費用勘定に暫定プール） | `商品`（資産勘定に直接計上） |
| 販売時の原価仕訳 | **なし**（売価の仕訳のみ） | **あり**（`売上原価 / 商品` を都度計上） |
| 売上返品時の原価仕訳 | **なし**（`売上 / 売掛金` のみ） | **あり**（`商品 / 売上原価` で在庫と原価を戻す） |
| 売上値引時の原価仕訳 | なし | **なし**（在庫は戻らないため原価は動かない） |
| 決算整理仕訳 | **必須**（期首振替・期末計上） | **原則不要**（残高がすでに確定済み） |
| P/L上の表示科目 | `売上原価`（仕入勘定残高を集計） | `売上原価`（売上原価勘定残高をそのまま表示） |

> **出題者の意図**：売上原価対立法の問題において、「売上値引」が出た際に条件反射で原価の戻し仕訳（`商品 / 売上原価`）を書かせる罠、および決算整理前残高試算表で `仕入` ではなく `商品` と `売上原価` が並んでいる際に三分法と混同して二重に決算仕訳を切らせる罠が頻出します。

### 対比表②：諸掛（付随費用）の4パターン完全整理

| 区分 | 当社負担（契約上、当社が払うべき費用） | 先方負担（本来は取引先が払う費用を当社が現金で立て替えた） |
|---|---|---|
| **仕入諸掛**（引取運賃等） | **商品の取得原価に算入**（借方：`仕入` または `商品`） | **立替債権として処理**（借方：`立替金` または `買掛金` の減額） |
| **販売諸掛**（発送費等） | **販売費として独立処理**（借方：`発送費`） | **立替債権として処理**（借方：`売掛金` への加算 または `立替金`） |

> **出題者の意図**：引取運賃を「発送費」に混ぜて売上総利益を歪めさせる罠や、先方負担の立替運賃を当社負担と誤認して商品の取得原価（または発送費）に混ぜさせる罠が定番です。**「誰の財布が減るべき契約か（経済的負担者は誰か）」**を最初に確認してください。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算年1回、3月31日）の当期における以下の商品売買取引について、(1) **三分法**による全仕訳（決算整理を含む）および (2) **売上原価対立法**による全仕訳を示し、当期の**売上原価・売上総利益・営業利益**を求めよ。なお、商品はすべて同一品目・同一単価管理であり、クレジット手数料は販売時に全額を支払手数料として処理し、他の販管費は発生していない。

- 期首繰越商品：50個（単価 ＠2,000円、金額 100,000円）
- 4月10日：商品100個を＠1,900円（計190,000円）で掛け仕入し、当社負担の引取運賃10,000円を現金で支払った。
- 4月12日：商品150個を＠2,000円（計300,000円）で掛け仕入した（運賃は先方負担）。
- 4月15日：4月12日仕入分のうち10個に品質不良があったため返品し、買掛金から20,000円を差し引くこととした。
- 4月20日：商品210個を＠3,000円（計630,000円）でクレジット払いにより販売した（クレジット手数料は売価の2%、原価は＠2,000円）。なお、当社負担の発送費4,000円を現金で支払った。
- 3月31日（決算）：実地棚卸の結果、期末商品は80個（＠2,000円、160,000円）であった。

### 問2（本試験標準・ひっかけ対応）
乙社は**売上原価対立法**を採用している。期首商品40個（＠1,500円、60,000円）を保有しており、当期中に以下の取引を順に行った。すべての取引の仕訳を示し、当期末の**商品残高・売上高・売上原価・売上総利益・売掛金残高・買掛金残高**（期首売掛・買掛残高は0円とする）をそれぞれ求めよ。なお、乙社の取扱商品はすべて原価＠1,500円である。

1. 商品120個を＠1,500円（計180,000円）で掛け仕入した。その際、先方負担の引取運賃3,000円を当社が現金で立て替えて支払い、買掛金から差し引く契約とした。
2. 商品100個を＠2,500円（計250,000円）で掛け販売した。その際、先方負担の発送費4,000円を当社が現金で立て替えて支払い、売掛金に含めて請求することとした。
3. 上記2.で販売した商品のうち10個について、軽微な包装汚れがあったため＠300円の値引を行い、売掛金を減額した（商品は顧客の手元にある）。
4. 上記2.で販売した商品のうち8個について、仕様違いにより返品を受け、売掛金を減額した（8個は倉庫に戻入された）。

### 問3（1級視点・応用思考）
三分法を採用する丙社（販管費は発送費以外に発生しないものとする）の第1期・第2期について、以下の資料と誤謬が判明した。次の(1)〜(3)に答えよ。

- **第1期（正しい数値）**：期首商品 120,000円、当期純仕入高（本体880,000円＋当社負担引取運賃20,000円）、売上高 1,200,000円、期末商品 150,000円。

#### (2) 引取運賃20,000円の誤処理が営業利益に影響しない理由
- 引取運賃20,000円に係る商品は第1期中に**全量販売済み**であるため、正しく「仕入」に含めた場合は当期の**売上原価**（20,000円）となり、誤って「発送費」とした場合は当期の**販管費**（20,000円）となる。
- したがって、段階利益である「売上総利益」は20,000円過大になるが、その下の「営業利益」の段階では販管費20,000円が差し引かれて相殺されるため、**営業利益への影響は0円**となる。
- **※もし第1期末に在庫として残っていた場合**：正しい処理では20,000円は期末商品（B/S資産）として翌期に繰り延べられるのに対し、誤処理では全額が第1期の発送費（費用）として即時に落とされるため、**第1期の営業利益は20,000円過小**になる。

#### (3) 第2期の正誤差額と2年間通算営業利益の自動相殺

| 項目（第2期） | 正しい数値 | 誤った数値 | 差額（誤 － 正） | 判定 |
|---|---:|---:|---:|---|
| 期首商品 | 150,000 | 200,000 | +50,000 | 50,000円 過大 |
| 当期純仕入 | 900,000 | 900,000 | 0 | 一致 |
| 期末商品 | 180,000 | 180,000 | 0 | 一致 |
| 売上原価 | 870,000 | 920,000 | +50,000 | **50,000円 過大** |
| **営業利益**（1,300,000－原価） | **430,000** | **380,000** | **-50,000** | **50,000円 過小** |

- **2年間通算営業利益の証明**：
  - 正しい2年間合計：`330,000 (第1期) ＋ 430,000 (第2期) ＝ 760,000円`
  - 誤った2年間合計：`380,000 (第1期) ＋ 380,000 (第2期) ＝ 760,000円`
  - **差額：0円**（期末在庫の評価誤りは、当期の利益を歪めた分だけ翌期の期首在庫を通じて逆方向に利益を歪めるため、2期通算で必ず自動相殺される＝**期間損益の自己修正機能**）。

> **誤答パターン分析**：第1期の誤謬「引取運賃20,000円」と「期末在庫＋50,000円」の双方が売上原価を押し下げる方向に働く点（合計70,000円過小）を見落とす誤答、および第2期において期首在庫の過大が「売上原価の過大＝利益の過小」に繋がる符号を逆転させる誤答が多発します。
