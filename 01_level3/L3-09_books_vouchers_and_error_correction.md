## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

同じ商品でも、月初の仕入は＠100円だったのに、月末の仕入は＠130円に値上がりすることがあります。この状態で商品が売れたとき、「いったい＠100円の商品が売れたのか、＠130円の商品が売れたのか」を決めなければ、売上原価も期末在庫も計算できません。この「**単価の異なる在庫から払い出す順番の仮定**」を整理するのが**商品有高帳（先入先出法・移動平均法）**です。

また、企業の経理は1人がすべての帳簿を書くのではなく、現金係・売上係・仕入係で分業して「伝票」を起票し、試算表で「借方合計 ＝ 貸方合計」を照合することで不正とミスを防ぐ（**内部牽制**）仕組みをとっています。もし記帳ミスが発覚したときも、消しゴムで消す（改ざん）ことは許されず、必ず**「訂正仕訳」**によって修正履歴を透明に残します。

### 実務の現場・財務分析・監査の目線
- **クラウド会計・ERP時代でも帳簿体系が不変である理由**：現代の会計ソフトでは入力画面から直接試算表が出力されますが、内部データベースでは「仕訳帳（主要簿）→ 総勘定元帳（主要簿）→ 得意先元帳・商品有高帳（補助簿）」という論理構造で動いています。特に上場企業の監査では「ある数字がどの伝票・証憑から来たか（監査証跡）」を追跡するため、過去の誤記を上書き削除せず「訂正仕訳（または赤黒処理）」で履歴を残すことが内部統制上の絶対ルールです。
- **インフレ局面で評価方法が利益と税金に与える影響**：物価が上昇している局面では、古い安い仕入単価から払い出す**先入先出法**の方が「売上原価が安く、利益と法人税が高くなり、期末在庫が高く」出ます。投資家は企業の在庫評価方法（有価証券報告書等の注記）を確認して他社と利益率を比較します。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **商品有高帳（先入先出法 vs 移動平均法）**：
>    - 4/1 前月繰越：100個 × ＠100円 ＝ 10,000円
>    - 4/10 仕入：200個 × ＠130円 ＝ 26,000円
>    - 4/15 売上：200個（売価 ＠200円 ＝ 40,000円）
>    - 4/20 仕入：50個 × ＠160円 ＝ 8,000円
>    - 4/25 売上：50個（売価 ＠200円 ＝ 10,000円）
> 2. **3伝票制（取引の分解と擬制）**：商品 100,000円を販売し、代金のうち 30,000円を現金で受け取り、残額 70,000円は掛けとした（入金伝票・振替伝票で処理）。
> 3. **訂正仕訳の差分法**：売掛金 50,000円を普通預金で回収した取引を、誤って `(借) 普通預金 50,000 / (貸) 売上 50,000` と記帳していた。

### 5要素の増減による仕訳導出（伝票・訂正）

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ②分解(入) | 現金 | 30,000 | 売上 | 30,000 |
| ②分解(振) | 売掛金 | 70,000 | 売上 | 70,000 |
| ②擬制(振) | 売掛金 | 100,000 | 売上 | 100,000 |
| ②擬制(入) | 現金 | 30,000 | 売掛金 | 30,000 |
| ③訂正 | 売上 | 50,000 | 売掛金 | 50,000 |

- **伝票の分解法 vs 擬制法**：どちらも合算すれば `(借) 現金 30,000, 売掛金 70,000 / (貸) 売上 100,000` となり完全一致する。擬制法は「いったん全額を掛け取引とみなしてから、一部を即時回収した」と分解する実務的な起票法である。
- **訂正仕訳の3ステップ（差分法）**：①誤仕訳を横に書く → ②あるべき正仕訳を横に書く → ③「誤を消す逆仕訳＋正仕訳」を相殺合算する（普通預金 50,000 は誤・正で共通なので触らず、`売上` を取り消して `売掛金` を減らす）。

### 💡 独学者が必ず抱く「なぜ？」徹底Q&A

- **Q1：試算表で「借方合計 ＝ 貸方合計」が一致したのに、まだミスが隠れていることがあるのはなぜですか？**
  - **A**：複式簿記は「借方と貸方を同額で記録したか」までは自動検証してくれますが、①取引丸ごとの仕訳漏れ、②二重記帳、③借方貸方の金額は合っているが勘定科目を間違えた（例：備品を消耗品費にした）、④借方と貸方を丸ごと逆に記帳した、といったミスでは合計値が一致してしまうためです。
- **Q2：商品有高帳の「払出単価」と「売価」を混同しないコツはありますか？**
  - **A**：商品有高帳はあくまで**「倉庫にある在庫の原価（仕入値）の記録」**であり、売価（販売価格）は一切書き込まないのが鉄則です！ 売価は売上帳やP/Lの売上高で記録し、商品有高帳の払出欄には「仕入れたときの単価（原価）」だけを書きます。
- **Q3：3伝票制の「擬制法」では、なぜわざわざ実態と違う仕訳を2本に分けるのですか？**
  - **A**：現金出納帳を担当する人（入金・出金伝票の係）と、掛取引や売掛金管理を担当する人（振替伝票の係）の役割を明確に分ける（内部牽制を効かせる）ためです。全部を振替伝票で全額掛けとして記録しておけば、得意先ごとの総取引額がすべて売掛金元帳に残り、顧客管理の漏れがなくなります。

### 【1級貫通・標準下書きフォーマット】

型02（ボックス図）で投入＝産出の保存則を確認し、型03で有高帳の時系列計算を固定します。

```text
【先入先出法 (FIFO)：古い単価から払い出す】
  4/15 払出(200個): 100×@100(10,000) + 100×@130(13,000) = 23,000円
  4/25 払出( 50個): 50×@130 = 6,500円  => 売上原価 29,500円
  期末残高 (100個): 50×@130(6,500) + 50×@160(8,000) = 14,500円

【移動平均法：仕入のつど平均単価を再計算】
  4/10 仕入後: (10,000 + 26,000) ÷ 300個 = @120円 -> 4/15払出 200×@120 = 24,000円
  4/20 仕入後: (12,000 +  8,000) ÷ 150個 = @133.33... -> (例題:割り切れ注意)
  ※本例では 4/20後 100×@120 + 50×@160 = 20,000円 -> 150個、
    もし4/20が100個×@150なら @135円 等。本例は4/25が 50×(20,000/150) で端数が出るため
    実戦では割り切れる単価設計を検算する（FIFO: 29,500+14,500 = 44,000円）。
```
※先入先出法と移動平均法のどちらであっても、**`売上原価 ＋ 期末商品 ＝ 期首商品 ＋ 当期純仕入高（44,000円）`** のボックス保存則は絶対に崩れません。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（3級）】
1. **先入先出法と移動平均法の計算**：仕入のたびに平均単価を更新する移動平均法と、ロット順に払い出す先入先出法。
2. **返品の単価ルール**：仕入返品は「仕入時の単価」で払い出し、売上返品は「売上時の払出単価」で受け入れる。
3. **3伝票制（入金・出金・振替）と試算表の限界**：貸借合計が一致しても見抜けない誤謬（仕訳漏れ、二重記帳、金額同額の科目誤り）を識別できること。
4. **差分法による訂正仕訳**：1発で正しい状態へ戻す仕訳を正確に書けること。

### 【未来の拡張フック（2級・1級への伏線・一読でOK）】
- **2級への接続（`L2I-02`, `L2I-05`）**：商品有高帳の先入先出法・平均法の計算構造は、そのまま工業簿記の**材料元帳**および**総合原価計算（先入先出法・平均法ボックス図）**へと直結する。
- **1級への接続（`L1C-01`, `L1C-05`）**：月次一括の総平均法、小売業向けの売価還元法、さらには過去の決算誤謬を期首利益剰余金で直す**「誤謬の訂正（修正再表示）」**へと進化する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 比較項目 | 先入先出法 (FIFO) | 移動平均法 |
|---|---|---|
| 払出単価の決定 | 最も古い仕入ロットから順に払出 | 新規仕入のつど残高全体で加重平均単価を再計算 |
| 物価上昇時の期末在庫 | 高い最新単価が残るため**期末在庫大・利益大** | 平均化されるため中間の数値になる |
| 売上返品の受入単価 | 直前に払い出した単価で戻す | 売上時に払い出した平均単価で戻す |

> **出題者の意図**：移動平均法において、すでに払い出した分を含めて期首からの累計で平均単価を計算してしまうミス（総平均法との混同）、および試算表で「借方合計＝貸方合計が一致しているからミスはない」と誤認させる引っ掛けが定番です。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

- 共通投入額：`20,000 + 36,000 + 34,000 = 90,000円`（150個）、共通売上高：`110個 × @900 = 99,000円`

#### (1) 先入先出法
- 5/15 払出（50個）：`40×@500(20,000) + 10×@600(6,000) = 26,000円`（残：50個×@600＝30,000円）
- 5/28 払出（60個）：`50×@600(30,000) + 10×@680(6,800) = 36,800円`
- **売上原価**：`26,000 + 36,800 = 62,800円`
- **月末商品**：`40個 × @680 = 27,200円`（検算：`62,800 + 27,200 = 90,000円`）
- **売上総利益**：`99,000 - 62,800 = 36,200円`

#### (2) 移動平均法
- 5/8 仕入後：`(20,000 + 36,000) ÷ (40 + 60) = 56,000 ÷ 100 = @560円`
- 5/15 払出（50個）：`50 × @560 = 28,000円`（残：50個 × @560 ＝ 28,000円）
- 5/22 仕入後：`(28,000 + 34,000) ÷ (50 + 50) = 62,000 ÷ 100 = @620円`
- 5/28 払出（60個）：`60 × @620 = 37,200円`
- **売上原価**：`28,000 + 37,200 = 65,200円`
- **月末商品**：`40個 × @620 = 24,800円`（検算：`65,200 + 24,800 = 90,000円`）
- **売上総利益**：`99,000 - 65,200 = 33,800円`

> **誤答パターン分析**：移動平均法で5/22の平均単価を出す際、5/15にすでに払い出した50個を含めて `(20,000+36,000+34,000) ÷ 150 = @600円` としてしまう総平均法との混同が定番ミスです。

### 問3の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1訂正 | 備品 | 180,000 | 消耗品費 | 180,000 |
| 2訂正 | 普通預金 | 180,000 | 買掛金 | 90,000 |
|  |  |  | 売掛金 | 90,000 |
| 3訂正 | 現金 | 120,000 | 借入金 | 120,000 |

- **2番の導出プロセス**：誤仕訳 `(借) 買掛金 90,000 / (貸) 普通預金 90,000` を消す逆仕訳 `(借) 普通預金 90,000 / (貸) 買掛金 90,000` に、あるべき正仕訳 `(借) 普通預金 90,000 / (貸) 売掛金 90,000` を合算する。
- **営業利益への正味影響**：1番の消耗品費（費用）180,000円が取り消されるため **＋180,000円（利益増加）**。2番・3番はいずれもB/S勘定（資産・負債）間の誤謬であるため損益には影響しない。

> **誤答パターン分析**：2番において普通預金を90,000円だけ増やしてしまい、逆仕訳の打ち消し分（もう90,000円）が抜ける誤答が多発します。
