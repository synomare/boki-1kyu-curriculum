## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

現金・預金は、企業にとって血液そのものであり、同時に**最も不正（横領・紛失）が起きやすい危険な資産**です。もし金庫の中のお金が帳簿より10,000円少ないのに「まあいいか」と放置したり、逆に複数の銀行口座のプラス残高とマイナス残高（借金）を勝手に相殺してB/Sに載せたりしたらどうなるでしょうか？
- **過不足放置の罠**：帳簿残高と実際有高が一致しないまま決算書を作れば、B/Sの現金残高は「架空の数字」になり、内部の不正や記帳ミスを隠蔽することになる。
- **口座相殺の罠**：A銀行に預金250,000円、B銀行に借越（実質的な短期借入金）120,000円があるのに相殺して「預金130,000円」と表示すると、銀行への返済義務（負債）120,000円を投資家から隠すことになる。

したがって、現金・預金の会計は以下の原則から導かれます。
1. **通貨代用証券の現金処理**：配当金領収証など「銀行に行けば即時に現金化できるもの」は、実質的に現金と同一の購買力を持つため「現金」に含める（※2027年4月改定により紙の小切手・手形は出題範囲から廃止）。
2. **定額資金前渡制度（インプレスト・システム）**：現場に一定額の小口現金だけを持たせ、使途報告と引き換えに同額を補給することで、不正を防ぐ内部統制を実現する。
3. **総額主義の原則**：異なる銀行間の預金と借越、および原因不明の雑益と雑損は、勝手に相殺せず総額で表示する。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> 1. **現金過不足**：期中に帳簿残高 120,000円に対して実際有高が 112,000円であった。その後、旅費交通費 5,500円の記帳漏れが判明し、残額は原因不明のまま決算を迎えた。
> 2. **小口現金**：定額 50,000円のインプレスト・システムで、用度係から「旅費交通費 18,000円、通信費 7,000円、消耗品費 12,000円（計 37,000円）」の支払報告を受け、即時に当座預金から補給した。
> 3. **当座借越**：当座預金残高 100,000円の状態で、買掛金 280,000円を当座振込で支払った（当座借越契約あり）。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ①発見 | 現金過不足 | 8,000 | 現金 | 8,000 |
| ①判明 | 旅費交通費 | 5,500 | 現金過不足 | 5,500 |
| ①決算 | 雑損 | 2,500 | 現金過不足 | 2,500 |
| ②補給 | 旅費交通費 | 18,000 | 当座預金 | 37,000 |
|  | 通信費 | 7,000 |  |  |
|  | 消耗品費 | 12,000 |  |  |
| ③決済 | 買掛金 | 280,000 | 当座預金 | 100,000 |
|  |  |  | 当座借越 | 180,000 |

- **①の論理**：金庫に112,000円しかないのに帳簿を120,000円のままにはできないため、まず「現金（資産－）」を8,000円減らし、原因調査中の仮勘定「現金過不足」を借方に立てる。5,500円は「旅費交通費（費用＋）」に振り替え、決算でも不明な2,500円は「雑損（費用＋）」として確定させる。
- **②の論理**：補給時に「小口現金」を出し入れせず、使用した費用を直接計上して「当座預金（資産－）」から同額を補給すれば、小口現金勘定は常に定額50,000円に保たれる。
- **③の論理**：当座預金は100,000円しか引き出せない（資産－100,000）。不足する180,000円は銀行から自動的に借りている状態なので「当座借越（負債＋）」とする。

### 【1級貫通・標準下書きフォーマット】

型03（T勘定連結型）を用いて、現金過不足・小口現金・当座口座の残高推移を追跡します。

```text
    [ 現金 (資産) ]                   [ 現金過不足 (仮勘定) ]
  -----------+-----------           -----------+-----------
  帳簿120,000| 不足 8,000  =====>   発見  8,000| 判明  5,500
  (実 112,000)                                 | 雑損  2,500

    [ 当座預金 (資産) ]               [ 当座借越 (負債) ]
  -----------+-----------           -----------+-----------
  残  100,000| ③   100,000                    | ③   180,000
```

**手順の固定化**：
1. 現金過不足は必ず「**帳簿残高を実際有高に合わせる**」向きで現金を増減させる。
2. 小口現金の即時補給は「借方：各費用 ／ 貸方：当座預金（または普通預金）」の1本で処理する。
3. 当座決済は、現在の当座預金残高を超えた分だけを「当座借越（負債）」とする。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（3級）】
1. **通貨代用証券と非現金の区別**：通貨・配当金領収証・期限到来済公社債利札は「現金」、切手・収入印紙は「貯蔵品（購入時は通信費・租税公課）」、定期預金は独立管理。
2. **現金過不足の期中・決算処理**：仮勘定である現金過不足は決算時に必ずゼロ（雑益または雑損へ振替）にすること。
3. **当座借越の一勘定・二勘定対応**：当座預金（資産）と当座借越（負債）を明確に分離して処理できること。

### 【未来の拡張フック（2級・1級への伏線・一読でOK）】
- **2級への接続（`L2C-01`）**：企業側の当座預金残高と銀行側の残高証明がズレる原因（未通知・時間外預入・誤記等）を整理する「**銀行勘定調整表**」へ進化する。
- **1級への接続（`L1C-14`）**：B/Sの「現金及び預金」から定期預金（満期3ヶ月超）や当座借越の性質を切り分け、**キャッシュ・フロー計算書における「現金及び現金同等物」**の定義へと接続する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 対象物 | 簿記上の勘定科目 | 経済的実態（分類の根拠） |
|---|---|---|
| 通貨、配当金領収証、期限到来済利札 | **現金** | 即時に銀行等で換金できる支払手段 |
| 郵便切手・収入印紙（未使用分） | **貯蔵品** | 換金手段ではなく前払いの事務用品・税金 |
| 定期預金（満期1年超） | **長期定期預金** | 満期まで引き出せない固定資産（投資その他の資産） |
| 他行の当座借越 | **当座借越**（負債） | 預金と相殺できない短期の銀行借入金 |

> **出題者の意図**：2027年4月改定で紙の小切手は廃止されましたが、手許に「未使用の切手・収入印紙」を混ぜて現金残高を誤らせる罠や、A銀行の普通預金とB銀行の当座借越を相殺させてB/S負債を消させる罠は依然として最頻出です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
以下の4つの取引について、それぞれ仕訳を示せ。
1. 株主総会決議に基づき受け取った配当金領収証 24,000円を金庫に保管した。
2. 小口現金（定額 40,000円）について、用度係から「通信費 11,000円、水道光熱費 9,500円、旅費交通費 6,500円」の支払報告を受け、ただちに普通預金から同額を補給した。
3. 当座預金残高が 150,000円の状態で、買掛金 230,000円を当座口座から振り込んで支払った（当座借越契約あり）。
4. 商品 50,000円をQRコード決済（キャッシュレス決済）で販売した。決済事業者への手数料は売上の3%であり、販売時に支払手数料を認識し、残額は後日入金（未収入金）となる。

### 問2（本試験標準・ひっかけ対応）
甲社（決算3月31日）における以下の時系列取引の仕訳を示し、**決算時の雑益・雑損および期末の現金B/S残高**を求めよ。
- 11月10日：現金の帳簿残高 85,000円に対して、実際有高は 97,000円であったため、過不足を処理した。
- 11月20日：上記のうち 9,000円は売掛金の現金回収の記帳漏れであることが判明した。残額は決算まで判明しなかった。
- 3月31日（決算）：上記11月の現金過不足残高を整理するとともに、当日の現金帳簿残高 140,000円に対して実際有高が 134,500円であった。調査の結果、4,000円は通信費の記帳漏れと判明したが、残額は原因不明であった。

### 問3（1級視点・応用思考）
乙社（決算3月31日）の期末における銀行口座および金庫内の状況は以下のとおりであった。B/Sに表示すべき**①流動資産「現金及び預金」、②流動負債「当座借越」、③流動資産「貯蔵品」、④固定資産「長期定期預金」**の金額をそれぞれ算出し、A銀行の当座預金とB銀行の当座借越を相殺してはいけない理由を1〜2行で説明せよ。
- A銀行 当座預金：+250,000円
- B銀行 当座預金：-120,000円（当座借越契約に基づくマイナス残高）
- C銀行 普通預金：+400,000円
- D銀行 定期預金：+500,000円（満期は決算日の翌日から起算して2年後）
- 金庫内の保管物：通貨 60,000円、配当金領収証 15,000円、未使用の郵便切手 8,000円、未使用の収入印紙 12,000円

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1 | 現金 | 24,000 | 受取配当金 | 24,000 |
| 2 | 通信費 | 11,000 | 普通預金 | 27,000 |
|  | 水道光熱費 | 9,500 |  |  |
|  | 旅費交通費 | 6,500 |  |  |
| 3 | 買掛金 | 230,000 | 当座預金 | 150,000 |
|  |  |  | 当座借越 | 80,000 |
| 4 | 未収入金 | 48,500 | 売上 | 50,000 |
|  | 支払手数料 | 1,500 |  |  |

- 取引2補給額：`11,000 + 9,500 + 6,500 = 27,000円`
- 取引4手数料：`50,000 × 3% = 1,500円`、未収入金：`50,000 - 1,500 = 48,500円`

> **誤答パターン分析**：取引2で小口現金を40,000円補給してしまったり、取引3で買掛金230,000円全額を「当座借越」にして当座預金残高150,000円を使い忘れるミスが定番です。

### 問2の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 11/10 | 現金 | 12,000 | 現金過不足 | 12,000 |
| 11/20 | 現金過不足 | 9,000 | 売掛金 | 9,000 |
| 3/31① | 現金過不足 | 3,000 | 雑益 | 3,000 |
| 3/31② | 通信費 | 4,000 | 現金 | 5,500 |
|  | 雑損 | 1,500 |  |  |

```text
    [ 現金過不足 (11月分) ]
  -----------+-----------
  11/20 9,000| 11/10 12,000
  3/31  3,000| (残高 0)
```

- **雑益**：3,000円（11月分過剰残）、**雑損**：1,500円（3/31不足 `5,500 - 4,000`）
- **期末現金B/S残高**：134,500円（実際有高に一致）

> **誤答パターン分析**：雑益3,000円と雑損1,500円を相殺して「雑益1,500円」のみを計上してしまうミス（総額主義違反）、および決算当日の不足5,500円を一度「現金過不足」に立てて消し忘れるミスが多発します。

### 問3の解答と解説

- **①流動資産「現金及び預金」**：`通貨 60,000 + 配当金領収証 15,000 + A銀行当座 250,000 + C銀行普通 400,000 = 725,000円`
- **②流動負債「当座借越」**：`120,000円`（B銀行マイナス残高）
- **③流動資産「貯蔵品」**：`切手 8,000 + 印紙 12,000 = 20,000円`
- **④固定資産「長期定期預金」**：`500,000円`（満期が決算日の翌日から1年超＝ワン・イヤー・ルールにより固定資産）
- **相殺禁止の理由**：A銀行への預金債権とB銀行に対する借越債務は法的な相手先が異なり、原則として相殺権がないため、総額主義の原則により資産（250,000円）と負債（120,000円）を両建て表示しなければならない。

> **誤答パターン分析**：D銀行の定期預金500,000円（2年後満期）や未使用の切手・印紙20,000円を「現金及び預金」に合算してしまう誤答、およびA銀行とB銀行を相殺して130,000円にする誤答が多発します。
