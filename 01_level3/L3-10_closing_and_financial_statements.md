## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

1年間のすべての取引と決算整理仕訳が終わったあと、企業は「今期いくら儲かったか（P/L）」と「期末時点でどれだけの財産と借金があるか（B/S）」を確定し、同時に翌期へスムーズにバトンを渡すために**帳簿の締切**を行う必要があります。

もし決算手続の最後に「P/Lの当期純利益」と「B/Sの純資産増加額」が一致しているか検算しなかったらどうなるでしょうか？
- **集計ミス・漏れの見逃し**：ある費用をP/LにもB/Sにも転記し忘れたまま決算書を公表してしまい、貸借対照表の左右が合わない（あるいは利益が誤った）重大な不備を起こす。
- **翌期への収益・費用の混入**：P/L科目（売上や給料）は「当期1年間の成績」なので、決算時に損益勘定へ集めてゼロリセット（**損益振替**）し、その最終結果である当期純利益だけを「繰越利益剰余金（純資産）」へ合算（**資本振替**）しなければ、翌期の売上に当期の売上が混ざってしまう。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> A社（決算3月31日）の決算整理前残高試算表（前T/B）と決算整理事項は以下のとおりである。8桁精算表を完成させ、英米式決算法による帳簿締切仕訳（損益振替・資本振替）を示せ。
> - **前T/B（借方合計＝貸方合計＝3,000,000円）**：
>   - 借方：現金預金 1,000,000、売掛金 300,000、繰越商品 150,000、備品 500,000、仕入 700,000、給料 250,000、支払保険料 60,000、仮払法人税等 40,000
>   - 貸方：買掛金 200,000、貸倒引当金 3,000、備品減価償却累計額 100,000、資本金 1,300,000、繰越利益剰余金 197,000、売上 1,200,000
> - **決算整理事項**：
>   1. 期末商品棚卸高は 180,000円である（三分法）。
>   2. 売掛金期末残高に対し 2% の貸倒引当金を差額補充法で設定する。
>   3. 備品について定額法（耐用年数5年、残存価額ゼロ）で減価償却を行う。
>   4. 支払保険料のうち 20,000円は翌期分である。
>   5. 当期の法人税等は 67,000円と確定した。

### 【1級貫通・標準下書きフォーマット】

型03（T勘定連結）による「損益 → 繰越利益剰余金」の締切フローと、精算表の二重一致チェックです。

```text
    [ 損益 (集合勘定) ]                 [ 繰越利益剰余金 (純資産) ]
  -----------+-----------             -----------+-----------
  費用1,130,000| 売上1,200,000                    | 期首 197,000
  資本振替70,000|                      =====>     | 資本振替70,000
  -----------+-----------                         | (期末267,000)

  【精算表の最終検算】
  ・P/L列：貸方 1,200,000 － 借方 1,130,000 ＝ 当期純利益 70,000円
  ・B/S列：借方 2,000,000 － 貸方 1,930,000 ＝ 当期純利益 70,000円 (一致！)
```

※並走例題の精算表B/S列の合計検算：
- B/S借方：`現金預金 1,000,000 + 売掛金 300,000 + 繰越商品 180,000 + 備品 500,000 + 前払保険料 20,000 = 2,000,000円`
- B/S貸方：`買掛金 200,000 + 貸倒引当金 6,000 + 累計額 200,000 + 未払法人税等 27,000 + 資本金 1,300,000 + 繰越利益剰余金 197,000 = 1,930,000円`
- 差額：`2,000,000 - 1,930,000 = 70,000円`（P/L利益と1円も違わず完全一致！）

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（3級）】
1. **8桁精算表の構造**：`残高試算表` ± `修正記入` → `損益計算書`（収益・費用）と `貸借対照表`（資産・負債・資本）への正確な振り分け。
2. **評価勘定の精算表上の位置**：貸倒引当金と減価償却累計額は、精算表上はB/S貸方列に配置し、提出用B/Sでは対応資産の下に控除表示する。
3. **英米式決算法の締切**：収益・費用を「損益」へ集め、損益残高を「繰越利益剰余金」へ振り替える（黒字なら貸方、赤字なら借方）。

### 【未来の拡張フック（2級・1級への伏線・一読でOK）】
- **2級への接続（`L2C-11`, `L2C-12`）**：精算表の枠組みはそのまま「**本支店合併精算表**」や「**連結精算表**（親会社＋子会社±連結修正仕訳＝連結F/S）」へと直接進化する。
- **1級への接続（`L1C-13`, `L1C-14`）**：1級の連結精算表では、さらに非支配株主持分や包括利益（OCI）の組替調整まで同一の精算表ロジックで処理する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 精算表上の扱い | 提出用B/S・P/L上の表示科目 |
|---|---|---|
| 繰越商品（期末） | B/S借方列 | **商品** |
| 仕入（決算整理後残高） | P/L借方列 | **売上原価** |
| 貸倒引当金・減価償却累計額 | B/S貸方列 | 各資産から**控除表示**（B/S合計には純額を算入） |
| 繰越利益剰余金 | 精算表B/S貸方（期首額＋利益行） | 期末額（期首額±当期純損益）で1行表示 |

> **出題者の意図**：精算表の「繰越利益剰余金」を期末額に書き換えてしまってB/SとP/Lの差額が合わなくなるミス、および決算整理前残高試算表の「仮払法人税等」を修正記入で消し忘れてB/S借方に残してしまうミスが定番です。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着）
甲社（決算3月31日）の以下の整理前残高と決算整理事項に基づき、①決算整理仕訳（4本）を示し、②**売上原価・減価償却費・当期純利益・提出用B/Sの資産合計（純額）**を求めよ。
- **整理前残高（貸借合計 2,500,000円）**：
  - 借方：現金預金 800,000、売掛金 200,000、繰越商品 100,000、備品 600,000、仕入 620,000、給料 180,000
  - 貸方：買掛金 300,000、貸倒引当金 2,000、備品減価償却累計額 150,000、借入金 300,000、資本金 700,000、繰越利益剰余金 148,000、売上 900,000
- **決算整理事項**：
  1. 期末商品棚卸高は 120,000円である（三分法）。
  2. 売掛金期末残高に対し 2% の貸倒引当金を差額補充法で設定する。
  3. 備品について定率法（償却率20%）で減価償却を行う。
  4. 借入金の当期分未払利息が 8,000円ある。

乙社（決算3月31日）の決算整理後における収益・費用および純資産の期首残高は以下のとおりであった。①**損益振替仕訳（収益・費用の2本）**と **資本振替仕訳**を示し、②**期末B/Sに計上される繰越利益剰余金**を求めよ。
- 収益：売上 800,000円、受取手数料 10,000円
- 費用：仕入（売上原価） 550,000円、給料 220,000円、減価償却費 60,000円、支払利息 30,000円
- 期首（整理後）繰越利益剰余金：180,000円（期中の配当等はなし）

### 問3（1級視点・応用思考）
丙社（決算3月31日）の以下の「虫食い精算表（抜粋）」において、空欄 **A〜D** の金額を論理的に逆算せよ（法人税等は0円とする）。
- 前T/B：繰越商品 200,000、仕入 950,000、備品 500,000、減価償却累計額 150,000、売上 1,500,000、給料 430,000
- 決算整理後P/L：売上高 1,500,000、売上総利益 600,000、売上原価 **B**、給料 430,000、減価償却費 **C**、当期純利益 **D**
- 決算整理後B/S（提出用純額）：総資産合計 2,400,000（期末商品 **A** を含む）、負債合計 900,000、資本金 1,000,000、期首繰越利益剰余金 380,000（当期の増資・配当はなし）

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1期首 | 仕入 | 100,000 | 繰越商品 | 100,000 |
| 1期末 | 繰越商品 | 120,000 | 仕入 | 120,000 |
| 2貸倒 | 貸倒引当金繰入 | 2,000 | 貸倒引当金 | 2,000 |
| 3償却 | 減価償却費 | 90,000 | 備品減価償却累計額 | 90,000 |
| 4未払 | 支払利息 | 8,000 | 未払利息 | 8,000 |

- 売上原価：`100,000 + 620,000 - 120,000 = 600,000円`
- 貸倒引当金：`200,000 × 2% = 4,000円` → 繰入 `4,000 - 2,000 = 2,000円`
- 減価償却費（定率法20%）：`(600,000 - 150,000) × 20% = 90,000円`（累計額期末 `240,000円`）
- **当期純利益**：`売上 900,000 - (売上原価 600,000 + 給料 180,000 + 貸倒繰入 2,000 + 減価償却費 90,000 + 支払利息 8,000) = 20,000円`
- **提出用B/S 資産合計（純額）**：`現金預金 800,000 + (売掛金 200,000 - 引当 4,000 = 196,000) + 商品 120,000 + (備品 600,000 - 累計 240,000 = 360,000) = 1,476,000円`
  - 検算（負債＋純資産）：`買掛 300,000 + 借入 300,000 + 未払利息 8,000 + 資本金 700,000 + 繰越利益剰余金 (148,000 + 20,000) = 1,476,000円`（完全一致！）

> **誤答パターン分析**：定率法の減価償却費を `600,000 × 20% = 120,000円` としてしまうミス、および提出用B/Sの資産合計に評価勘定（4,000円＋240,000円）を控除しない総額1,720,000円を書いてしまうミスが定番です。

### 問2の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 損益(収) | 売上 | 800,000 | 損益 | 810,000 |
|  | 受取手数料 | 10,000 |  |  |
| 損益(費) | 損益 | 860,000 | 仕入 | 550,000 |
|  |  |  | 給料 | 220,000 |
|  |  |  | 減価償却費 | 60,000 |
|  |  |  | 支払利息 | 30,000 |
| 資本振替 | 繰越利益剰余金 | 50,000 | 損益 | 50,000 |

- 収益合計 `810,000円` ＜ 費用合計 `860,000円` のため、**当期純損失 50,000円**。
- 損失は純資産の減少要因であるため、資本振替では「借方：繰越利益剰余金 50,000 / 貸方：損益 50,000」となる。
- **期末繰越利益剰余金**：`180,000 - 50,000 = 130,000円`

> **誤答パターン分析**：赤字（当期純損失）のときに条件反射で黒字と同じ向きの資本振替 `(借) 損益 / (貸) 繰越利益剰余金` を書いてしまい、純資産を増やしてしまう誤答が多く見られます。

### 問3の解答と解説

```text
  【P/L側からの逆算】            【B/S側からの逆算】
  売上高      1,500,000           総資産       2,400,000
  (-) 売上総利益 600,000          (-) 負債       900,000
  ---------------------           (-) 資本金   1,000,000
  売上原価(B)   900,000           (-) 期首剰余金 380,000
                                  ----------------------
  期首200,000 + 仕入950,000       当期純利益(D)  120,000
  - B(900,000) = 期末商品(A) 250,000
```

- **B（売上原価）**：`売上高 1,500,000 - 売上総利益 600,000 = 900,000円`
- **A（期末商品）**：`期首 200,000 + 仕入 950,000 - 売上原価 900,000 = 250,000円`
- **D（当期純利益）**：B/S等式 `2,400,000 - 900,000 - 1,000,000 - 380,000 = 120,000円`
- **C（減価償却費）**：P/L等式 `売上総利益 600,000 - 給料 430,000 - C = 当期純利益 120,000` より、**C ＝ 50,000円**

> **誤答パターン分析**：B/Sの純資産から逆算した120,000円を「期末繰越利益剰余金」と誤認したり、C（減価償却費）をB/Sの累計額150,000円から推測しようとして手詰まりになるケースが多発します。
