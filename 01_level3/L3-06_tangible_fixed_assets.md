## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

会社が1,000,000円の機械を購入し、これから5年間にわたって製品を作って売上を生み出すとします。もし購入初年度に「1,000,000円全額を費用」にしてしまったら、決算書はどう嘘をつくでしょうか？
- **1年目の異常赤字と2〜5年目の異常黒字**：機械は5年間ずっと働いているのに、1年目だけ1,000,000円の費用を背負って大赤字になり、2〜5年目は機械のコストゼロで異常な高利益が出てしまう。
- **B/Sからの資産消滅**：まだあと4年間もキャッシュを生む能力がある機械が、B/S上でゼロ円（資産に載らない）になり、企業の生産設備の実態が隠されてしまう。

したがって、有形固定資産の会計は**費用配分の原則**に基づき、取得原価を耐用年数にわたって計画的に費用化（減価償却）します。

※**2027年4月改定の重要ポイント**：これまで2級の範囲だった**「定率法による減価償却」**および**「有形固定資産の除却・廃棄」**が、2027年4月以降、3級の標準範囲に加わりました。本単元では定額法・定率法・除却・廃棄を最初から一体として完全習得します。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

> **【並走例題】**
> A社（決算3月31日）は×1年4月1日に機械装置（本体 960,000円、据付費 40,000円）を現金で購入し、使用を開始した（耐用年数5年、残存価額ゼロ）。
> 1. **定額法**（年間償却額 200,000円）と **定率法**（償却率 40%）のそれぞれについて、×1年度・×2年度の減価償却仕訳（間接法）と×2年度末の帳簿価額を比較せよ。
> 2. **期中売却（定額法ケース）**：×3年9月30日（期首から6ヶ月経過）に、上記機械を 450,000円（後日入金・未収入金）で売却した。
> 3. **期末除却・廃棄（定率法ケース）**：×2年度末（帳簿価額 360,000円）に上記機械の使用を中止し、①**除却**した場合（処分見込価額 60,000円）、②**廃棄**した場合（廃棄業者への支払 40,000円・現金）の仕訳をそれぞれ示せ。

### 5要素の増減による仕訳導出

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 取得 | 機械装置 | 1,000,000 | 現金 | 1,000,000 |
| 定額1年 | 減価償却費 | 200,000 | 減価償却累計額 | 200,000 |
| 定率1年 | 減価償却費 | 400,000 | 減価償却累計額 | 400,000 |
| 定率2年 | 減価償却費 | 240,000 | 減価償却累計額 | 240,000 |
| 期中売却 | 減価償却費 | 100,000 | 減価償却累計額 | 100,000 |
|  | 減価償却累計額 | 500,000 | 機械装置 | 1,000,000 |
|  | 未収入金 | 450,000 |  |  |
|  | 固定資産売却損 | 50,000 |  |  |
| 除却(定率) | 減価償却累計額 | 640,000 | 機械装置 | 1,000,000 |
|  | 貯蔵品 | 60,000 |  |  |
|  | 固定資産除却損 | 300,000 |  |  |
| 廃棄(定率) | 減価償却累計額 | 640,000 | 機械装置 | 1,000,000 |
|  | 固定資産廃棄損 | 400,000 | 現金 | 40,000 |

- **取得の論理**：据付費40,000円は使用可能にするための不可避な支出ゆえ取得原価 `1,000,000円` に算入。
- **定額法 vs 定率法**：定額法は毎年均等 `1,000,000 ÷ 5 = 200,000円`。定率法は未償却残高（帳簿価額）に一定率を乗じる：`1年目 1,000,000 × 40% = 400,000円`（末簿価 600,000）、`2年目 600,000 × 40% = 240,000円`（末簿価 360,000）。
- **期中売却の論理**：まず期首から売却日までの6ヶ月分の価値消費 `200,000 × 6/12 = 100,000円` を償却し、累計額を `400,000 + 100,000 = 500,000円`（売却直前簿価 500,000円）に更新してから、売却対価450,000円との差額50,000円を売却損とする。
- **除却 vs 廃棄**：除却は「使うのをやめて倉庫へ移した状態」であり、鉄屑等の処分見込価額60,000円を「貯蔵品（資産＋）」へ振り替え、残額300,000円を「固定資産除却損」とする。廃棄は完全に捨てて処分費用40,000円を払うため、簿価360,000＋廃棄費用40,000＝400,000円を「固定資産廃棄損」とする。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（3級）】
1. **付随費用の原価算入**：購入手数料・運賃・据付費・登録諸費用はすべて取得原価へ。
2. **定額法と定率法（月割計算）**：定率法は必ず「`(取得原価 - 期首累計額) × 償却率 × 月数/12`」で計算。
3. **資本的支出 vs 収益的支出**：資産の価値・耐用年数を伸ばす支出は固定資産の増加、現状維持の修繕は「修繕費」。
4. **売却・除却・廃棄の3点セット**：直前までの月割償却を先に行い、正確な直前簿価を出してから手放す。

### 【未来の拡張フック（2級・1級への伏線・一読でOK）】
- **2級への接続（`L2C-04`, `L2C-05`）**：利用量に応じた「生産高比例法」、国庫補助金による「圧縮記帳」、そして**新リース会計基準（第34号）**の「使用権資産」の減価償却へと接続する。
- **1級への接続（`L1C-06`, `L1C-07`, `L1I-10`）**：収益性低下で簿価を切り下げる「**減損会計**」、将来の解体撤去費用をあらかじめ取得原価に上乗せして償却する「**資産除去債務（ARO）**」、そして設備投資の意思決定における「減価償却の**タックス・シールド効果**」へと直結する。

## 4. 試験官の罠・混同しやすい論点の対比表

| 処理 | 物理的実態 | 処分見込価額／処分費用 | 損益勘定 |
|---|---|---|---|
| **売却** | 第三者へ売って対価を得る | 売却価額（現金・未収入金） | 固定資産売却益／売却損 |
| **除却** | 事業使用を中止（物は手元に残る） | **処分見込価額を「貯蔵品」**へ | 固定資産除却損 |
| **廃棄** | 完全に解体・処分して捨てる | **廃棄費用を支出**（損に加算） | 固定資産廃棄損 |

> **出題者の意図**：期中売却や期中除却において、当期首から処分日までの「当期分の月割減価償却」を計上せずに期首簿価のまま売却損・除却損を計算させる罠、および定率法で月割計算をする際に「期首帳簿価額」ではなく「取得原価」に償却率を掛けてしまう罠が最頻出です。

## 6. 完全検算済み・解答とプロセス解説

### 問1の解答と解説

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 1取得 | 車両運搬具 | 1,200,000 | 普通預金 | 1,200,000 |
| 2定額1年 | 減価償却費 | 120,000 | 車両減価償却累計額 | 120,000 |
| 2定額2年 | 減価償却費 | 240,000 | 車両減価償却累計額 | 240,000 |
| 3定率1年 | 減価償却費 | 240,000 | 車両減価償却累計額 | 240,000 |
| 3定率2年 | 減価償却費 | 384,000 | 車両減価償却累計額 | 384,000 |

- 取得原価：`1,140,000 + 60,000 = 1,200,000円`
- 定額法：×1年度（10/1〜3/31の6ヶ月）`1,200,000 ÷ 5 × 6/12 = 120,000円`（末簿価 `1,080,000円`）、×2年度 `240,000円`（末簿価 `840,000円`）。
- 定率法：×1年度（6ヶ月）`1,200,000 × 40% × 6/12 = 240,000円`（末簿価 `960,000円`）、×2年度 `960,000 × 40% = 384,000円`（末簿価 `576,000円`）。

> **誤答パターン分析**：×1年度が期中10/1取得（6ヶ月使用）であるにもかかわらず、12ヶ月分を償却してしまうミス、および定率法2年目に期首簿価960,000円ではなく取得原価1,200,000円に40%を掛けてしまうミスが典型です。

### 問3の解答と解説

```text
  ×1/4/1        ×2/3/31        ×3/3/31        ×3/9/30(売却)
----+--------------+--------------+--------------+----->
  取得原価 C    残 0.8C        残 0.64C       6ヶ月償却 64,000
              (累計0.2C)     (累計0.36C=360,000) (直前簿価 576,000)
```

1. **取得原価の逆算**：
   - 定率法20%の2年目末の帳簿価額は `C × (1 - 0.2) × (1 - 0.2) = 0.64C`、累計額は `C - 0.64C = 0.36C`。
   - `0.36C = 360,000` より、**取得原価 C ＝ 1,000,000円**。
2. **×3年9月30日売却の仕訳**：
   - 3年目期首簿価 `1,000,000 - 360,000 = 640,000円`、6ヶ月償却 `640,000 × 20% × 6/12 = 64,000円`。
   - 直前累計額 `360,000 + 64,000 = 424,000円`（直前簿価 `576,000円`）→ 売却損 `576,000 - 500,000 = 76,000円`。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 3償却 | 減価償却費 | 64,000 | 機械減価償却累計額 | 64,000 |
| 3売却 | 機械減価償却累計額 | 424,000 | 機械装置 | 1,000,000 |
|  | 未収入金 | 500,000 |  |  |
|  | 固定資産売却損 | 76,000 |  |  |

3. **据付費100,000円即時費用化による×1年度利益の歪み**：
   - 正しい処理では100,000円のうち初年度に費用化されるのは `100,000 × 20% = 20,000円` のみ。
   - 誤処理では100,000円全額が修繕費として初年度に費用化されるため、費用が `100,000 - 20,000 = 80,000円` 過大になり、**×1年度の営業利益は 80,000円 過小**になる。

> **誤答パターン分析**：(1)で2年目の累計360,000円を `0.4C` と単純比例計算して900,000円と誤るケース、および(3)で初年度の償却差額20,000円を考慮せず100,000円過小と答えるケースが多発します。
