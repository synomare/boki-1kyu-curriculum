## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

原子力発電所、化学工場のタンク、アスベストを含む建物などを建設すると、何十年後の解体時に莫大な撤去費用（除去支出）が法律や契約で義務づけられます。昔の会計では解体する年度にいきなり費用計上していましたが、それだと**「何十年も工場を稼働させて利益を得てきた期間には除去費用を1円も負担させず、最後の1年だけに巨額の赤字を押し付ける」**という極めて不合理な決算書になってしまいます。

そこで、資産除去債務に関する会計基準（第18号）は、**「資産を取得した瞬間に、将来の除去支出を割り引いた現在価値を負債（資産除去債務）として計上し、同額を固定資産の取得原価に上乗せして耐用年数にわたって減価償却（費用配分）する」**という**資産負債の両建て処理**を義務づけています。

- **資産化と費用配分の本質**：除去債務という「将来の義務」は負債（B/S）に計上され、それに対応する経済的犠牲は資産の取得原価に含まれて毎期の減価償却費（営業費用）となる。
- **利息費用の本質**：割り引いていた負債の金額が、時の経過とともに将来の支払予定額へ膨らんでいく増加額（アンワインディング）は「利息費用（営業費用区分、減価償却費と同じ区分）」として計上される。
- **見積り変更の非対称性（重要ルール）**：将来の見積除去支出が増えた（上方修正）ときは**その時点の新たな割引率**を使うが、減った（下方修正）ときは**負債計上当時の古い割引率**を使う。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### ARO（3年・10%・ゼロ端数モデル）のライフサイクル仕訳

**【例題】** X1年4月1日、設備本体 2,100,000円を現金で取得した（耐用年数3年、残存0、定額法）。3年後に法令に基づく除去支出 1,197,900円が見込まれる（割引率年 10%、`1.10^3 = 1.331`）。X4年3月31日（3年後）に実際除去費用 1,220,000円を現金払いした。

- **取得時PV（ARO初期値）**：`1,197,900 ÷ 1.331` ＝ **900,000円** → 設備総取得原価 ＝ `2,100,000 ＋ 900,000` ＝ **3,000,000円**（年減価償却費 `1,000,000円`＝本体700k＋除去300k）。
- **X1末（X2/3/31）**：利息費用 `900,000 × 10%` ＝ **90,000円**（ARO残 `990,000円`）。
- **X2末（X3/3/31）**：利息費用 `990,000 × 10%` ＝ **99,000円**（ARO残 `1,089,000円`）。
- **X3末（X4/3/31）**：利息費用 `1,089,000 × 10%` ＝ **108,900円**（ARO残 `1,197,900円`）。実際除去1,220,000円との差額 **22,100円** を **履行差額（費用）** とする。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① X1/4/1 取得 | 機械装置 | 3,000,000 | 現金預金 | 2,100,000 |
|  |  |  | 資産除去債務 | 900,000 |
| ② X2/3/31 償却・利息 | 減価償却費 | 1,000,000 | 減価償却累計額 | 1,000,000 |
|  | 利息費用 | 90,000 | 資産除去債務 | 90,000 |
| ③ X4/3/31 除去履行 | 資産除去債務 | 1,197,900 | 現金預金 | 1,220,000 |
|  | 履行差額 | 22,100 |  |  |

### 【1級貫通・標準下書きフォーマット】型01・型04（ARO資産・負債両建て表）

```text
  | 年度 | 期首ARO負債 | 利息費用(10%) | 期末ARO負債 | | 除去資産簿価 | 除去償却費 |
  |------+-------------+---------------+-------------+-+--------------+------------|
  | 取得 |           - |             - |     900,000 | |      900,000 |          - |
  |  X1  |     900,000 |        90,000 |     990,000 | |      600,000 |    300,000 |
  |  X2  |     990,000 |        99,000 |   1,089,000 | |      300,000 |    300,000 |
  |  X3  |   1,089,000 |       108,900 |   1,197,900 | |            0 |    300,000 |
```

**手順**：
1. 「ARO負債（複利で増える）」と「除去費用資産（定額等で減る）」の2列を同じテーブルで管理する。
2. 見積り変更が起きたら、修正時点の残存年数で増加分（新割引率）または減少分（旧割引率）を割り引き、**負債と資産の両方に同額を加減**してから翌期以降の償却と利息を再計算する。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（1級）】
- AROの基本処理（取得時両建て・減価償却・利息費用・履行差額）。
- **見積り変更の計算**（将来CF上方修正＝**変更時割引率**、下方修正＝**当初割引率**の非対称性ルールと修正後の償却・利息）。
- **賃借建物に係る敷金の簡便処理**（資産除去債務の計上に代えて、返還見込のない敷金を賃借期間で均等費用配分する特例）。
- **固定資産の交換**（自己所有資産同士の同種交換＝簿価引継ぎ・損益不認識 vs 異種交換＝時価評価・交換損益認識）。

### 【未来の拡張フック（1級本試験・リース・税効果）】
- **新リース会計基準（`L1C-08`）との接続**：賃借建物の原状回復義務に係る資産除去債務は、使用権資産の取得原価に含めて償却する。
- **税効果会計との連動（`L1C-11`）**：会計上のARO減価償却費・利息費用は、実際に除去支出するまで税務上損金不算入となるため、将来減算一時差異（DTA）が発生する（一方、資産側も税務簿価とズレるため両建一時差異となる）。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 上方修正（将来CF増加） | 下方修正（将来CF減少） |
|---|---|---|
| **適用する割引率** | **見積り変更時点の新たな割引率** | **当初負債計上時の割引率（古い率）** |
| **変更の理論的理由** | 新たな債務を現在の金利環境で引き受けたとみなす | 既存の負債の一部取り消し（金利低下で負債が増える矛盾を防ぐ） |
| **仕訳・影響** | `借方：有形固定資産 / 貸方：ARO` | `借方：ARO / 貸方：有形固定資産` |

> **出題者の意図**：見積り変更で「下方修正なのにうっかり新しい割引率を使ってしまうミス」、および「X1年度末に上方修正した場合、修正後の除去資産残高を残存2年で割り直す（変更前の年300kに増加分を足し忘れる）ミス」が極めて多い。さらに、利息費用の表示区分を「営業外費用」と誤解させる罠にも注意せよ（原則、減価償却費と同じ**営業費用**区分）。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

- **取得時ARO** ＝ `441,000 ÷ 1.1025` ＝ **400,000円** → 設備総取得原価 `1,400,000円`（年償却 `700,000円`）。
- **X1末利息** ＝ `400,000 × 5%` ＝ **20,000円**（ARO残 `420,000円`）。
- **X2末利息** ＝ `420,000 × 5%` ＝ **21,000円**（ARO残 `441,000円`）。
- **履行差額** ＝ `ARO負債441,000 － 実際支出430,000` ＝ **履行差額（益） 11,000円**。

### 問2 解答・解説

**【ケース(A) 上方修正：新割引率 5% を適用】**
1. 増加額の現在価値 ＝ `+220,500 ÷ 1.05^2` ＝ **+200,000円**。
   - 修正後ARO負債 ＝ `990,000 ＋ 200,000 ＝ 1,190,000円`（旧990k分は10%、新200k分は5%で複利増加）。
   - 修正後除去資産簿価 ＝ `600,000 ＋ 200,000 ＝ 800,000円`（残存2年）。
2. X2年度：
   - **除去費用償却費** ＝ `800,000 ÷ 2年` ＝ **400,000円**
   - **利息費用** ＝ `990,000 × 10% ＋ 200,000 × 5%` ＝ `99,000 ＋ 10,000` ＝ **109,000円**

**【ケース(B) 下方修正：当初割引率 10% を適用】**
1. 減少額の現在価値 ＝ `-242,000 ÷ 1.10^2` ＝ **-200,000円**。
   - 修正後ARO負債 ＝ `990,000 － 200,000 ＝ 790,000円`（すべて10%）。
   - 修正後除去資産簿価 ＝ `600,000 － 200,000 ＝ 400,000円`（残存2年）。
2. X2年度：
   - **除去費用償却費** ＝ `400,000 ÷ 2年` ＝ **200,000円**
   - **利息費用** ＝ `790,000 × 10%` ＝ **79,000円**

### 問3 解答・解説

- **(A) 敷金の簡便処理**：返還見込のない300,000円を契約期間5年で均等償却（`300,000 ÷ 5 ＝ 60,000円/年`）し、敷金を直接減額する。5年後の敷金残高は返還見込額の **700,000円** となる。
- **(B) 固定資産の交換**：旧機械の簿価は `1,000,000 － 600,000 ＝ 400,000円`。同種交換は投資の継続として簿価400,000円を引き継ぎ（損益0）、異種交換は旧資産の売却と新資産の購入とみなして時価520,000円で計上し **交換益 120,000円** を認識する。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| (A) X1/4/1 差入 | 敷金 | 1,000,000 | 現金預金 | 1,000,000 |
| (A) X2/3/31 費用配分 | 支払家賃（原状回復費） | 60,000 | 敷金 | 60,000 |
| (B) ① 同種交換 | 新機械 | 400,000 | 旧機械 | 1,000,000 |
|  | 減価償却累計額 | 600,000 |  |  |
| (B) ② 異種交換 | 土地 | 520,000 | 旧機械 | 1,000,000 |
|  | 減価償却累計額 | 600,000 | 固定資産交換益 | 120,000 |

> **誤答パターン分析**：同種交換で時価520,000円を使って交換益120,000円を計上してしまうミス（投資が継続しているため交換損益を認識しないのが原則）。
