## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

自己株式の取得は「株主への資本の払戻し（実質的な減資）」であり、処分は「新株の発行と同じく株主からの資本の払込み」です。したがって、自己株式の取得・処分・消却の差額はすべて**株主との資本取引**であり、P/L（損益）に一切混ぜてはいけません。また、処分差損等で「その他資本剰余金」がマイナス（負の残高）になったまま決算を迎えるのは「元本欠損の放置」になるため、期末に**繰越利益剰余金でゼロまで補填**します。

一方、従業員への**ストック・オプション（SO）**は、現金の代わりに「自社株を安く買える権利（新株予約権）」を労働の対価として渡すものです。もし権利付与時に費用を計上しなかったら、**従業員の労働コスト（人件費）がP/Lから抜け落ちて利益が過大に見えてしまいます**。そのため、権利確定日までの勤務期間にわたって公正な評価単価を「株式報酬費用（費用）」と「新株予約権（純資産）」として両建て認識します。

- **自己株式の本質**：資産ではなく「株主資本の控除項目（資本の払戻し）」。取得付随費用だけは資本取引と切り離して営業外費用とする。
- **ストック・オプションの本質**：付与日（Grant Date）の公正な評価単価（原則として再評価しない）に、期末時点の見積失効数を反映した権利確定見込数を乗じて期間配分する。
- **分配可能額規制の本質**：債権者保護のため、剰余金から「自己株式簿価」を差し引き、さらに換金性の乏しい「のれん（1/2）＋繰延資産」が資本金・準備金合計を超える分（のれん等調整額）を配当不可としてロックする。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 自己株式の負残高補填と標準仕訳

**【例題】** 期首のその他資本剰余金 30,000円、繰越利益剰余金 400,000円。
1. 当社株式 100株を @1,000円（100,000円）で取得し、付随手数料 5,000円とともに現金払いした。
2. うち 60株（簿価 60,000円）を @800円（48,000円）で処分した（差損 12,000円 → その他資本剰余金残 `18,000円`）。
3. 残る 40株（簿価 40,000円）を消却した → その他資本剰余金は `18,000 － 40,000 ＝ -22,000円`（負の残高）。
4. 決算において、その他資本剰余金の負残高 **22,000円** を繰越利益剰余金で補填した（期末残：その他資本剰余金 0円、繰越利益剰余金 **378,000円**）。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 自己株式取得 | 自己株式 | 100,000 | 現金預金 | 105,000 |
|  | 支払手数料（営業外） | 5,000 |  |  |
| ② 自己株式処分(損) | 現金預金 | 48,000 | 自己株式 | 60,000 |
|  | その他資本剰余金 | 12,000 |  |  |
| ③ 自己株式消却 | その他資本剰余金 | 40,000 | 自己株式 | 40,000 |
| ④ 期末負残高補填 | 繰越利益剰余金 | 22,000 | その他資本剰余金 | 22,000 |

### 【1級貫通・標準下書きフォーマット】型01・型03（SO期間配分＆資本T勘定）

```text
  [ SO計算タイムライン (100個 × @5,000円, 2年) ]
  X1/4/1(付与)          X2/3/31(X1末)             X3/3/31(X2末・確定)
  ----+---------------------+-------------------------+----------------->
      | 権利確定見込 90個   | 確定実績 80個           |
      | 累計=90×5k×(1/2)    | 累計=80×5k×(2/2)        |
      |     = 225,000円     |     = 400,000円         |
      | X1費用 = 225,000円  | X2費用 = 400k-225k=175k |
```

**手順**：
1. 自己株式は「その他資本剰余金T勘定」を書き、期中赤字でもそのままマイナスを累積させ、**決算で一括して繰越利益剰余金から補填**する。
2. SOは必ず**「当期末時点の必要累計額（見込個数 × 付与日単価 × 経過月数/全勤務月数）」**を先に求め、前期末累計額を引いて当期株式報酬費用を出す（洗替不要・プロスペクティブ）。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（1級）】
- 自己株式の取得（付随費用は営業外費用）・処分（その他資本剰余金）・消却・負残高の期末補填。
- **新株発行と自己株式処分の同時実行**（払込金額を株数比等で新株と自己株に按分し、原則として新株分は資本金／資本準備金、自己株分は自己株式簿価との差額をその他資本剰余金へ）。
- **ストック・オプション（SO）**の付与・失効見積修正・権利行使（資本組入）・権利不行使失効（新株予約権戻入益＝特別利益）。
- **会社法上の分配可能額**の計算（特に「のれん等調整額」の判定式）。

### 【未来の拡張フック（1級本試験・連結・結合）】
- **企業結合における自己株式の交付（`L1C-15`）**：買収対価として新株ではなく自己株式を交付する場合、時価（取得対価）と自己株式簿価の差額はその他資本剰余金となる（資本剰余金が負になれば期末に利益剰余金で補填）。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 正しい処理 | 試験官の罠 |
|---|---|---|
| **自己株式取得の付随費用** | **営業外費用（支払手数料等）** | 株式交付費（繰延資産）や自己株式取得原価に含めてしまうミス |
| **その他資本剰余金負残高** | **決算期末**に繰越利益剰余金からゼロまで補填 | 取引の都度（期中消却の瞬間等）に繰越利益剰余金から直接減額してしまうミス（期中に再度処分差益が出る可能性があるため期末に判定） |
| **SOの未行使失効時** | **新株予約権戻入益（特別利益）** | 自己株式と同じ資本取引と誤解してその他資本剰余金にしてしまうミス（新株予約権は権利確定前の株主との資本取引ではないため、失効時はP/L利益へ戻す） |

> **出題者の意図**：特に**分配可能額の「のれん等調整額」（問3）**は、「のれん全額ではなく **のれんの1/2 ＋ 繰延資産** を、**資本金＋準備金** と比較し、超過額が出た場合でもさらに区分上限判定がある」というステップの記憶曖昧さを突いてくる。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

- 払込総額 150,000円を株数比（新株40 : 自己株60）で按分する。
  - 新株発行対価：`150,000 × (40 ÷ 100)` ＝ **60,000円** → 全額 **資本金 60,000円**。
  - 自己株式処分対価：`150,000 × (60 ÷ 100)` ＝ **90,000円** → 自己株式簿価72,000円との差額 **18,000円** が **その他資本剰余金**。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 新株+自己株同時実行 | 現金預金 | 150,000 | 資本金 | 60,000 |
|  |  |  | 自己株式 | 72,000 |
|  |  |  | その他資本剰余金 | 18,000 |

> **誤答パターン分析**：150,000円から先に自己株式72,000円を引いた残額78,000円をすべて資本金にしてしまうミス（自己株式処分差益18,000円は資本金ではなくその他資本剰余金）。

### 問2 解答・解説

1. **権利確定期間（X1・X2年度）**：
   - X1年度末必要累計額：`90個 × @5,000 × (1年 ÷ 2年)` ＝ **225,000円**（X1株式報酬費用 **225,000円**）。
   - X2年度末確定累計額：`80個 × @5,000 × (2年 ÷ 2年)` ＝ **400,000円** → X2株式報酬費用 ＝ `400,000 － 225,000` ＝ **175,000円**。
2. **権利行使・失効（X3年度）**：
   - 70個行使：払込現金 `70 × @10,000 = 700,000円` ＋ 取崩新株予約権 `70 × @5,000 = 350,000円` → **資本金 1,050,000円**。
   - 10個失効：`10 × @5,000` ＝ **新株予約権戻入益 50,000円**（特別利益）。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| X1末 報酬費用 | 株式報酬費用 | 225,000 | 新株予約権 | 225,000 |
| X2末 報酬費用 | 株式報酬費用 | 175,000 | 新株予約権 | 175,000 |
| X3 権利行使(70個) | 現金預金 | 700,000 | 資本金 | 1,050,000 |
|  | 新株予約権 | 350,000 |  |  |
| X3 失効(10個) | 新株予約権 | 50,000 | 新株予約権戻入益 | 50,000 |

> **誤答パターン分析**：X2年度末に10個失効した分を「新株予約権戻入益」として戻してしまうミス。権利確定日前の退職見込変動は、累計額の修正（株式報酬費用の加減）で調整する。

### 問3 解答・解説

- **剰余金合計** ＝ `その他資本剰余金 150,000 ＋ 繰越利益剰余金 550,000` ＝ **700,000円**
- 控除項目：自己株式 `100,000` ＋ その他有価証券評価差額金（借方残）`30,000` ＝ **130,000円**
1. **通常ケース**：
   - `のれん×1/2 ＋ 繰延資産` ＝ `320,000×0.5 ＋ 80,000` ＝ **240,000円**
   - `資本金 ＋ 資本準備金 ＋ 利益準備金` ＝ `1,000,000 ＋ 200,000 ＋ 100,000` ＝ **1,300,000円**
   - `240,000 ≤ 1,300,000` ゆえ、**のれん等調整額 ＝ 0円**。
   - **分配可能額** ＝ `700,000 － 130,000 － 0` ＝ **570,000円**。
2. **比較ケース（資本金＋準備金合計＝150,000円の場合）**：
   - 超過額 ＝ `240,000 － 150,000 ＝ 90,000円`（なお `のれん×1/2 + 繰延資産 = 240k > 資本金+準備金 = 150k` かつ繰延資産80k+超過分として、基準上 `Max(0, のれん/2 + 繰延資産 - (資本金+準備金+その他資本剰余金))` ではなく、会社計算規則では「`のれん×1/2 ＋ 繰延資産` が `資本金＋準備金` を超える場合、その超過額（ただしその他資本剰余金や繰延資産との比較調整後 **90,000円**）」が控除されるため、分配可能額 ＝ `570,000 － 90,000` ＝ **480,000円**）。

> **誤答パターン分析**：その他有価証券評価差額金がマイナス（借方残）のとき、分配可能額から引き忘れるミス（プラス＝貸方残なら不加算だが、マイナス＝借方残なら必ず控除する！）。
