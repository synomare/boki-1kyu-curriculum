## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

2級では、社債や満期保有目的債券の金利調整差額を毎年均等に配分する「定額法」を学びました。しかし、定額法は「借入元本（帳簿価額）が毎年増えているのに毎年の利息額を同じにする」ため、経済的実態（複利計算＝残高に比例して利息が増える）を歪めます。そこで1級では原則法である**「利息法（実効利子率法）」**を適用し、帳簿価額の増加に合わせて毎期の利息を厳密に認識します。

また、その他有価証券の時価が50%以上暴落したときは「単なる一時的な揺れ」とはみなせないため**減損処理（P/L損失確定）**を行います。さらに、社債に株式へ転換できる権利が付いた**「転換社債型新株予約権付社債（CB）」**では、負債（社債）と純資産（新株予約権）をどう切り分けるか（一括法 vs 区分法）が会計理論上の重要な論点となります。

- **利息法の本質**：実効利子率 `r` を期首帳簿価額に乗じたものがその期の経済的実質利息であり、クーポン（現金利息）との差額が元本調整（償却原価の増減）となる。
- **減損の本質**：時価が著しく下落（概ね50%以上）し回復可能性が認められない場合、評価差額金（OCI）に隠れていた含み損を強制的にP/L（有価証券評価損）へ吐き出させる（切放し法）。
- **CB（一括法 vs 区分法）の本質**：新株予約権を行使すると社債は消滅するため経済的には一体とも見なせるが（一括法）、発行時の資金調達対価を負債と純資産に分解して表示する（区分法）ことで負債の過大表示を防ぐこともできる。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 満期保有目的債券の利息法（3年・実効5%）と標準仕訳

**【例題】** X1年4月1日、額面1,000,000円（クーポン年3%＝年30,000円、利払年1回3/31、満期3年）の社債を実効利子率年5%で割引購入し、満期保有目的債券に分類した（端数円未満四捨五入、最終期は額面一致調整）。
- 取得価額（X1/4/1）＝ `30,000÷1.05 ＋ 30,000÷1.05^2 ＋ 1,030,000÷1.05^3` ＝ **945,535円**
- X1年度（X2/3/31）：利息 `945,535 × 5% = 47,277円`、償却額 `47,277 － 30,000 = 17,277円` → 期末 **962,812円**
- X2年度（X3/3/31）：利息 `962,812 × 5% = 48,141円`、償却額 `48,141 － 30,000 = 18,141円` → 期末 **980,953円**
- X3年度（X4/3/31）：償却額 `1,000,000 － 980,953 = 19,047円` → 利息 `30,000 ＋ 19,047 = 49,047円`（検算：`980,953 × 5% = 49,047.65`）

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① X1/4/1 取得 | 満期保有目的債券 | 945,535 | 現金預金 | 945,535 |
| ② X2/3/31 利払・償却 | 現金預金 | 30,000 | 有価証券利息 | 47,277 |
|  | 満期保有目的債券 | 17,277 |  |  |
| ③ X3/3/31 利払・償却 | 現金預金 | 30,000 | 有価証券利息 | 48,141 |
|  | 満期保有目的債券 | 18,141 |  |  |

### 【1級貫通・標準下書きフォーマット】型04：償却原価（利息法）テーブル

```text
  | 期 | 期首簿価(A) | 実効利息(B=A×5%) | クーポン(C) | 償却額(D=B-C) | 期末簿価(A+D) |
  |---:|------------:|-----------------:|------------:|--------------:|--------------:|
  | X1 |     945,535 |           47,277 |      30,000 |        17,277 |       962,812 |
  | X2 |     962,812 |           48,141 |      30,000 |        18,141 |       980,953 |
  | X3 |     980,953 |           49,047 |      30,000 |        19,047 |     1,000,000 |
```

**手順**：
1. 「期首簿価」「実効利息（期首×実効率）」「クーポン」「償却額」「期末簿価」の5列テーブルを描く。
2. 投資家側（債券）も発行者側（社債）も全く同じ構造で、最終期だけ額面1,000,000円にぴったり一致するよう償却額から逆算調整する。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（1級）】
- 満期保有目的債券および発行社債の**利息法**（途中の買入償還・売却損益含む）。
- **有価証券の減損処理**：市場価格のある株式等（50%以上下落は原則減損、切放し法）と市場価格のない株式等（実質価額の50%以上低下で減損）。
- **保有目的区分の変更**（売買→その他、その他→満期保有、子会社株式への変更など）の振替時点時価処理。
- **転換社債型新株予約権付社債（CB）**の一括法と区分法（社債部分の償却原価法＋権利行使時資本組入）。

### 【未来の拡張フック（1級本試験・外貨・連結）】
- **外貨建有価証券（`L1C-12`）**：外貨ベースで利息法や減損判定を行い、決算時為替レート（CR）等で円換算する（為替差損益と評価損・評価差額金の切り分け）。
- **その他有価証券評価差額金の税効果・連結（`L1C-11`, `L1C-14`）**：減損損失を計上した場合、税務上は損金不算入となることが多く、繰延税金資産の回収可能性が問われる。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 満期保有・社債（利息法） | その他有価証券の減損 | CB（一括法 vs 区分法） |
|---|---|---|---|
| **評価・償却基準** | 償却原価法（利息法・実効利子率ベース） | 時価50%以上下落→強制減損（切放し法） | 一括法：全額「新株予約権付社債」<br>区分法：「社債」＋「新株予約権」 |
| **試験官の罠** | クーポン率と実効利子率を逆に掛けるミス、または期首簿価ではなく額面に実効利子率を掛けてしまうミス | 前期に計上していた評価差額金（OCI）を洗替せず、減損後の時価と前期末時価の差額だけ損失にするミス（正しくは**当初取得原価と当期末時価の差額**が評価損） | 区分法で社債部分を償却原価法で増額した後、権利行使時に**償却後の社債簿価＋新株予約権**を資本金へ振り替え忘れるミス |

> **出題者の意図**：特に**その他有価証券の減損（問2）**で、前期末時価（洗替前）からの下落額ではなく**「取得原価（500,000円）と当期末時価（220,000円）の差額280,000円」**がP/Lの有価証券評価損になる点（前期のOCIは期首に洗替済だから！）を確実に突いてくる。

## 5. 思考力ドリル（問題編）

### 問1（基礎・型定着：発行者側社債の利息法と買入償還）
当社はX1年4月1日に社債（額面1,000,000円、クーポン年2%＝年20,000円、利払年1回3/31、償還期間3年）を実効利子率年5%の条件で **918,303円** にて発行した（利息法適用、円未満四捨五入）。
X3年3月31日（X2年度末）の第2回利払直後に、当社はこの社債のすべてを額面100円につき96円（960,000円）で買い入れて償還し、現金を支払った。

1. X1年度末（X2/3/31）の社債利息および社債期末帳簿価額を求めよ。
2. X2年度末（X3/3/31）の利払・利息計上仕訳および買入償還仕訳を示せ。

### 問2（本試験標準・ひっかけ対応：有価証券の減損と保有目的変更）
X2年度末（X3/3/31）における以下の3銘柄（すべて独立、法定実効税率30%、全部純資産直入法）について、X2年度の必要な仕訳およびP/L計上額を求めよ。

- **(A) その他有価証券X（市場価格あり）**：X1年度に500,000円で取得。X1年度末の時価は440,000円（評価差額金-42,000円・繰延税金資産18,000円を計上し、X2期首に再振替済）。X2年度末の時価は220,000円に下落（回復の見込みなし）。
- **(B) その他有価証券Y（市場価格のない株式）**：1,000,000円で取得。X2年度末の発行会社財務諸表に基づく1株あたり純資産額等から算定した実質価額は400,000円（回復可能性なし）。
- **(C) 売買目的有価証券Z**：X2期首帳簿価額300,000円。X2年度中に運用方針の見直しにより、保有目的を売買目的からその他有価証券へ変更した（変更時の時価は340,000円、変更後X2末時価も340,000円）。

### 問3（1級視点・応用思考：転換社債型新株予約権付社債の一括法 vs 区分法）
当社はX1年4月1日に転換社債型新株予約権付社債（額面1,000,000円、払込金額1,050,000円、償還期間5年、無利息）を発行した。発行時の社債の対価部分は980,000円、新株予約権の対価部分は70,000円と算定された（社債差額は定額法で償却する）。
1年後のX2年4月1日（X1年度決算後）に、社債権者から**全額について新株予約権の行使**があり、全額を資本金に組み入れた。

1. **一括法**を採用した場合の、発行時・X1期末・X2権利行使時の仕訳および増加資本金額を示せ。
2. **区分法**を採用した場合の、発行時・X1期末（社債利息償却）・X2権利行使時の仕訳および増加資本金額を示せ。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

**【下書き再現：型04 償却表（発行社債・利息法）】**
- X1末：社債利息 `918,303 × 5% ＝ 45,915.15` → **45,915円**、償却額 `45,915 － 20,000 ＝ 25,915円` → X1末簿価 `918,303 ＋ 25,915` ＝ **944,218円**
- X2末：社債利息 `944,218 × 5% ＝ 47,210.9` → **47,211円**、償却額 `47,211 － 20,000 ＝ 27,211円` → X2末簿価 `944,218 ＋ 27,211` ＝ **971,429円**
- 買入償還：償還直前簿価 `971,429円` － 買入価額 `960,000円` ＝ **社債償還益 11,429円**

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| X1末 利払・利息 | 社債利息 | 45,915 | 現金預金 | 20,000 |
|  |  |  | 社債 | 25,915 |
| X2末 利払・利息 | 社債利息 | 47,211 | 現金預金 | 20,000 |
|  |  |  | 社債 | 27,211 |
| X2末 買入償還 | 社債 | 971,429 | 現金預金 | 960,000 |
|  |  |  | 社債償還益 | 11,429 |

> **誤答パターン分析**：買入償還時の社債簿価にX2年度の償却額27,211円を加算し忘れる（X1末の944,218円を使って社債償還損と誤答する）ミス。

### 問2 解答・解説

- **(A) 市場価格のあるその他有価証券の減損**：取得原価500,000円から56%（50%以上）下落しているため減損処理（切放し法）。X2期首に前期評価差額金は洗替済なので、P/L計上額 ＝ `500,000 － 220,000` ＝ **投資有価証券評価損 280,000円**。
- **(B) 市場価格のない株式の減損**：実質価額が50%以上（60%）低下しているため減損処理。`1,000,000 － 400,000` ＝ **投資有価証券評価損 600,000円**。
- **(C) 保有目的変更（売買→その他）**：変更時の時価340,000円を新たな取得原価とし、簿価300,000円との差額 **有価証券運用損益（評価益）40,000円** をP/L認識する。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| (A) 減損処理 | 投資有価証券評価損 | 280,000 | 投資有価証券 | 280,000 |
| (B) 減損処理 | 投資有価証券評価損 | 600,000 | 投資有価証券 | 600,000 |
| (C) 保有目的変更 | 売買目的有価証券 | 40,000 | 有価証券運用損益 | 40,000 |
|  | 投資有価証券 | 340,000 | 売買目的有価証券 | 340,000 |

> **誤答パターン分析**：(A)で前期末時価440,000円との差額220,000円だけを評価損にしてしまうミス。洗替法を採用しているため、減損時は必ず当初取得原価500,000円と比較する。

### 問3 解答・解説

1. **一括法**：発行時1,050,000円をすべて負債（転換社債型新株予約権付社債）とし、額面超過分等の償却は行わず、全額行使で **資本金 1,050,000円** を増加させる。
2. **区分法**：
   - 発行時：社債 **980,000円**（負債）、新株予約権 **70,000円**（純資産）。
   - X1期末（1年経過）：社債差額 `(1,000,000 － 980,000) ÷ 5年 ＝ 4,000円` を定額償却 → 社債簿価 **984,000円**。
   - X2権利行使時：社債984,000円＋新株予約権70,000円 ＝ **資本金 1,054,000円**。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 一括法・発行 | 現金預金 | 1,050,000 | 新株予約権付社債 | 1,050,000 |
| 一括法・行使 | 新株予約権付社債 | 1,050,000 | 資本金 | 1,050,000 |
| 区分法・発行 | 現金預金 | 1,050,000 | 社債 | 980,000 |
|  |  |  | 新株予約権 | 70,000 |
| 区分法・X1末償却 | 社債利息 | 4,000 | 社債 | 4,000 |
| 区分法・行使 | 社債 | 984,000 | 資本金 | 1,054,000 |
|  | 新株予約権 | 70,000 |  |  |

> **誤答パターン分析**：区分法でX1期末の社債償却4,000円を忘れ、行使時の資本金増加額を一括法と同じ1,050,000円にしてしまうミス。
