## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

百貨店・スーパー・アパレルなど何万点もの商品を扱う小売業では、個別に原価を追跡するのが不可能です。そこで、値札（売価）ベースで期末棚卸高をカウントし、そこに「原価率」を掛けて期末原価を逆算するのが**売価還元法**です。このとき「値下（バーゲン値引き）」を原価率の分母から除くか残すかで、通常の原価法と低価法（値下商品の評価切下げを自動反映）が鮮やかに分かれます。

また、現代ビジネスの収益認識（企業会計基準第29号）は単なる「モノを渡した瞬間の売上」では測れません。①**ポイント付与**は将来の割引サービスの「前受（契約負債）」であり、②**返品権付販売**は「返金が予想される分は最初から売上にしてはいけない（返金負債）」、③**百貨店の消化仕入や仲介サイト（代理人）**は「総額ではなく純額の手数料だけが真の売上」、④**長期割賦（重要な金融要素）**は「代金の中に隠れた金利（受取利息）を分離する」という**経済的実態の徹底解剖**が求められます。

- **売価還元法（低価法 vs 原価法）の本質**：分母に「正味値下額」を含めないと原価率が下がり、期末商品の評価額が下がる（＝値下商品の正味売却価額低下＝低価法評価減を自動実現する）。
- **収益認識の核心（支配の移転）**：約束した財・サービスを顧客に移転した時に、企業が権利を得ると見込む対価の額で収益を認識する（5ステップ）。
- **工事損失引当金の本質**：工事進行中に総見積原価が受注収益を上回り**赤字（損失）が確実視**されたら、まだ工事が進んでいない未来の損失部分まで当期に前倒しで引当計上する（保守主義の原則）。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 売価還元法（低価法 vs 原価法）と収益認識の標準仕訳

**【例題（売価還元法）】** 期首商品（原価120,000円、売価200,000円）、当期仕入（原価600,000円、売価950,000円）、原始値入後：純値上額50,000円、純値下額200,000円、当期売上高700,000円。
- 期末商品売価 ＝ `200,000 ＋ 950,000 ＋ 50,000 － 200,000 － 700,000` ＝ **300,000円**
- 原価合計（分子）＝ `120,000 ＋ 600,000` ＝ **720,000円**
- **売価還元低価法**（分母から純値下200kを除く）：分母 `200k＋950k＋50k = 1,200,000円` → 原価率 `720k ÷ 1,200k` ＝ **60%** → 期末商品原価 ＝ `300,000 × 60%` ＝ **180,000円**
- **売価還元原価法**（分母に純値下200kを含める）：分母 `1,200k － 200k = 1,000,000円` → 原価率 `720k ÷ 1,000k` ＝ **72%** → 期末商品原価 ＝ `300,000 × 72%` ＝ **216,000円**

| 取引（売価還元低価法・決算） | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 期首繰越振替 | 仕入 | 120,000 | 繰越商品 | 120,000 |
| ② 期末商品計上(60%) | 繰越商品 | 180,000 | 仕入 | 180,000 |

※売上原価 ＝ `120,000 ＋ 600,000 － 180,000 ＝ 540,000円`（なお、原価法216,000円との差額36,000円が値下に伴う実質的な評価減に相当する）。

### 【1級貫通・標準下書きフォーマット】型02・型04（売価還元ボックス＋収益5ステップ図）

```text
  [ 売価還元ボックス (売価ベース) ]      [ 原価率の比較 ]
  ---------------------+-------------    分子(原価): 120k + 600k = 720,000円
  期首売価     200,000 | 売上 700,000
  仕入売価     950,000 |                 [低価法] 分母 = 1,200,000 -> 60%
  純値上額      50,000 | 期末 300,000     => 期末 300k × 60% = 180,000円
  (△純値下額 -200,000)|                 [原価法] 分母 = 1,000,000 -> 72%
  ---------------------+-------------     => 期末 300k × 72% = 216,000円
  計         1,000,000 | 計 1,000,000
```

**手順**：
1. 売価ボックスで「期末売価（300,000円）」を確定する（実地棚卸がある場合は帳簿売価との差額＝売価棚卸減耗にも原価率を乗じる）。
2. 低価法なら「値下前売価合計（1,200k）」、原価法なら「値下後売価合計（1,000k）」を分母にして原価率を出す。

## 4. 試験官の罠・混同しやすい論点の対比表

| 収益認識論点 | 収益計上の原則 | 対照・関連B/S科目 | 試験官の罠 |
|---|---|---|---|
| **ポイント付与** | 独立販売価格の比率で商品売上とポイント（契約負債）に配分 | 契約負債（負債） | 付与ポイント額100%をそのまま引当金のように費用＋負債にするミス |
| **返品権付販売** | 返品予想分は売上・売原から除外し、純額のみ認識 | 返金負債（負債）・返品資産（資産） | 売価100%の返金負債だけでなく、**原価ベースの返品資産**を忘れやすい |
| **本人 vs 代理人** | 在庫リスク・価格決定権なし＝代理人（手数料のみ純額） | 買掛金/売掛金（受託等） | 受取額全額を売上・仕入で総額処理してしまう罠 |
| **工事損失引当金** | 総見積損失 － 既に計上済の損失（または＋利益） ＝ 引当額 | 工事損失引当金（負債） | 当期に既に認識した赤字（例：-100k）を引かずに総損失（-200k）全額を引当計上してしまう二重計上ミス |

> **出題者の意図**：特に**工事損失引当金（問2）**の「すでに当期P/L（売上1,000k − 原価1,100k = -100k）で認識した赤字を差し引いて、残りの未認識赤字100,000円だけを引き当てる」計算と、**重要な金融要素（問3）**の「販売時は現金販売価格1,000,000円だけが売上になり、差額102,500円は2年間の受取利息になる」構造が狙われる。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

- **(A) ポイント制度**：
  - 独立販売価格合計 ＝ `100,000 ＋ 25,000 ＝ 125,000円`
  - 商品への配分：`100,000 × (100,000 ÷ 125,000)` ＝ **80,000円**（売上）
  - ポイントへの配分：`100,000 × (25,000 ÷ 125,000)` ＝ **20,000円**（契約負債）
  - X2年度使用時：契約負債20,000円を取り崩して **売上 20,000円** を認識する。
- **(B) 返品権付販売**：
  - 返品されない90個分のみ収益・原価認識：`売上 90,000円`、`売上原価 54,000円`。
  - 返品予想10個分：`返金負債 10,000円`（負債）、`返品資産 6,000円`（商品からの振替資産）。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| (A) X1販売・付与 | 現金預金 | 100,000 | 売上 | 80,000 |
|  |  |  | 契約負債 | 20,000 |
| (A) X2ポイント使用 | 契約負債 | 20,000 | 売上 | 20,000 |
| (B) 返品権付売上 | 売掛金 | 100,000 | 売上 | 90,000 |
|  |  |  | 返金負債 | 10,000 |
| (B) 返品権付原価 | 売上原価 | 54,000 | 商品 | 60,000 |
|  | 返品資産 | 6,000 |  |  |

> **誤答パターン分析**：(A)で100,000円全額を売上にしてポイント25,000円を販管費＋引当金にする旧基準の誤答、および(B)で返品資産6,000円を認識し忘れるミス。

### 問2 解答・解説

- **X1年度 進捗度** ＝ `実際原価 1,100,000 ÷ 総見積原価 2,200,000 ＝ 50%`
- **X1年度 工事収益（売上高）** ＝ `2,000,000 × 50%` ＝ **1,000,000円**（相手勘定：契約資産）
- **X1年度 工事原価** ＝ **1,100,000円**（ここまでで既に認識済の工事損失＝ `-100,000円`）
- **見込まれる総損失** ＝ `工事収益総額 2,000,000 － 総見積原価 2,200,000 ＝ -200,000円`
- **工事損失引当金繰入額** ＝ `総損失 200,000 － 当期認識済損失 100,000` ＝ **100,000円**（X2年度に発生する残りの赤字を前倒し計上）

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 工事原価発生 | 未成工事支出金 | 1,100,000 | 諸口 | 1,100,000 |
| ② 収益・原価認識 | 契約資産 | 1,000,000 | 完成工事高 | 1,000,000 |
|  | 完成工事原価 | 1,100,000 | 未成工事支出金 | 1,100,000 |
| ③ 引当金計上 | 工事損失引当金繰入 | 100,000 | 工事損失引当金 | 100,000 |

> **誤答パターン分析**：工事損失引当金を総損失の200,000円全額計上してしまい、P/L損失合計が300,000円（二重計上）になるミス。

### 問3 解答・解説

- **(A) 代理人取引**：当社は手配の履行義務のみを負う代理人であるため、手数料 `500,000 × 10%` ＝ **50,000円** のみを売上（純額）とし、メーカーへの支払額450,000円は預り金の精算とする。
- **(B) 重要な金融要素**：
  - X1/4/1 引渡時：現金販売価格 **1,000,000円** で **売上**（契約資産／売掛金1,000,000円）および **売上原価 700,000円** を認識。
  - X2/3/31（X1末）：`1,000,000 × 5%` ＝ **受取利息 50,000円**（債権残高 1,050,000円）。
  - X3/3/31（X2末）：`1,050,000 × 5%` ＝ **受取利息 52,500円**、現金 **1,102,500円** 回収。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| (A) 代理人仲介 | 現金預金 | 500,000 | 売上（手数料収益） | 50,000 |
|  |  |  | 現金預金（または未払金） | 450,000 |
| (B) X1/4/1 引渡 | 売掛金 | 1,000,000 | 売上 | 1,000,000 |
|  | 売上原価 | 700,000 | 商品 | 700,000 |
| (B) X2/3/31 利息 | 売掛金 | 50,000 | 受取利息 | 50,000 |
| (B) X3/3/31 回収 | 現金預金 | 1,102,500 | 売掛金 | 1,050,000 |
|  |  |  | 受取利息 | 52,500 |

> **誤答パターン分析**：(B)で将来の受取総額1,102,500円をそのまま売上高にしてしまうミス。重要な金融要素が含まれる場合、利息相当額102,500円は必ず売上高から切り離して時の経過に応じて受取利息とする。
