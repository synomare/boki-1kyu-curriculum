## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

先物・オプション・金利スワップなどのデリバティブ（金融派生商品）は、契約時点の元本が小さくても将来莫大な損益を生むリスクがあるため、原則として**決算時に必ず時価評価して差額をP/Lに計上（時価評価原則）**し、オフバランス（簿外リスク）を防ぎます。

しかし、企業が保有資産の値下がりリスクや将来の原材料高騰リスクを打ち消す目的でデリバティブを使う場合（ヘッジ取引）、**「ヘッジ手段（先物等）の評価損益だけが当期P/Lに出て、ヘッジ対象（予定仕入やその他有価証券）の損益は翌期以降（または純資産）にズレる」**という会計上のミスマッチ（架空の利益・損失ブレ）が生じます。これを解消し、ヘッジ対象とヘッジ手段の損益を**同じ期間のP/Lにぶつける**ための特別ルールが**ヘッジ会計**です。

- **繰延ヘッジ（原則）**：ヘッジ手段（先物等）の評価損益をP/Lに出さず、いったん純資産の**「繰延ヘッジ損益（税引後）」**にプールしておき、ヘッジ対象の損益が実現する期にP/Lへ解放（または取得原価に加減）する。
- **時価ヘッジ（例外・その他有価証券専用）**：すでにB/Sにあるその他有価証券の評価差額を特例としてP/Lへ出し、先物の評価損益とP/L上で相殺する。
- **金利スワップの特例処理**：変動金利借入の金利を固定化するスワップのうち一定要件を満たすものは、時価評価すら省略し「借入金とスワップが最初から固定金利借入1本だったかのように」支払利息を純額処理する。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 予定取引の繰延ヘッジ（取得原価調整）と標準仕訳

**【例題】** 当社（税率30%）はX2年5月10日に購入予定の材料について、価格高騰リスクを回避するためX1年12月1日に商品先物（買建・契約額1,000,000円）を契約し、繰延ヘッジを適用した。
- **X2/3/31（決算日）**：先物時価が1,100,000円へ上昇（先物評価益 **+100,000円**）。繰延ヘッジ損益（税引後70,000円）＋繰延税金負債（30,000円）として純資産へ繰り延べる。
- **X2/5/10（決済・材料購入）**：先物を1,120,000円で反対売買し、決済差金現金120,000円を受け取ると同時に、高騰した材料を1,120,000円で購入した。先物の利益120,000円を材料の取得原価から控除（直接減額）する結果、実質的な材料取得原価は当初予定どおり **1,000,000円** となる。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① X2/3/31 決算（繰延） | 先物資産 | 100,000 | 繰延ヘッジ損益 | 70,000 |
|  |  |  | 繰延税金負債 | 30,000 |
| ② X2/5/10 決済（+20k追加） | 現金預金 | 120,000 | 先物資産 | 100,000 |
|  |  |  | 繰延ヘッジ損益 | 14,000 |
|  |  |  | 繰延税金負債 | 6,000 |
| ③ X2/5/10 材料購入・取崩 | 材料 | 1,120,000 | 現金預金 | 1,120,000 |
|  | 繰延ヘッジ損益 | 84,000 | 材料 | 120,000 |
|  | 繰延税金負債 | 36,000 |  |  |

### 【1級貫通・標準下書きフォーマット】型01：ヘッジ会計・時間軸＆損益対応表

```text
  X1/12/1           X2/3/31 (決算)             X2/5/10 (決済・材料購入)
  ---+------------------+--------------------------+-----------------> 時間
     | 先物買建 1,000k  | 時価 1,100k (+100k)      | 決済 1,120k (+120k現金)
     | (証拠金等は略)   | [繰延] B/S先物 +100k     | 材料購入 1,120k
     |                  |        純資産 +70k       | ヘッジ控除 -120k
     |                  |        DTL    +30k       | => 実質材料原価 1,000k
```

**手順**：
1. タイムライン上にヘッジ対象（材料・有価証券・借入）とヘッジ手段（先物・スワップ・オプション）を並べる。
2. 決算時点で「原則（P/L認識）」か「繰延ヘッジ（純資産＋税効果）」か「時価ヘッジ（その他有価証券をP/Lへ）」かを判定し、決済時に純資産（繰延ヘッジ損益＋DTL/DTA）をすべて取り崩す。

## 4. 試験官の罠・混同しやすい論点の対比表

| 比較項目 | 繰延ヘッジ（原則） | 時価ヘッジ（容認・その他有価証券のみ） |
|---|---|---|
| **対象となるヘッジ対象** | 予定取引・有価証券・外貨建等（広範囲） | **その他有価証券のみ** |
| **ヘッジ手段の評価損益** | 純資産（**繰延ヘッジ損益**・税効果あり）へ繰延 | 当期P/Lへ計上 |
| **ヘッジ対象の評価差額** | 通常どおり（その他有価証券なら評価差額金） | **当期P/Lへ計上**（先物とP/L相殺） |

> **出題者の意図**：①その他有価証券の時価ヘッジなのに、予定取引と同じく「繰延ヘッジ損益」を使ってしまうミス、②繰延ヘッジ損益に**税効果（DTA/DTL）を掛け忘れるミス**、③金利スワップの特例処理で、わざわざ与えられた期末スワップ時価評価額を仕訳に入れてしまうミスを狙う。

2. **時価ヘッジ**を適用した場合のX1年度末決算整理仕訳と、P/L（当期損益）への純影響額を示せ。

### 問2（本試験標準・ひっかけ対応：金利スワップの原則処理 vs 特例処理）

X2年3月31日（X1年度末）において、借入金利息400,000円の支払いとスワップの純受取額100,000円の受領が完了した。なお、X2年3月31日における金利スワップの時価評価額は **+200,000円（資産）** であった。

1. **原則処理（繰延ヘッジ）**を採用した場合の、X1年度のP/L支払利息およびX1年度末B/S計上項目（スワップ資産・繰延ヘッジ損益・DTL）を求めよ。
2. **特例処理**を採用した場合の、X1年度のP/L支払利息およびX1年度末B/Sのスワップ評価処理について答えよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

1. **繰延ヘッジ**：その他有価証券は通常どおり評価差額金(-56,000円)とDTA(24,000円)、先物は繰延ヘッジ損益(+56,000円)とDTL(24,000円)とする。純資産合計への純影響額は `-56,000 ＋ 56,000` ＝ **0円**（P/L影響も0円）。
2. **時価ヘッジ**：その他有価証券の評価損-80,000円と先物の評価益+80,000円の両方を当期P/Lに計上する。P/L純影響額 ＝ `-80,000 ＋ 80,000` ＝ **0円**（純資産影響も0円）。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 繰延ヘッジ（証券） | その他有価証券評価差額金 | 56,000 | その他有価証券 | 80,000 |
|  | 繰延税金資産 | 24,000 |  |  |
| ① 繰延ヘッジ（先物） | 先物資産 | 80,000 | 繰延ヘッジ損益 | 56,000 |
|  |  |  | 繰延税金負債 | 24,000 |
| ② 時価ヘッジ（証券） | 投資有価証券評価損（ヘッジ損） | 80,000 | その他有価証券 | 80,000 |
| ② 時価ヘッジ（先物） | 先物資産 | 80,000 | 先物評価益 | 80,000 |

> **誤答パターン分析**：時価ヘッジのときに税効果（DTA/DTL）を計上してしまうミス。時価ヘッジでは双方P/L損益として相殺されるため、評価差額金や繰延ヘッジ損益の一時差異は発生しない。

### 問2 解答・解説

1. **原則処理（繰延ヘッジ）**：
   - **P/L 支払利息**：借入利息 `400,000` － スワップ純受取 `100,000` ＝ **300,000円**
   - **B/S（X1末）**：スワップ資産 **200,000円**、繰延ヘッジ損益（純資産）**140,000円**、繰延税金負債 **60,000円**
2. **特例処理**：
   - **P/L 支払利息**：**300,000円**（原則と同額）
   - **B/S（X1末）**：**金利スワップの時価評価（200,000円）を行わない（B/S計上額0円）**。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 原則：利息・純受取 | 支払利息 | 300,000 | 現金預金 | 300,000 |
| 原則：スワップ時価 | 金利スワップ資産 | 200,000 | 繰延ヘッジ損益 | 140,000 |
|  |  |  | 繰延税金負債 | 60,000 |
| 特例：利息のみ | 支払利息 | 300,000 | 現金預金 | 300,000 |

> **誤答パターン分析**：特例処理の問題で問題文に「期末時価200,000円」と書いてあると、ついスワップ資産を計上してしまうミス（典型的なダミー資料の罠）。

---

### 問3 解答・解説

- 購入時オプション簿価 50,000円 → 期末公正価値 130,000円（オプション評価増 **+80,000円**）。
1. **全体指定**：評価増80,000円の全額を繰延ヘッジの対象とする → **繰延ヘッジ損益 56,000円**、繰延税金負債 24,000円。
2. **本源的価値のみ指定**：
   - 本源的価値の変動：`100,000 － 0 ＝ +100,000円` → 繰延ヘッジ対象（税引後 **繰延ヘッジ損益 70,000円**、繰延税金負債 30,000円）。
   - 時間的価値の変動：`30,000 － 50,000 ＝ -20,000円` → ヘッジ指定外のため当期P/L処理（**オプション評価損 20,000円**）。
   - 検算：`借方(資産増80,000 ＋ 評価損20,000 = 100,000) ＝ 貸方(繰延ヘッジ70,000 ＋ DTL30,000 = 100,000)` で完全一致！

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 全体指定 | オプション資産 | 80,000 | 繰延ヘッジ損益 | 56,000 |
|  |  |  | 繰延税金負債 | 24,000 |
| ② 本源的価値のみ指定 | オプション資産 | 80,000 | 繰延ヘッジ損益 | 70,000 |
|  | オプション評価損 | 20,000 | 繰延税金負債 | 30,000 |

> **誤答パターン分析**：②で資産の増加額80,000円に引きずられ、時間的価値の減少-20,000円をP/Lに落とさず繰延ヘッジ損益と相殺してしまうミス。オプションの本源的価値(+100k)と時間的価値(-20k)を必ず別々に追跡せよ。
