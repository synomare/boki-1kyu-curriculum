## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

旧基準では、所有権移転外のオペレーティング・リースは「賃貸借処理（オフバランス）」とされ、B/Sに借金（将来の支払義務）が一切載りませんでした。しかし、解約不能な長期リースで店舗や飛行機を借りている実質は「ローンを組んで数年間その資産を使う権利を買った」のと変わりません。そこで**企業会計基準第34号（新リース会計基準）**は、2級（`L2C-05`）で学んだとおり借手のリースを原則すべてオンバランスする**使用権モデル**を採用しました。

1級では、この「使用権モデル」を実務の複雑な契約形態へ貫通させます。①延長オプションを織り込んだ**リース期間の決定**、②期中に賃料や期間が変わったときの**リースの契約変更（再測定）**、③自社ビルを売ってそのまま借り続ける**セール・アンド・リースバック（S&LB）**（売却できた部分だけ売却益を認める）、④又貸しである**サブリース**（中間貸手は「原資産」ではなく自分の持つ「使用権資産」の耐用年数等で分類判定する）、⑤**貸手の会計処理**（ファイナンス・リースの3方法）まで、すべてが1つのロジックで繋がります。

- **借手・条件変更の本質**：新たな条件で計算し直したリース負債の増減額をそのまま**使用権資産の帳簿価額に加減**する（範囲の縮小を伴う一部解約以外は、原則P/Lに損益を出さず残存期間で償却調整）。
- **セール・アンド・リースバックの本質**：建物（100%）を売って40%相当の権利をリースバックで保持したなら、真に他社へ移転した権利は**60%分だけ**。よって売却益も全体ではなく移転した60%分だけを認識し、使用権資産は元簿価の40%だけ引き継ぐ。
- **サブリースの本質**：ヘッドリース（借手）とサブリース（貸手）は別個の契約として処理し、中間貸手は「原資産（例：耐用年数50年のビル）」ではなく「自分が保有する**使用権資産**（例：リース期間5年）」をベースにファイナンスかオペレーティングかを判定する。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 借手・利息法＆リース条件変更（ゼロ端数モデル）

**【例題】** X1年4月1日に機械のリース契約（解約不能3年、年間リース料 399,300円・各3/31後払い、追加借入利子率年 10%、所有権移転なし、定額法）を締結した。
- **開始日（X1/4/1）**：PV ＝ `399,300÷1.10 ＋ 399,300÷1.10^2 ＋ 399,300÷1.10^3` ＝ `363,000 ＋ 330,000 ＋ 300,000` ＝ **993,000円**（使用権資産・リース負債計上、年償却 `331,000円`）。
- **X1末（X2/3/31）**：支払利息 `993,000 × 10% ＝ 99,300円`、元本返済 `399,300 － 99,300 ＝ 300,000円` → X1末負債残 `693,000円`、使用権資産残 `662,000円`。
- **X1末 リースの条件変更**：X2/3/31に賃料を年間 **330,750円** へ改定した（変更時の割引率年 **5%**、残存2年）。
  - 新リース負債 ＝ `330,750÷1.05 ＋ 330,750÷1.05^2` ＝ `315,000 ＋ 300,000` ＝ **615,000円**。
  - 負債減少額 ＝ `615,000 － 693,000` ＝ **-78,000円** → 使用権資産を78,000円減額し **584,000円** とする（X2・X3年の償却は各 `292,000円`）。
  - X2末利息 `615,000 × 5% = 30,750円`（元本 `300,000`、負債残 `315,000`）、X3末利息 `315,000 × 5% = 15,750円`（元本 `315,000`、負債残 `0`）。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（1級）】
- **リース期間の決定**：解約不能期間 ＋ 行使することが合理的に確実な延長オプション期間（＋行使しないことが合理的に確実な解約オプション期間）。
- **開始日の使用権資産測定**：`リース負債 ＋ 開始日以前の前払リース料 ＋ 当初直接費用 － 受け取ったリース・インセンティブ`（＋原状回復ARO）。
- **契約変更（条件変更）**の再測定計算。
- **セール・アンド・リースバック（S&LB）**：売却に該当する場合の「保持割合による使用権資産引継・移転割合による売却益制限」と、売却に該当しない金融取引処理。
- **貸手のファイナンス・リース3方法**および**サブリースの判定基準**。

### 【未来の拡張フック（1級本試験・総合問題）】
- **借地権を含む不動産リース（基準第34号の特則）**：旧来オフバランスだった定期借地権等も新基準ではオンバランス対象となるが、権利金や更新料・原状回復義務の組み込み方が実務・試験の重要論点となる。
- **連結CF計算書との連動（`L1C-14`）**：使用権資産・リース負債の計上自体は非資金取引だが、毎期のリース負債元本返済額は「財務活動によるキャッシュ・フロー」に、利息支払額は「営業活動（または財務活動）」に区分される。

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 正しい基準（ASBJ第34号） | 試験官の典型的な罠 |
|---|---|---|
| **使用権資産の開始日計上額** | リース負債 ＋ 前払リース料 ＋ 当初直接費用 － インセンティブ | 当初直接費用（仲介手数料等）を支払時にP/L費用処理したり、リース負債に含めてしまうミス |
| **S&LB（売却該当時）の売却益** | `(公正価値 － 帳簿価額) × (公正価値 － リース負債PV) ÷ 公正価値` | 売却価額と簿価の差額100%をそのまま固定資産売却益にしてしまうミス |
| **サブリース（中間貸手）の分類** | 自分が持つ **「使用権資産」** を基準にファイナンス/オペレーティング判定 | 大元のオーナーが持つ「原資産（例：建物50年）」の耐用年数で判定してしまうミス |
| **貸手の3方法の選択** | 第1法（販売益一括）・第2法（割賦基準的繰延）・第3法（金融型：売上計上なし） | 第2法で利息部分（41,000円）まで売上高に含めたり、第3法で製品売上高を計上してしまうミス |

> **出題者の意図**：特に**S&LBの売却益計算（問2）**で、なぜ売却益が制限されるのか（自分にリースバックした40%部分は権利を手放していないから！）を理解せず丸暗記している受験生を、売却価額やリース条件を少し変えた問題で確実に見分ける。

### 問2 解答・解説

1. **ケース(A) 売却に該当する場合**
   - 保持割合 ＝ `リースバックPV 400,000 ÷ 公正価値 1,000,000 ＝ 40%`、移転割合 ＝ `60%`。
   - **使用権資産** ＝ `旧建物簿価 600,000 × 40%` ＝ **240,000円**
   - **リース負債** ＝ **400,000円**
   - **固定資産売却益** ＝ `(公正価値 1,000,000 － 簿価 600,000) × 移転割合 60%` ＝ **240,000円**（残りの保持40%相当の含み益160,000円は認識しない）。
2. **ケース(B) 金融取引に該当する場合**
   - 売手兼借手は建物の認識を中止せず（簿価600,000円のまま維持）、受け取った現金1,000,000円は**金融負債（長期借入金等）**として処理する。売却益は **0円**。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| (A) 売却該当 | 現金預金 | 1,000,000 | 建物 | 600,000 |
|  | 使用権資産 | 240,000 | リース負債 | 400,000 |
|  |  |  | 固定資産売却益 | 240,000 |
| (B) 金融取引 | 現金預金 | 1,000,000 | 長期借入金（金融負債） | 1,000,000 |

> **誤答パターン分析**：(A)で使用権資産をリース負債と同額の400,000円にし、売却益を全額400,000円計上してしまうミス（旧基準的誤解）。新基準第34号では保持割合で簿価を引き継ぎ、移転割合に限定して売却益を認識する。

### 問3 解答・解説

**【前半：貸手の3方法】**
- PVスケジュール（820,000円、5%）：
  - X1末：受取利息 `820,000 × 5% ＝ 41,000円`、元本回収 `441,000 － 41,000 ＝ 400,000円`（残 `420,000円`）。
  - X2末：受取利息 `420,000 × 5% ＝ 21,000円`、元本回収 `441,000 － 21,000 ＝ 420,000円`（残 `0円`）。
- ① **第1法**：開始日に売上 **820,000円**、売上原価 **738,000円**（販売益82,000円）、X1末受取利息 **41,000円** → X1合計利益 **123,000円**。
- ② **第2法（延払基準的処理）**：X1末の受取額441,000円（うち元本回収400,000円・利息41,000円）に応じて売上高 **441,000円**、売上原価 `738,000 × (400,000 ÷ 820,000) ＝` **360,000円** を認識し、X1合計利益は **81,000円**（販売益40,000円＋利息41,000円相当）となる。
- ③ **第3法（金融型、原価820,000円）**：売上高 **0円**、売上原価 **0円**、受取利息 **41,000円** → X1合計利益 **41,000円**。

|  |  |  | 受取利息 | 41,000 |

**【後半：サブリース判定】**
- 中間貸手は原資産（耐用年数50年のビル）ではなく、ヘッドリースから生じた**「使用権資産（経済的耐用年数＝リース期間5年）」**を参照して分類を判定する。5年の使用権資産のうち4.5年（90%）を転貸しているため経済的耐用年数の大部分を占めており、**ファイナンス・リース**に分類される。

> **誤答パターン分析**：第2法の売上原価を441,000円ベースで按分したり、サブリースを「50年のうち4.5年（9%）だからオペレーティング・リース」と誤判定するミス。
