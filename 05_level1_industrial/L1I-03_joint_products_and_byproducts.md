## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

原油を精製すればガソリン・灯油・重油が同時にでき、牛を加工すればロース・カルビ・皮革が同時に生まれます。このように、**同一の原料・工程から必然的に複数種類の異種製品が生み出される**のが**連産品（Joint Products）**です。分離点（Split-off Point）までに掛かった**結合原価**は物理的には不可分ですが、もしこれを単純な重量（物量基準）で割ると、単価の安い重油や屑肉が巨額の原価を背負わされて**「売るほど大赤字に見えるのに、作らないわけにもいかない」という経営上の錯覚**が起きます。

そこで原価計算基準は、連産品の結合原価を**「それぞれの経済的負担能力（分離点における正味実現可能価額＝NRV＝最終売価－追加加工費－販売費）」の比率で按分する（正常市価基準）**ことを原則としています。また、連産品を分離点そのまま売るか追加加工して高く売るかの意思決定では、**分離点までの結合原価はすでに確定した埋没原価（サンク・コスト）として完全に無視**し、追加収益と追加加工費の差額だけで判定します。

- **連産品 vs 副産物の違い**：経済的価値が同格レベルの主製品群＝**連産品**（結合原価を按分）。経済的価値が圧倒的に低いおまけ＝**副産物**（結合原価から副産物の評価額を控除）。
- **NRV（正味実現可能価額）の本質**：`最終販売見込価額 － 分離点以降の追加加工費（－ 見積販売費）`。分離点時点での正味の稼ぐ力を表す。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 連産品のNRV按分と標準仕訳

**【例題】** 結合原価 **700,000円** の工程から、分離点で連産品A（400kg）と連産品B（300kg）が生じた。それぞれの追加加工費および最終売価は以下のとおり。
- 連産品A：追加加工費 120,000円、最終売価 720,000円 → 分離点NRV ＝ `720,000 － 120,000 ＝ 600,000円`（割合 **60%**）
- 連産品B：追加加工費 200,000円、最終売価 600,000円 → 分離点NRV ＝ `600,000 － 200,000 ＝ 400,000円`（割合 **40%**）
- **結合原価按分**：A ＝ `700,000 × 60% ＝ 420,000円`（最終総原価 `420k ＋ 120k ＝ 540,000円`）、B ＝ `700,000 × 40% ＝ 280,000円`（最終総原価 `280k ＋ 200k ＝ 480,000円`）。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 分離点：結合原価按分 | 連産品A仕掛品 | 420,000 | 結合工程仕掛品 | 700,000 |
|  | 連産品B仕掛品 | 280,000 |  |  |
| ② 追加加工費投入 | 連産品A仕掛品 | 120,000 | 加工費（諸口） | 320,000 |
|  | 連産品B仕掛品 | 200,000 |  |  |
| ③ 完成・製品振替 | 製品A | 540,000 | 連産品A仕掛品 | 540,000 |
|  | 製品B | 480,000 | 連産品B仕掛品 | 480,000 |

### 【1級貫通・標準下書きフォーマット】型02・型10（結合原価NRVツリー図）

```text
                       +--> [A] 売720k - 追120k = NRV 600k (60%)
                       |     => 結合按分 420k + 追120k = 540,000円
  [ 結合工程: 700k ] --+
  (NRV計: 1,000k)      |
                       +--> [B] 売600k - 追200k = NRV 400k (40%)
                             => 結合按分 280k + 追200k = 480,000円
```

**手順**：
1. 副産物や作業屑があれば、まず**結合原価から控除**して「正味結合原価」を確定する。
2. 各連産品の**NRV（最終売価－追加加工費－見積販売費）**をツリーの右側に書き出し、その比率で正味結合原価を按分する。
3. 最後に按分後の結合原価に「実際の追加加工費」を足して製品原価を確定する。

## 3. 級別・深化ロードマップ（今やること vs 未来の拡張）

### 【今すぐ100%定着させるコア（1級）】

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 正しい基準 | 試験官の罠 |
|---|---|---|
| **連産品の按分基準** | **分離点のNRV**（最終売価 － 追加加工費 － 見積販売費） | 単純に「最終売価（720k : 600k）」の比で結合原価を按分してしまうミス |
| **副産物の控除** | 結合原価総額から**副産物のNRVを控除**した残りを連産品で按分 | 副産物にも結合原価を按分したり、逆に控除を忘れて過大な結合原価を連産品に配るミス |
| **追加加工の意思決定** | `増分収益(加工後売価－分離売価) － 追加加工費` のみで判定 | 結合原価の按分額を意思決定計算に混ぜて「按分後原価だと赤字だから加工しない」と誤判断する罠 |

> **出題者の意図**：問2の追加加工判断で、あえて結合原価の按分額を先に計算させてから追加加工の採算を問い、**按分された結合原価700,000円を埋没原価として切り捨てられるか**を試すのが1級の王道問題である。

## 5. 思考力ドリル（問題編）

※本セクションでは問題のみを提示します。途中経過や解説は記載していません。

### 問1（基礎・型定着：副産物控除と連産品のNRV按分）
当月の結合工程において総結合原価 **850,000円** が発生し、分離点において連産品X・Yおよび副産物C（1個のみ）が産出された。副産物Cの評価額は分離点における見積売却価額 60,000円から見積販売費 10,000円を控除した額とし、結合原価総額から控除する。

- 連産品X：分離点後の追加加工費 300,000円、最終売価 900,000円
- 連産品Y：分離点後の追加加工費 100,000円、最終売価 500,000円

1. 正味結合原価（連産品X・Yに按分すべき結合原価）を求めよ。
2. 連産品XおよびYの「結合原価按分額」および「最終製品原価（完成品原価）」をそれぞれ求めよ。

### 問2（本試験標準・ひっかけ対応：追加加工の意思決定と埋没原価）
結合原価 700,000円から生じた連産品P・Qについて、分離点そのままの売却と追加加工後の売却のいずれが有利か判定せよ。

- **製品P**：分離点売価 300,000円 ／ 追加加工費 180,000円を掛けると 520,000円で売却可能。
- **製品Q**：分離点売価 200,000円 ／ 追加加工費 150,000円を掛けると 320,000円で売却可能。

1. 製品P・Qそれぞれについて、追加加工すべきか分離点で売却すべきか、差額利益の数値とともに判定せよ。
2. なぜこの意思決定において結合原価 700,000円を考慮してはならないのか、理由を述べよ。

### 問3（1級視点・応用思考：物量基準 vs NRV基準の採算歪み）
結合原価 600,000円の工程から、連産品M（100kg、分離点売価 900,000円、追加加工なし）と連産品N（200kg、分離点売価 300,000円、追加加工なし）が産出され、全数販売された。

1. 誤って**物量基準（kg数比）**で結合原価を按分した場合の、M・Nそれぞれの売上総利益を求めよ。
2. 原則どおり**NRV（正常市価）基準**で按分した場合の、M・Nそれぞれの売上総利益を求め、物量基準が引き起こす経営判断の誤りを指摘せよ。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

**1. 正味結合原価**
- 副産物Cの評価額（NRV）：`60,000 － 10,000 ＝ 50,000円`
- **正味結合原価** ＝ `850,000 － 50,000` ＝ **800,000円**

**2. 連産品X・Yの按分と最終原価**
- XのNRV ＝ `900,000 － 300,000 ＝ 600,000円`（割合 `600 ÷ 1,000 = 60%`）
- YのNRV ＝ `500,000 － 100,000 ＝ 400,000円`（割合 `400 ÷ 1,000 = 40%`）
- **連産品X**：結合原価按分 `800,000 × 60%` ＝ **480,000円** → 最終原価 `480,000 ＋ 300,000` ＝ **780,000円**
- **連産品Y**：結合原価按分 `800,000 × 40%` ＝ **320,000円** → 最終原価 `320,000 ＋ 100,000` ＝ **420,000円**

> **誤答パターン分析**：XとYのNRV比（60:40）ではなく、最終売価比（900:500 = 9:5）で結合原価800,000円を按分してしまうミス。

---

### 問2 解答・解説

**1. 追加加工意思決定（差額収益 － 追加加工費）**
- **製品P**：増分収益 `(520,000 － 300,000) ＝ 220,000円` － 追加加工費 `180,000円` ＝ **+40,000円** → **追加加工が有利**。
- **製品Q**：増分収益 `(320,000 － 200,000) ＝ 120,000円` － 追加加工費 `150,000円` ＝ **-30,000円** → **分離点での売却が有利**。

**2. 結合原価を無視する理由**
- 分離点までに発生した結合原価700,000円は、すでに過去に発生し終えており、その後P・Qをそのまま売ろうが追加加工しようが一切変化しない**埋没原価（無関連原価）**であるため、将来の増分キャッシュ・フローを比較する意思決定には無関係である。

> **誤答パターン分析**：PやQの分離点NRV比で結合原価700,000円を按分し、例えばPに結合原価400,000円が配賦されたから「400k+180k=580k ＞ 売価520k ゆえ赤字なので加工しない」と誤判断してしまう典型的な罠。

---

### 問3 解答・解説

1. **物量基準（M 100kg : N 200kg ＝ 1 : 2）**：
   - M：原価 `200,000円` → 売上総利益 `900,000 － 200,000` ＝ **+700,000円**
   - N：原価 `400,000円` → 売上総利益 `300,000 － 400,000` ＝ **-100,000円（見かけの赤字！）**
2. **NRV基準（M 900k : N 300k ＝ 3 : 1）**：
   - M：原価 `450,000円` → 売上総利益 `900,000 － 450,000` ＝ **+450,000円**
   - N：原価 `150,000円` → 売上総利益 `300,000 － 150,000` ＝ **+150,000円**
   - 経営的指摘：物量基準では重量の重いNに原価を押し付けた結果、Nが赤字製品に見えてしまい「Nを廃棄しよう」という誤った判断を招く。NRV基準なら双方の利益率が均一（50%）となり、経済的価値に見合った正しい採算評価ができる。

> **誤答パターン分析**：Nが見かけ赤字(-100k)だからといって「Nの生産を中止すべき」と答えてしまうミス（連産品は分離点まで必然的に同時にできるため、Nの売価300kがプラスなら廃棄せず売った方が会社全体は儲かる）。
