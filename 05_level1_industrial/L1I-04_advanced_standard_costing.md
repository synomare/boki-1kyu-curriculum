## 1. 本質と経済的実態（なぜこの会計処理が存在するのか）

飲料・塗料・合金・食品などの現場では、高い材料Aと安い材料Bをブレンドして製品を作ります。このとき「材料数量差異が-24,000円の不利になった」だけでは、現場が**「①そもそも投入した原材料全体から製品ができる歩留まり（収率）が悪かったのか」**、それとも**「②レシピの配合割合を変えて高いAを多く入れすぎたのか（あるいは安いBを多く入れて節約したのか）」**が分かりません。

そこで1級では、2級で学んだ「材料数量差異」をさらに**「配合差異（ブレンド比率のズレによるコスト差）」**と**「歩留差異（総投入重量あたりの出来高効率のズレ）」**の2つに分解します。さらに財務諸表作成上、標準原価の設定ミス等で原価差異が多額に出た場合は、B/Sの期末在庫まで「実際原価相当額」へ戻すための**原価差異の期末按分**を行います。

- **配合差異の本質**：総投入量（実際総kg）を前提として、**「標準配合割合通りの平均単価」と「実際配合割合の加重単価」のズレ**（安い材料を多く混ぜれば有利、高い材料を多く混ぜれば不利）。
- **歩留差異の本質**：標準配合平均単価（1kgあたり標準平均コスト）を用いて、**「本来100単位造るのに必要な標準総kg」と「実際に投入した総kg」の差**を評価したもの（投入量が少なくて済めば有利）。
- **原価差異按分の本質**：多額な価格差異・数量差異等をすべて売上原価に落とすと期末棚卸資産が歪むため、標準原価残高比等で「仕掛品・製品・売上原価」へ引き戻す。

## 2. 論理で導く基本構造と「1級仕様の解法フォーマット」

### 配合差異・歩留差異の3段階分解と標準仕訳

**【例題】** 製品1単位の標準材料配合（標準総投入 10kg、標準平均単価 `@320円/kg`）：
- 材料A：標準単価 `@400円 × 6kg`（配合比 60%）＝ 2,400円
- 材料B：標準単価 `@200円 × 4kg`（配合比 40%）＝ 800円（計 3,200円/単位）
- 当月生産実績：100単位分投入（標準総投入量 **1,000kg**：A 600kg・B 400kg ＝ 標準320,000円）。
- 実際消費実績：総投入 **1,100kg**（A 620kg×@410 ＝ 254,200円、B 480kg×@190 ＝ 91,200円、計 **345,400円**）。
- 差異分析（すべて標準 － 実際）：
  - **材料価格差異**：A `(400-410)×620 = -6,200`、B `(200-190)×480 = +4,800` → 計 **-1,400円（不利）**
  - **材料配合差異**（実際総投入1,100kgの標準配合＝A 660kg, B 440kg vs 実際A 620kg, B 480kg）：
    A `400×(660-620) = +16,000`、B `200×(440-480) = -8,000` → 計 **+8,000円（有利）**（安いBを多く混ぜた効果！）
  - **材料歩留差異**（標準平均単価@320 × (標準1,000kg － 実際1,100kg)）：
    `@320 × (-100kg)` ＝ **-32,000円（不利）**（100kg余分に投入したロス！）
  - 検算：`数量差異計 ＝ +8,000 ＋ (-32,000) ＝ -24,000円`、総差異 `-1,400 - 24,000 = -25,400円`（`320,000 - 345,400` と完全一致！）。

| 取引（パーシャル・プラン） | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 実際消費投入 | 仕掛品 | 345,400 | 材料A | 254,200 |
|  |  |  | 材料B | 91,200 |
| ② 差異切り出し | 材料価格差異 | 1,400 | 仕掛品 | 25,400 |
|  | 材料歩留差異 | 32,000 | 材料配合差異 | 8,000 |

### 【1級貫通・標準下書きフォーマット】型06：3本柱・配合歩留ボックス図

```text
  (1) 実際原価        (2) 実際投入×標準単価   (3) 実際総kgを標準比   (4) 標準総kg×標準比
  A: 620×410=254.2k   A: 620×400=248.0k       A: 660×400=264.0k      A: 600×400=240.0k
  B: 480×190= 91.2k   B: 480×200= 96.0k       B: 440×200= 88.0k      B: 400×200= 80.0k
  計 1,100kg 345.4k   計 1,100kg 344.0k       計 1,100kg 352.0k      計 1,000kg 320.0k
  |<-- 価格 -1,400 -->|<-- 配合 +8,000 ------>|<-- 歩留 -32,000 ----->|
```

**手順**：
1. 左から右へ `(1)実際 → (2)実際×標準単価 → (3)実際総kg×標準配合比 → (4)完全標準` の4列を並べる。
2. `(2)-(1)=価格差異`、`(3)-(2)=配合差異`、`(4)-(3)=歩留差異` と**右から左を引くだけ**で符号を含めて100%機械的に算出できる！

## 4. 試験官の罠・混同しやすい論点の対比表

| 項目 | 正しい算定・仕訳 | 試験官の罠 |
|---|---|---|
| **配合差異 vs 歩留差異** | 配合差異は「実際総投入kg」ベース<br>歩留差異は「標準平均単価」ベース | 配合差異を「標準総kg」で計算してしまい、総数量差が2重に入るミス |
| **多額な原価差異の按分** | 期末仕掛品・期末製品・売上原価の**当月発生標準原価（または残高）比**で按分 | 原価差異のうち「価格差異（受入時）」は期末材料にも按分されるのに、それを忘れて材料を除外してしまうミス（**消費価格差異なら仕掛品・製品・売原の3者**） |
| **修正パーシャルプラン** | 仕掛品借方には「標準単価×実際消費量」が入る | 普通のパーシャル・プランと混同して「実際単価×実際消費量」を入れてしまうミス |

> **出題者の意図**：特に**問1（配合差異-21,000円不利と歩留差異+21,000円有利がぴったり相殺されて通常の数量差異は0円になるケース）**が1級の超名作問題である。「数量差異0円だから現場に異常なし」と見逃してしまう問題点を、配合・歩留分解によって暴き出す本単元の本質そのものを突いている。

## 5. 思考力ドリル（問題編）

※本セクションでは問題のみを提示します。途中経過や解説は記載していません。

### 問1（基礎・型定着：配合差異と歩留差異の分解）
ある製品の1単位あたりの標準材料配合（標準総投入 5kg）は、材料X：`@600円 × 2kg ＝ 1,200円`、材料Y：`@300円 × 3kg ＝ 900円`（合計 2,100円、標準平均単価 `@420円/kg`）である。
当月の生産実績は200単位分投入（標準総投入量 1,000kg）であり、実際消費実績は総投入 **950kg**（X：450kg × @620円、Y：500kg × @300円）であった。

1. 材料価格差異、材料配合差異、および材料歩留差異（有利・不利を明記）を求めよ。
2. 通常の数量差異（XとYの合計）がいくらになるか計算し、なぜ配合・歩留に分解する必要があるのか簡潔に述べよ。

### 問2（本試験標準・ひっかけ対応：多額な原価差異の期末按分）
標準原価計算を採用する当社の当期末において、材料消費に関する**不利差異 120,000円**が多額に発生したため、原価計算基準に基づき当期の総原価要素（標準原価ベース）に応じて期末仕掛品・期末製品・売上原価へ按分することとした（期首仕掛品・期首製品はなく、当月投入標準材料費の配分結果は以下のとおり）。

- 月末仕掛品に含まれる標準材料費：200,000円
- 月末製品に含まれる標準材料費：300,000円
- 当期売上原価に含まれる標準材料費：1,500,000円（合計 2,000,000円）

1. 仕掛品・製品・売上原価へのそれぞれの差異配賦額を求めよ。
2. 期末の原価差異整理仕訳を示せ。

### 問3（1級視点・応用思考：修正パーシャル・プランと標準原価改定）
1. **修正パーシャル・プラン**：標準消費単価 `@500円/kg` の材料を `@520円/kg` で 1,200kg 購入し（受入時に入庫価格差異を切り出す）、当月製造に **1,050kg** 消費した（当月標準消費量は 1,000kg）。修正パーシャル・プランにおける「材料購入時」「材料消費時」および「仕掛品勘定から切り出される差異」の仕訳を示せ。
2. **標準原価改定**：翌期首において標準原価の改定を行い、期首仕掛品（旧標準 200,000円）の新標準原価が 220,000円へ引き上げられた。この改定差額の仕訳を示せ。

## 6. 完全検算済み・解答とプロセス解説

### 問1 解答・解説

**【下書き再現：型06 3本柱図】**
- `(1)` 実際：`450×620(279,000) ＋ 500×300(150,000) ＝ 429,000円`
- `(2)` 実際kg×標準単価：`450×600(270,000) ＋ 500×300(150,000) ＝ 420,000円`
- `(3)` 実際総量950kg×標準比(40%:60%)：`X 380kg×600(228,000) ＋ Y 570kg×300(171,000) ＝ 399,000円`（`950 × @420 = 399,000` 一致！）
- `(4)` 完全標準1,000kg：`200単位 × 2,100 ＝ 420,000円`

**1. 各差異**
- **材料価格差異**：`420,000 － 429,000` ＝ **-9,000円（不利差異）**
- **材料配合差異**：`399,000 － 420,000` ＝ **-21,000円（不利差異）**（高価なXを多く混ぜすぎた）
- **材料歩留差異**：`420,000 － 399,000` ＝ **+21,000円（有利差異）**（総重量を50kg節約できた）

**2. 通常の数量差異と分解意義**
- 通常の数量差異計 ＝ `-21,000 ＋ 21,000` ＝ **0円**。分解しなければ「数量管理は完璧」と誤認してしまうが、実際には「高いXを多く入れて歩留まりを良く見せた（配合損と歩留益の相殺）」という現場の実態を捉えるために分解が不可欠となる。

> **誤答パターン分析**：(3)の950kgに対するXとYの標準配合比（40%と60%）を逆にしてしまい、配合差異と歩留差異の符号を取り違えるミス。

### 問2 解答・解説

- 差異配賦率 ＝ `120,000 ÷ 2,000,000 ＝ 6%`
1. **配賦額**：
   - 仕掛品：`200,000 × 6%` ＝ **12,000円**
   - 製品：`300,000 × 6%` ＝ **18,000円**
   - 売上原価：`1,500,000 × 6%` ＝ **90,000円**
2. **仕訳**：

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 原価差異期末按分 | 仕掛品 | 12,000 | 材料消費価格差異 | 120,000 |
|  | 製品 | 18,000 |  |  |
|  | 売上原価 | 90,000 |  |  |

> **誤答パターン分析**：売上原価1,500,000円を含めず、仕掛品と製品だけで按分したり、逆に標準慣行に反して期末在庫を除外して全額120,000円を売上原価に入れてしまうミス。

### 問3 解答・解説

1. **修正パーシャル・プラン**：
   - 材料購入時：1,200kgを標準@500円(600,000円)で受け入れ、材料受入価格差異 **24,000円** を切り出す。
   - 材料消費時：実際消費1,050kgを標準@500円＝ **525,000円** で仕掛品へ投入する。
   - 仕掛品差異：標準消費500,000円との差額＝純粋な材料数量差異 **-25,000円（不利）** のみが切り出される。
2. **標準原価改定**：旧標準200,000円→新標準220,000円につき **+20,000円** 仕掛品を増額し、貸方に「標準原価改定差額」を計上する。

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| ① 材料購入(受入差異) | 材料 | 600,000 | 買掛金 | 624,000 |
|  | 材料受入価格差異 | 24,000 |  |  |
| ② 材料消費(修正ﾊﾟｰｼｬﾙ) | 仕掛品 | 525,000 | 材料 | 525,000 |
| ③ 仕掛品差異(数量のみ) | 材料数量差異 | 25,000 | 仕掛品 | 25,000 |
| ④ 期首標準改定 | 仕掛品 | 20,000 | 標準原価改定差額 | 20,000 |

> **誤答パターン分析**：修正パーシャル・プランなのに、仕掛品の借方に実際購入額（1,050×520＝546,000円）を入れてしまい、受入価格差異と二重計上してしまうミス。
