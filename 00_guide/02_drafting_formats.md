# 1級貫通・標準下書きフォーマット集（全10型）＆仕訳テーブル規約

本教材では、3級から1級まで**同じ下書きの「型」**を使い続けます。1級本試験の膨大な資料を限られた時間で正確に捌くため、以下の10型を統一フォーマットとして定義します。

---

## 標準Markdown仕訳テーブル規約（全単元共通）

解説・解答内のすべての仕訳は、以下のいずれかの厳密なMarkdownテーブル形式で記述します（金額はカンマ区切りの整数、単位「円」は表外またはヘッダに明記、借方合計＝貸方合計を常に満たすこと）。

**基本形式（単一仕訳または連続仕訳）**

```markdown
| 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---:|---|---:|
| 現金 | 100,000 | 売上 | 100,000 |
```

**取引／日付付き形式（複数取引を並べる場合）**

```markdown
| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
|---|---|---:|---|---:|
| 4/10 | 仕入 | 190,000 | 買掛金 | 190,000 |
|  | 仕入 | 10,000 | 現金 | 10,000 |
```
※先頭列（`取引`・`日付`・`No.`・`仕訳`）に値が入った行から次の値が入る行の前までを1つの仕訳グループとみなし、グループごとに `借方金額合計 == 貸方金額合計` を保ちます。

## 型01：タイムライン型（時間軸と期間配分・現在価値）

- **適用単元**：`L3-04`, `L3-06`, `L3-07`, `L2C-04`〜`08`, `L1C-01`, `L1C-04`, `L1C-06`〜`08`, `L1C-10`, `L1C-12`, `L1I-10`
- **手順**：①会計期間（期首〜期末）の縦線を引く → ②発生・取得・契約時点に印をつける → ③月数・年数・残存期間を上部に書き込む → ④当期帰属分と次期以降分を矢印で分離する。

```text
  前期末        取得/契約          当期末(決算)        満期/償還
----+-------------+------------------+------------------+-----> 時間
    |             |<---- 当期(m月) --->|<--- 翌期以降 --->|
    |             |  [発生/配分額]     |  [繰延/残高]     |
```

## 型02：ボックス図型（投入＝産出の保存則）

- **適用単元**：`L3-03`, `L3-05`, `L3-09`, `L2C-03`, `L2C-11`, `L2I-02`, `L2I-05`, `L2I-06`, `L1C-05`, `L1I-02`, `L1I-03`
- **手順**：①左側に「期首＋当期投入（借方）」、右側に「当期払出＋期末（貸方）」を配置 → ②数量と金額（必要なら単価）を併記 → ③**左辺合計 ＝ 右辺合計**の検算を行う。
- **進化**：3級の「商品ボックス」は、2級で右下に「棚卸減耗損・商品評価損」が加わり、工業簿記ではそのまま「仕掛品ボックス（完成品換算量併記）」へ同型進化する。

```text
+-----------------------------------+-----------------------------------+
|  期首在庫       xx個    xxx,xxx円 |  売上原価(完成) xx個    xxx,xxx円 |
|                                   |  (減耗・仕損)   xx個     xx,xxx円 |
|  当期純仕入     xx個    xxx,xxx円 |  期末在庫       xx個     xx,xxx円 |
|  (当期投入)                       |  (評価損控除前)                   |
+-----------------------------------+-----------------------------------+
|  借方合計       xx個    xxx,xxx円 |  貸方合計       xx個    xxx,xxx円 |
+-----------------------------------+-----------------------------------+
```
※検算等式：`期首 ＋ 当期投入 ＝ 当期払出（売上原価/完成品） ＋ 減耗・仕損 ＋ 期末在庫`

## 型05：シュラッター図型（製造間接費・補助部門費の予算差異分析）

- **適用単元**：`L2I-03`, `L1I-01`
- **手順**：①内枠（基準操業度）と外枠（実際操業度）の座標を確定 → ②水平線に固定予算額 `F`、斜線に変動率 `v` を引く → ③上から順に「実際発生額」「予算許容額（`F + v×実際`）」「予定配賦額（`(F/基準 + v)×実際`）」を並べ、**予算差異**と**操業度差異**を上下に分離する。

```text
  発生額
    ^
    |                        * 実際発生額
    |                       /|
    |            +---------*-| <-- 予算許容額 (F + v×実際)
    |           /|         | |     [予算差異 = 許容 - 実際]
    |          / |         | |
    |---------*--+---------*-| <-- 固定費ライン (F)
    |  固定費 |  |         | |     [操業度差異 = 配賦 - 許容]
    |  (F)    |  |         * | <-- 予定配賦額
    +---------+--+---------+-----> 操業度(時間)
              0  実際      基準
```

## 型06：面積差異図型（標準原価・配合歩留・市場差異）

- **適用単元**：`L2I-07`, `L1I-04`, `L1I-06`
- **手順**：①縦軸に単価（賃率・価格）、横軸に数量（時間）をとる → ②内側の長方形を「標準（S×S）」、外側の長方形を「実際（A×A）」として描画 → ③L字型の差額面積を「価格（賃率）差異（上段・実際数量基準）」と「数量（能率）差異（右段・標準価格基準）」に分割する。

```text
  単価
    ^
    |--------------------|  <-- 実際単価 (Ap)
    |    価格差異        |
    |  (Sp - Ap) × Aq    |
    |--------------------+-------|  <-- 標準単価 (Sp)
    |                    |       |
    |   標準原価         | 数量  |
    |   Sp × Sq          | 差異  |
    +--------------------+-------+---> 数量
    0                   Sq      Aq
```

## 型09：一時差異スケジューリング表型（税効果会計）

- **適用単元**：`L2C-10`, `L1C-11`
- **手順**：①項目ごとに「会計上の簿価」と「税務上の簿価」の差額として一時差異を算出 → ②将来、課税所得を減額する（将来減算＝DTA）か加算する（将来加算＝DTL）かを判定 → ③解消年度別の法定実効税率を乗じて繰延税金資産・負債を確定する。

## 型10：差額原価収益・意思決定マトリクス型
