## 第1章：財務報告の目的と概念フレームワーク

### 1. 財務諸表は誰のために、何のために作るのか
企業会計の究極の目的は、**投資家（株主・債権者）の意思決定に有用な情報を提供すること**（意思決定有用性）です。具体的には、「この企業は将来どれだけキャッシュを生み出す力があるか（将来キャッシュ・フローの予測）」を判断する材料を提供することにあります。

### 2. 会計情報の質的特性
- **意思決定との関連性**：将来のキャッシュ・フロー予測に役立つ情報であること。
- **信頼性（忠実な表現・検証可能性・中立性）**：企業の恣意的な操作（粉飾）を許さず、経済的実態を忠実に表現すること。
- **比較可能性**：同じ企業を期間比較でき、他社とも企業間比較できること（継続性の原則）。

## 第2章：財務諸表の5要素と複式簿記の数学的必然性

簿記で扱うすべての勘定科目は、例外なく以下の**5要素**のいずれかに分類されます。

| 要素 | 所属F/S | 定義（経済的実態） | 定位置（増加側） |
|---|---|---|---|
| **資産** | B/S（借方） | 過去の取引の結果として支配している、**将来の経済的便益（キャッシュ獲得能力）** | **借方** |
| **負債** | B/S（貸方） | 過去の取引から生じた、**将来の経済的便益の放棄（キャッシュ支払義務）** | **貸方** |
| **純資産** | B/S（貸方） | 資産総額から負債総額を差し引いた**正味財産（残余持分）** | **貸方** |
| **収益** | P/L（貸方） | 純資産を増加させる要因（株主からの直接払込を除く成果の流入） | **貸方** |
| **費用** | P/L（借方） | 純資産を減少させる要因（株主への配当等を除く成果獲得のための犠牲） | **借方** |

### 複式簿記が「必ず貸借一致する」数学的証明

期末時点の貸借対照表（B/S）は、財産の総体（資産）とその調達源泉（負債＋純資産）の恒等式です。

$$\text{期末資産} = \text{期末負債} + \text{期首純資産} + (\text{収益} - \text{費用})$$

負の項である「費用」を左辺へ移項すると、複式簿記の根本恒等式が現れます。

$$\underbrace{\text{期末資産} + \text{費用}}_{\text{借方グループ}} = \underbrace{\text{期末負債} + \text{期首純資産} + \text{収益}}_{\text{貸方グループ}}$$

- **なぜ資産と費用が同じ「借方」なのか**：どちらも「調達した資金の運用形態（ストックとして残った価値＝資産、当期に消費して消えた価値＝費用）」だからです。
- **なぜ負債・純資産・収益が同じ「貸方」なのか**：すべて「資金の調達源泉（債権者からの借入＝負債、株主からの出資・蓄積＝純資産、事業活動で稼いだ源泉＝収益）」だからです。

## 第3章：利益計算の2大アプローチ（3級と1級の完全接続）

現代の会計基準は、伝統的な「収益費用アプローチ」と国際標準の「資産負債アプローチ」の2つの視点で動いています。

### 1. 収益費用アプローチ（伝統的・フロー中心）
「当期の正しい期間損益」を算定することを主眼とし、以下の原則で動きます。
- **発生主義**：現金の収支ではなく、経済的事実（価値の消費・発生）に基づいて費用を認識する（例：減価償却、経過勘定、引当金）。
- **実現主義**：財貨・サービスの引渡しと対価の成立をもって収益を認識する。
- **費用収益対応の原則**：当期の収益と、その収益獲得に貢献した費用を同じ期間に突き合わせる（例：売上と売上原価の対応）。
- **取得原価主義**：資産は原則として取得時の支出額で評価し、未実現の利益を計上しない。
- **保守主義の原則**：予想される損失は早期に計上し、不確実な利益は計上しない（例：貸倒引当金、棚卸資産の低価法、減損）。

### 2. 資産負債アプローチ（現代基準・ストック中心）
期末の「資産」と「負債」の定義・測定をまず確定し、その純資産の差額として利益を捉えます。
- **収益認識会計基準（企業会計基準第29号）**：顧客との契約における「履行義務」を識別し、資産の「支配の移転」によって収益を認識する（返金負債・返品資産・契約資産・契約負債）。
- **新リース会計基準（企業会計基準第34号）**：リース物件を借りて使用する権利（**使用権資産**）と、リース料を支払う義務（**リース負債**）を原則すべてB/Sに計上する。
- **包括利益とリサイクリング（1級）**：その他有価証券評価差額金などの純資産直入項目を含む「包括利益」と、実現時にP/Lへ組替調整される「当期純利益」を体系的に接続する。

## 第4章：測定属性スペクトラム（3級→1級でどう評価が変わるか）

| 測定属性 | 本質的な意味 | 主な適用単元 |
|---|---|---|
| **取得原価** | 取得時に支払った現金・対価の額 | `L3-03` 商品、`L3-06` 有形固定資産 |
| **償却原価** | 取得価額と額面額の差額を金利調整として期間配分した額 | `L2C-06` 満期保有社債、`L1C-03` 利息法 |
| **正味売却価額 (NRV)** | 予想売価から見積追加製造原価・販売費を控除した回収額 | `L2C-03` 低価法、`L1I-03` 連産品 |
| **回収可能価額** | 正味売却価額と使用価値（将来CFの現在価値）のいずれか高い方 | `L1C-06` 減損会計 |
| **割引現在価値** | 将来キャッシュ・フローを適切な割引率で現在時点に割り引いた額 | `L2C-05`・`L1C-08` 新リース、`L1C-07` ARO、`L1C-09` 退職給付、`L1I-10` NPV |
| **時価（公正価値）** | 市場参加者間の秩序ある取引で成立する価格 | `L2C-06` 売買目的/その他有価証券、`L1C-04` デリバティブ、`L1C-15` 企業結合 |

## 第5章：原価計算基準の体系（工業簿記・原価計算の背骨）

工業簿記・原価計算は、商業簿記の「商品 → 売上原価」という1段階の原価フローを、工場内部の「材料・労務・経費 → 仕掛品 → 製品 → 売上原価」に分解した**完全同型システム**です。原価計算基準は以下の5つの目的を定めています。

1. **財務諸表作成目的**：外部報告用の真実の売上原価・期末棚卸資産を算定する（実際原価・標準原価）。
2. **価格計算目的**：製品・サービスの販売価格決定の資料を提供する。
3. **原価管理目的**：標準原価と実際原価を比較し、能率差異を分析して現場を改善する（例外管理）。
4. **予算編成・予算統制目的**：利益計画（CVP・直接原価計算）と予算実績差異分析を行う。
5. **基本計画（意思決定）目的**：特殊意思決定（差額原価収益分析）および設備投資（NPV・IRR）を行う（**異なる目的に異なる原価**）。
