# 日商簿記 3級→1級 貫通カリキュラム教材（2027年4月新区分・新基準完全準拠）

## 1. 本教材のミッション

本プロジェクトは、**簿記3級レベルからスタートし、一切の「学び直し（アンラーン）」を発生させずに日商簿記1級の最短・本質的合格（および公認会計士・税理士レベルの理論基盤完成）へ到達する**ためのオリジナル教材体系です。

市販の3級・2級テキストにありがちな「とりあえずこの語呂合わせで覚えよう」「3級ではこう処理する（実は2級・1級では使わない）」という**その場しのぎの指導を完全に排除**し、最初から1級の本試験および実務の企業会計基準に直結する「思考のOS」と「下書きの型」をインストールします。

---

## 2. 5つの絶対設計原則

1. **原則1：丸暗記と無意味な語呂合わせの完全禁止**
   - すべての仕訳と会計処理は、①**経済的実態（お金と価値の移動）**、②**財務諸表の5要素（資産・負債・純資産・収益・費用）の定義**、③**会計理論・原価計算基準（発生主義、費用収益対応の原則、資産負債アプローチ等）**から論理的に導出します。
2. **原則2：「1級貫通マップ（フック設計）」の埋め込み**
   - 各単元において「**今この段階で100%定着させるコア**」と「**2級・1級への伏線（読むだけでOKな拡張フック）**」を視覚的に完全分離し、学習負荷を抑えつつ後の理解速度を劇的に引き上げます。
3. **原則3：「1級でもそのまま戦える下書きの型」の早期統一**
   - 3級段階から、1級の膨大な資料処理に耐えうる統一フォーマット（全10型：タイムライン、ボックス図、T勘定連結、CF/償却表、シュラッター図、面積差異図、連結タイムテーブル、退職給付ワークシート、一時差異スケジューリング表、差額原価収益マトリクス）を一貫して使用します。
4. **原則4：2027年4月改定・最新会計基準との完全整合**
   - 2027年4月1日以降に施行される日本商工会議所の新出題区分表（確定版）および最新の企業会計基準に100%準拠しています。
   - **紙の手形・小切手の完全廃止**（全級）：電子記録債権・債務、当座預金、ファクタリング、キャッシュレス決済へ一本化。
   - **3級への新規移行・追加論点**：売上原価対立法、定率法による減価償却、有形固定資産の除却・廃棄を3級コアとして標準統合。
   - **新リース会計基準（企業会計基準第34号）**：2級（借手オンバランス原則・使用権資産とリース負債・短期/少額リース）および1級（借手の高度論点・セール＆リースバック・サブリース・貸手処理）へ完全対応。
   - **収益認識に関する会計基準（企業会計基準第29号）**：5ステップモデルを基礎から1級応用まで一貫接続。
5. **原則5：数理的完全性（ゼロ・ハルシネーション検算）**
   - すべての例題・演習問題・解説は、PowerShell + .NET 128ビット `[decimal]`（財務用厳密10進演算）による自動検証スイートを通過しており、**借方＝貸方、B/S＝P/L整合、原価の投入＝産出均衡**を100%保証します。

## 3. 全単元共通「7セクション構成」と標準学習プロトコル

本カリキュラムの全55単元は、例外なく以下の7セクションで構成されています。

| セクション | 役割 | 学習時のアクション |
|---|---|---|
| **0. 単元メタデータ＆1級貫通マップ** | 地図の確認 | 今学ぶ単元が「どの会計理論」と「1級のどの論点」に繋がるかを30秒で把握する。 |
| **1. 本質と経済的実態** | なぜ必要かの理解 | 「もしこの処理をしなかったら決算書がどう嘘をつくか」を腹落ちさせる。 |
| **2. 論理で導く基本構造と解法フォーマット** | 型と導出の習得 | 仕訳を暗記せず5要素の増減で導き、指定の**標準下書きフォーマット**を手を動かして描く。 |
| **3. 級別・深化ロードマップ** | 範囲の明確化 | 「今すぐ100%定着させるコア」だけに集中し、「未来の拡張フック」は一読して流す。 |
| **4. 試験官の罠・対比表** | ひっかけの無力化 | 類似論点の違いと「出題者の意図（なぜその罠を仕掛けるか）」を押さえる。 |
| **5. 思考力ドリル（問題編）** | 自力演習 | **解説を見ずに**、必ず標準下書きフォーマットを描いて問1→問2→問3を解く。 |
| **6. 完全検算済み・解答とプロセス解説** | 検証と修正 | 数値だけでなく**下書き図の描き方**と**誤答パターン分析**を照合し、思考のズレを修正する。 |
| **7. 復習チェックリスト** | 定着確認 | テキストを閉じ、各項目の問いに**自分の言葉で白紙説明**できればその単元は合格。 |

### 分散学習・復習サイクル（定着の黄金律）

- **Day 0（初回学習）**：セクション0〜4を読み（20〜30分）、セクション5の問1〜3を解いてセクション6で検算する（30〜40分）。
- **Day 1（翌日）**：セクション7のチェックリストを見て、自分の言葉で1問30秒以内に説明できるか確認。詰まった箇所だけセクション1〜2を再読。
- **Day 7（1週間後）**：思考力ドリルの**問2・問3**を下書きフォーマットから白紙で再演習。
- **Day 21（3週間後）**：該当単元の下書きの型（`02_drafting_formats.md`）だけを思い出し、上位級へのフックを再確認。
