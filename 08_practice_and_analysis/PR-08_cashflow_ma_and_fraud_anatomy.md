# PR-08：キャッシュフロー経営・資金繰り・M&Aと会計不正（粉飾）の解剖学

## 0. 本巻の位置づけ＆対応カリキュラム単元マップ

企業経営の最終ゴールは「会計上の利益を作ること」ではなく、**「将来にわたってキャッシュ・フロー（現金）を生み出し続け、資本価値を増大させること」**です。本巻では、①経理実務の要である**資金繰り管理とC/F計算書**、②成長と再編の現場である**M&A・PPA（取得原価配分）・資本政策**、そして③簿記と財務分析の知識を総動員して見抜く**会計不正（粉飾決算）の典型的手口と兆候**を徹底解剖します。

## 1. 資金繰り表とキャッシュフロー経営（P/Lと現金のズレを制す）

財務経理の実務では、年1回・四半期ごとの「キャッシュ・フロー計算書（実績の事後報告）」に加えて、今後3〜12か月先を見通す**「月次・日次資金繰り表（未来の現金予測）」**を毎週更新します。

- **資金繰りの谷間（季節要因・納税・賞与）**：利益が順調に出ていても、法人税・消費税の納税月（通常決算2か月後）や夏冬の賞与支給月、大型設備投資の支払月には、一時的に巨額のキャッシュアウトが集中します。
- **手元流動性比率（月商倍率）**：`（現金預金＋短期有価証券） ÷ 月商`（＝年間売上÷12）。中小企業や成長企業では最低1.5〜3か月分の手元流動性を確保しつつ、突発的な危機に備えて銀行との**コミットメントライン（融資枠）**を契約します。
- **「運転資金借入」と「設備資金借入」の原則**：経常運転資金（売掛＋在庫−買掛）は短期借入や当座貸越で賄い、工場・機械の設備投資は回収期間（5〜10年）に合わせた長期借入で調達して返済期間を資産の寿命と一致させます。

## 2. M&A実務（DD・PPA・のれん減損）と資本政策のダイナミズム

簿記1級で学ぶ「企業結合・事業分離（[L1C-15](L1C-15)）」は、実際のM&A現場では次のようなプロセスで動きます。

```text
[買収価格の決定] ──▶ [財務・税務・法務DD] ──▶ [買収実行(クロージング)] ──▶ [PPA（取得原価配分）]
 EV/EBITDA倍率や     簿外債務・滞留在庫・      株式取得（支配獲得）         買収対価を諸資産・無形資産
 DCFで企業価値算定   顧客離反リスクを精査                                  (顧客関連等)・DTL・のれんへ配分
```

1. **PPA（Purchase Price Allocation：取得原価配分）**：買収対価と被買収企業の簿価純資産の差額をすべて「のれん」にするのではなく、被買収企業が持っていた**土地の含み益や顧客関係・特許権などの識別可能無形資産**を時価評価して認識し、それらに係る**繰延税金負債（DTL）**を控除した残額を `のれん` とします（[L1C-13](L1C-13), [L1C-15](L1C-15)）。
2. **M&A後の最大リスク＝のれんの減損**：買収時の事業計画（シナジー）が未達に終わると、残存する `のれん` や無形資産を一括で減損処理せざるを得なくなり、連結P/Lに巨額の特別損失が直撃します。
3. **資本政策（自己株式取得 vs 増資 vs ストックオプション）**：余剰資金で自己株式を取得・消却（[L1C-10](L1C-10)）すると発行済株式数が減り、1株当たり利益（EPS）とROEが向上します。一方、人材獲得のためのストック・オプションは、現金支出を伴わずに権利確定期間にわたって `株式報酬費用` を計上する仕組みです。

## 3. 会計不正（粉飾決算）の典型的5パターンと決算書での見抜き方

歴史的な粉飾事件の多くは、実は「高度で複雑なデリバティブ」ではなく、簿記3級・2級レベルの勘定科目を使った**5つの古典的パターン**に集約されます。しかし、複式簿記は必ず貸借が一致するため、**P/Lの利益を嘘で押し上げると、B/Sのどこかの資産が異常に膨らみ、営業キャッシュ・フローとの間に深刻な乖離が生まれます。**

| 粉飾パターン | 具体的な手口 | 決算書・指標に現れる「赤い警報（Red Flag）」 |
|---|---|---|
| **① 架空売上・循環取引・前倒し** | 期末直前に出荷していない売上を計上（押し込み販売）、または複数社間で商品・請求書をグルグル回す。 | 利益は増えているのに**売掛金回転日数（DSO）が急上昇**し、**営業CFがマイナス**になる。 |
| **② 在庫水増し・評価損先送り** | 期末棚卸数量を架空計上する、または売れない不良在庫の評価減（[L2C-03](L2C-03)）を行わず売上原価を圧縮する。 | 不自然に**売上総利益率（粗利率）が急改善**し、同時に**棚卸資産回転日数（DIO）が異常膨張**する。 |
| **③ 費用の過大資産化** | 本来は当期費用の開発費・広告費・外注費を「ソフトウェア」「前払費用」「仕掛品」へ逃がす。 | B/Sの無形固定資産・長期前払費用が膨張し、利益とC/Fの差（アクルーアル）が拡大する。 |
| **④ 連結外し・オフバランス飛ばし** | 赤字子会社や含み損のある資産を、形式上支配していない特別目的会社（SPC）等へ売却・移管する。 | 関係会社への多額の貸付金・保証債務注記、期末の不可解な不動産・有価証券売却益。 |
| **⑤ 引当金・減損の先送り** | 回収不能な売掛金や赤字事業の固定資産に対して、都合の良い将来計画を作って引当・減損を回避する。 | 営業赤字が続くのに減損損失ゼロ、滞留債権があるのに貸倒引当金設定率が極端に低い。 |

## 4. 並走ケーススタディ（完全検算済み・粉飾兆候の解剖＆M&A PPA）

### Case A：「増収増益なのに現金が消える」企業Yのフォレンジック分析（128bit検算済み）
企業Yは2期目にかけて売上高 `+25%`（`8,000 → 10,000`）、営業利益 `+50%`（`800 → 1,200`）の好決算を発表した。しかし、B/Sと営業CFを精査すると次の異常が判明した（単位：百万円、法人税支払は1期目 `240`・2期目 `360`、減価償却費は各期 `300`）。

| 項目（百万円） | 1期目 | 2期目 | 変化・異常シグナル |
|---|---:|---:|---|
| 売上高 ／ 売上原価 | `8,000` ／ `5,600` | `10,000` ／ `6,125` | 粗利率が `30.0% → 38.75%` へ不自然に急上昇 |
| 営業利益 | `800` | `1,200` | 見かけ上は `+50%` の大増益 |
| 期末 売掛金 ／ 棚卸資産 ／ 買掛金 | `1,000` ／ `900` ／ `800` | **`2,600` ／ `2,300` ／ `850`** | 売掛金 `+1,600`（2.6倍）、棚卸資産 `+1,400`（2.56倍） |
| **売上債権回転日数（DSO）** | `45.6日` (`1,000/8,000×365`) | **`94.9日`** (`2,600/10,000×365`) | 売上の伸び以上に未回収債権が倍増（押し込み・架空売上の疑い） |
| **棚卸資産回転日数（DIO）** | `58.7日` (`900/5,600×365`) | **`137.1日`** (`2,300/6,125×365`) | 在庫が約4.5か月分に膨張（評価損先送り・在庫水増しの疑い） |
| **間接法 営業キャッシュ・フロー** | **`+860`**（推計基準） | **`-1,810`** (`1,200+300-1,600-1,400+50-360`) | **営業利益 `1,200` に対し営業CF `-1,810`（キャッシュ転換率 `-150.8%`）** |

- **診断結果**：利益が `+50%` 伸びている裏で、売掛金増加 `-1,600` と棚卸資産増加 `-1,400` により営業CFが **`-1,810百万円`** の巨額赤字へ転落している。これは「架空・押し込み売上」と「在庫水増し（原価圧縮）」の典型的な組み合わせ兆候である。

### Case B：M&AにおけるPPA（取得原価配分）の仕訳と検算（128bit検算済み）
P社はS社株式の100%を現金 `5,000百万円` で取得した。取得日におけるS社の簿価純資産は `2,800百万円` であったが、PPAの結果、土地の時価評価差額 `+400百万円` および新たに識別された顧客関連無形資産 `+1,000百万円` が把握された（実効税率 `30%`）。
- 評価差額合計：`400 + 1,000 = 1,400百万円` → 繰延税金負債（DTL）：`1,400 × 30% = 420百万円`
- 識別可能純資産の時価：`2,800 + 1,400 - 420 = 3,780百万円`
- **のれん計上額**：`取得対価 5,000 - 3,780 = 1,220百万円`（日本基準で20年定額償却する場合、年額 `61百万円` ののれん償却費が発生）

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
| :--- | :--- | ---: | :--- | ---: |
| B1. S社株式の取得（個別） | 関係会社株式 | 5,000 | 現金預金 | 5,000 |
| B2. 支配獲得日の連結相殺・PPA | S社純資産 | 2,800 | 関係会社株式 | 5,000 |
|  | 土地 | 400 | 繰延税金負債 | 420 |
|  | 顧客関連資産 | 1,000 | | |
|  | のれん | 1,220 | | |

## 5. 実務・分析の落とし穴（よくある誤解と確認ポイント）

1. **「営業CFがプラスだから健全」という油断**：新リース基準や手形の先延ばし（買掛サイト長期化）による一時的な営業CF増加は持続しません。必ず「税引前利益＋償却費」と「営業CF」の乖離（アクルーアル）を複数年度で追ってください。
2. **PPAで顧客関連資産を認識しない場合との違い**：同じ `5,000` の買収でも、顧客関連資産 `1,000`（償却年数10年なら年 `100` 償却）と `のれん 1,220`（20年なら年 `61` 償却）に分かれるため、IFRS企業であっても「無形資産の償却費」が買収後の営業利益に影響する点に注意が必要です。
