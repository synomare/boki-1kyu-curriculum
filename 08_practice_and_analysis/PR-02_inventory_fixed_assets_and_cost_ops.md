## 1. 実地棚卸の現場手順と「棚卸差異」の切り分け

実地棚卸は、決算書上の `商品`（または `原材料`・`製品`）の実在性を担保するとともに、売上原価を確定させる最重要イベントです（[L3-03](L3-03), [L2C-03](L2C-03)）。

### 現場の標準プロセス（一斉棚卸 vs 循環棚卸）
- **一斉棚卸（期末一斉カウント）**：期末日の営業終了後や休日に倉庫の入出庫を完全に止め（**カットオフ**）、全棚へ棚卸タグ（またはバーコードスキャン）を貼って「帳簿を知らない担当者」がカウントし、別担当者が検算します（ブラインド・カウント）。
- **循環棚卸（サイクルカウント）**：年間を通じて倉庫のエリアや品目（ABC分析のAランク高額品は毎月、Cランクは年1回など）をローテーションで数え、期末一斉停止の負荷を下げる手法です。

```text
[実地棚卸で差異が出た！] ──▶ まず「カットオフ・入力ミス」を疑う（帳簿数量の修正）
                                  │
                                  ▼（帳簿数量が正しいと確定した後）
                         [真の棚卸減耗] ──▶ 原因調査（紛失・蒸発・盗難・未記帳廃棄）
                                  │
                                  ▼（残った正常在庫に対して）
                         [正味売却価額 (NRV) 評価] ──▶ 滞留品・型落ち品の低価法評価損
```

### 「帳簿ズレ（カットオフミス）」と「棚卸減耗」は全く別物
試験では最初から「帳簿1,000個・実地940個」と与えられますが、実務で差が出た瞬間にいきなり60個を `棚卸減耗損` にしてはいけません。例えば「3月31日午後に出荷した40個分の納品書が、倉庫システムにまだ入力されていなかった」場合、それは物が消えた（減耗）のではなく**売上原価の計上漏れ（帳簿数量の修正）**です。この切り分けを誤ると、粗利率と営業利益の分析が完全に狂います。

## 2. 固定資産台帳・現物照合・新リース契約台帳の一元管理

固定資産は1件あたりの金額が大きく、償却計算の誤りが複数年度にわたり損益を歪めるため、**固定資産台帳（資産管理システム）**によるライフサイクル管理が不可欠です（[L3-06](L3-06), [L2C-04](L2C-04)）。

| 管理フェーズ | 現場で確認すべき実務ポイント | 会計上のリスクと対応単元 |
|---|---|---|
| **① 取得・資本的支出** | 見積書・検収書を揃えたうえで、「修繕費」か「資産計上（資本的支出）」かを社内金額基準・機能向上の有無で稟議判定する。付随費用（運賃・据付費）も取得原価に含める。 | 修繕費への過大計上による利益圧縮（税務否認リスク）→ [L3-06](L3-06) |
| **② 期中保有・現物照合** | 年1回、台帳から出力した「資産番号シール」と現物（PC・機械・車両）を照合する（固定資産実査）。使われなくなった遊休機械が判明したら**減損の兆候**を点検する。 | すでに廃棄済みで現物がないのに台帳に残り続ける「簿外廃棄（幽霊資産）」→ [L1C-06](L1C-06) |
| **③ 除却・廃棄** | 廃棄業者へ引き渡した際の**産業廃棄物管理票（マニフェスト）**や除却稟議書を保存し、帳簿価額からスクラップ見込額（`貯蔵品`）を差し引いた残額を `固定資産除却損` とする。 | 廃棄証明がないと税務上の除却損が認められないリスク→ [L3-06](L3-06) |
| **④ リース契約（第34号）** | 2027年4月施行・新リース会計基準（ASBJ第34号）では、原則すべての借手リースがオンバランス対象。総務・工場が結ぶコピー機・社用車・倉庫契約を**契約時点で経理のリース台帳へ集約**する仕組みが必須。 | 現場が勝手に結んだレンタル・サブスク契約に「実質リース」が含まれ、B/S計上漏れになるリスク→ [L2C-05](L2C-05), [L1C-08](L1C-08) |

## 3. 製造現場における標準原価・予定配賦の月次運用

工業簿記の現場（ERP・原価計算システム）では、月末に実際単価が出揃うのを待ってから製品原価を計算していては出荷価格も見積もりも間に合いません。そのため現場は**標準原価（[L2I-07](L2I-07)）**と**製造間接費の予定配賦（[L2I-03](L2I-03)）**で月次を回し、月末に発生した原価差異を部門別の責任指標としてレビューします。

- **価格差異（購買部の責任）**：市況高騰や急ぎの発注によるスポット購入、発注ロットの縮小が原因。
- **数量差異（製造部の責任）**：歩留まり悪化、新人作業員の熟練不足、機械トラブルによる仕損が原因。
- **操業度差異（営業・生産計画の責任）**：受注減により工場の稼働時間が基準操業度を下回った固定費の遊休ロス。

## 4. 並走ケーススタディ（完全検算済み・棚卸＆固定資産除却＆標準差異）

### Case A：期末実地棚卸のカットオフ修正と評価（128bit検算済み）
期末商品（単価 `1,200円`）の帳簿残高は `1,000個（1,200,000円）` であったが、実地棚卸と照合した結果、以下の事実が判明した。
1. 期末最終日に出荷・引渡済みの `40個（原価 48,000円）` の出庫登録が漏れていたため、売上原価（仕入勘定）へ振り替える（修正後帳簿数量 `960個 ＝ 1,152,000円`）。
2. 実地棚卸数量は `940個` であり、`20個（24,000円）` の純粋な棚卸減耗が確定した。
3. 実地 `940個` の期末正味売却価額（NRV）は `1,100円/個` へ下落していたため、`940個 × 100円 ＝ 94,000円` の商品評価損を計上する。
4. 結果として期末B/Sの `繰越商品` 残高は `940個 × 1,100円 ＝ 1,034,000円`（`1,200,000 - 48,000 - 24,000 - 94,000 = 1,034,000円`）となる。

### Case B：固定資産台帳に基づく200%定率法償却と除却（128bit検算済み）
- 2025年4月1日に機械装置 `2,000,000円` を取得（耐用年数5年、200%定率法・償却率 `0.40`）。
  - 1年目減価償却費：`2,000,000 × 0.40 = 800,000円`（期末帳簿価額 `1,200,000円`）
  - 2年目減価償却費：`1,200,000 × 0.40 = 480,000円`（累計額 `1,280,000円`、帳簿価額 `720,000円`）
- 2年目末に当該機械を廃棄除却し、解体処分費 `50,000円` を普通預金から支払い、回収可能な金属スクラップ評価額 `30,000円` を `貯蔵品` に計上した。
  - 固定資産除却損：`帳簿価額 720,000 + 解体費 50,000 - スクラップ 30,000 = 740,000円`

| 取引 | 借方科目 | 借方金額 | 貸方科目 | 貸方金額 |
| :--- | :--- | ---: | :--- | ---: |
| A1. カットオフ修正（出荷済振替） | 仕入 | 48,000 | 繰越商品 | 48,000 |
| A2. 棚卸減耗損の計上 | 棚卸減耗損 | 24,000 | 繰越商品 | 24,000 |
| A3. 商品評価損の計上 | 商品評価損 | 94,000 | 繰越商品 | 94,000 |
| B1. 2年目減価償却（間接法） | 減価償却費 | 480,000 | 減価償却累計額 | 480,000 |
| B2. 機械装置の廃棄除却 | 減価償却累計額 | 1,280,000 | 機械装置 | 2,000,000 |
|  | 貯蔵品 | 30,000 | 普通預金 | 50,000 |
|  | 固定資産除却損 | 740,000 | | |

### Case C：月次原価差異会議の数値検証（128bit検算済み）
- 当月完成品 `1,000個` の直接材料費標準：`2kg/個 × 500円/kg ＝ 1,000,000円`
- 当月実際消費：`2,120kg × 520円/kg ＝ 1,102,400円`
- **価格差異**（購買責任）：`(500 - 520) × 2,120kg = -42,400円`（不利差異）
- **数量差異**（製造責任）：`500 × (2,000kg - 2,120kg) = -60,000円`（不利差異）
- **合計差異**：`-42,400 + (-60,000) = -102,400円`（`1,000,000 - 1,102,400` と完全一致）

## 5. 実務・分析の落とし穴（よくある誤解と確認ポイント）

1. **実地棚卸時の「預り在庫・積送在庫」の混入**：顧客に販売済みで保管だけ預かっている商品や、他社から預かっている受託品を自社の実地棚卸にカウントしてしまうと、期末在庫が過大になり利益が架空に膨らみます（別エリア隔離とタグ色分けが鉄則）。
2. **幽霊資産の放置と償却超過**：現物は数年前に捨てたのに、稟議が面倒で台帳から除却していない企業は非常に多く見られます。現物照合を行わないと、存在しない資産の減価償却費と固定資産税（償却資産税）を払い続けることになります。
3. **標準原価の放置**：原材料相場が1年前に比べて20%高騰しているのに標準原価を改定しないと、毎月巨額の不利差異が発生し続け、営業が赤字案件を黒字と誤認して受注する危険があります。

## 6. 定着チェックリスト

- [ ] 実地棚卸で差異が出たとき、いきなり棚卸減耗損にせず「カットオフ・入出庫入力漏れ」を先に切り分ける理由を説明できる。
- [ ] 固定資産台帳の現物照合（固定資産棚卸）を行わないとどのような問題（幽霊資産・減損漏れ・税務リスク）が起きるか説明できる。
- [ ] 新リース会計基準（第34号）の適用にあたり、総務・工場の契約をリース台帳へ一元集約する必要がある理由を説明できる。
- [ ] 上記ケースA（期末商品 `1,034,000円`）・ケースB（除却損 `740,000円`）・ケースC（価格差異 `-42,400円` / 数量差異 `-60,000円`）を自力で検算できる。
- [ ] 原価差異を「価格差異（購買）」「数量差異（製造）」「操業度差異（計画）」に分けて月次会議で議論する実務上の意味を説明できる。
