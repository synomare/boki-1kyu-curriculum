# CS-02：商業簿記・会計学 必須仕訳トリガー＆判断フローチャート集（3級→1級）

> **本巻の設計思想**：仕訳を「貸借のパターン」で丸暗記すると、少し問題文をひねられた瞬間に破綻します。本巻では**「問題文のキーワード → 経済的実態（5要素の増減）→ 仕訳の型」**を0.5秒で逆引きするトリガー表と、受験生が逆転しやすい罠の対比、さらに検算済みミニ仕訳を収録しました。

## 1. テーマ別「問題文キーワード → 5要素導出 → 仕訳トリガー」逆引き表

| キーワード / 状況 | 経済的実態（何が起きたか） | 仕訳の型（借方 ／ 貸方） | 試験の罠・注意点 |
|---|---|---|---|
| **電子決済・キャッシュレス売上** | 現金即時回収ではなく決済事業者への債権発生（手数料控除） | `(借) 未収入金・電子決済債権 ＋ 支払手数料 ／ (貸) 売上` | 手数料を売上から直接控除せず、総額で売上計上する |
| **売上原価対立法での販売** | 商品（資産）が引き渡され、同時に売上原価（費用）が発生 | `① (借) 売掛金 ／ (貸) 売上` `② (借) 売上原価 ／ (貸) 商品` | 決算整理で「しーくり」は不要（期末商品が既に残高） |
| **クレジット売掛金（信販手数料）** | 販売時点で金利相当の信販手数料が確定 | `(借) クレジット売掛金 ＋ 支払手数料 ／ (貸) 売上` | 2027年4月改定後は電子記録債権・電子決済と区別して処理 |
| **契約資産 vs 売掛金（収益認識）** | 義務履行済だが「時の経過以外の条件」で請求未確定なら契約資産 | `(借) 契約資産 ／ (貸) 売上` → 請求権確定時に `(借) 売掛金 ／ (貸) 契約資産` | 前受金は「契約負債」という負債科目で処理する |
| **固定資産の除却・廃棄（3級〜）** | 使用中止し貯蔵品（処分見込価額）へ振替、残額が損失 | `(借) 減価償却累計額 ＋ 貯蔵品 ＋ 固定資産除却損 ／ (貸) 備品等` | 廃棄費用が発生した場合は貸方に現金預金等、借方の除却/廃棄損に加算 |
| **新リース基準：開始時** | 使用権という資産と、割引現在価値のリース料支払義務を取得 | `(借) 使用権資産 ／ (貸) リース負債`（＋前払分等は現金預金） | リース期間中の支払は「利息費用」と「リース負債元本返済」に分解 |
| **減損損失の計上** | 回収可能価額まで資産を切り下げ、将来損失を当期に認識 | `(借) 減損損失 ／ (貸) 建物等`（間接控除時は減損累計額） | 減損後は「減損後の帳簿価額」で残存耐用年数にわたり再償却 |
| **資産除去債務（ARO）利息** | 時の経過により割引現在価値の負債が元本に近づく増加分 | `(借) 利息費用 ／ (貸) 資産除去債務` | 資産の償却費とは別に、毎期必ず負債を割り戻す |
| **ヘッジ会計（繰延ヘッジ原則）** | ヘッジ手段（先物等）の時価変動を、対象取引の実現まで純資産に繰延 | `(借/貸) デリバティブ資産・負債 ／ (貸/借) 繰延ヘッジ損益` | 時価ヘッジ（その他有価証券等）はヘッジ対象の損益とP/Lで相殺 |
| **圧縮記帳（積立金方式）** | 国庫補助金受贈益への一時課税を回避するため、任意積立金として留保 | `(借) 繰越利益剰余金 ／ (貸) 圧縮積立金`（税効果も適用） | 直接減額方式と異なり、固定資産の取得原価と償却費は変わらない |
| **退職給付（連結の未認識差異）** | 連結B/Sで未認識数理計算上差異等を負債計上し、税効果後をOCIへ | `(借) 退職給付に係る調整額（OCI）＋繰延税金資産 ／ (貸) 退職給付に係る負債` | 当期の費用認識額（組替調整額）と逆仕訳を混同しない |
| **税効果（将来減算一時差異）** | 会計上は費用済だが税務上は将来損金算入＝税金の前払い（資産） | `(借) 繰延税金資産 ／ (貸) 法人税等調整額` | 評価差額（その他有価証券等）の一時差異は相手勘定を純資産直入にする |
| **連結：のれんの償却** | 支配獲得時の超過収益力が毎期消費される（20年以内定額法） | `(借) のれん償却 ／ (貸) のれん` | 支配獲得日に応じて月割計算を忘れない |

## 2. 受験生が借方・貸方を最も逆転させやすい「5大逆転トラップ対比表」

| トラップ名 | よく間違えるパターン | 正しい理解（5要素からの導出） | 0.5秒見分けフレーズ |
|---|---|---|---|
| **① 見越 vs 繰延** | 前払費用を負債、未払費用を資産にしてしまう | **前払・未収＝資産（借方）**／**前受・未払＝負債（貸方）** | 「未払＝あとで払う義務（負債）」「前払＝すでに払った権利（資産）」 |
| **② 繰延税金資産 vs 負債** | 会計上の利益と課税所得の大小で符号を逆にする | **会計費用先行（税務まだ）＝税金前払＝資産**／**税務費用先行＝税金後払＝負債** | 「貸倒引当金超過＝今は損金にならず税金先払い＝繰延税金資産」 |
| **③ 為替差益 vs 為替差損** | 円安・円高と外貨建資産・負債の掛け合わせで迷う | **円安＝1ドル100円→120円**：外貨債権は受取額増（益）、外貨債務は返済額増（損） | 「外貨を持っていれば円安で得、外貨を借りていれば円安で損」 |
| **④ 全部純資産直入 vs 部分純資産直入** | 評価損が出たときのP/L計上の有無を混ぜる | **全部**：益も損も全額純資産／**部分**：益は純資産、損は当期P/L損失（保守主義） | 「部分＝益は隠して損だけP/Lに出す」 |
| **⑤ 連結のアップストリーム未実現利益** | 非支配株主持分の負担仕訳の貸借を逆にする | 子会社利益を取り消すため、**非支配株主持分を減額（借方）**し、相手は非支配株主に帰属する当期純利益（貸方） | 「子会社の儲けを消す＝非支配株主の取り分も減る（持分は借方で減少）」 |

## 4. 本試験で迷わない「4大判断フローチャート」

### (1) 新リース基準（借手）免除判定フロー
```text
リース契約を締結した
  ├─ 契約に「特定された資産の使用権の支配」が含まれる？
  │     └─ NO → サービス契約（通常の費用処理・オンバランス不要）
  └─ YES → 短期（12ヶ月以下・購入オプションなし）または少額リースに該当し免除規定を選択する？
        ├─ YES → リース料を定額法等で費用処理（オフバランス容認）
        └─ NO  → 原則処理：使用権資産／リース負債を割引現在価値でオンバランス！
```

### (2) 固定資産の減損会計 2ステップ判定フロー
```text
減損の兆候がある（営業赤字継続、時価の著しい下落等）
  └─ Step1：割引前将来CF合計 ＜ 帳簿価額 か？
        ├─ NO  → 減損損失を認識しない（帳簿価額そのまま）
        └─ YES → Step2：回収可能価額 ＝ Max(正味売却価額, 使用価値) を算定
                   └─ 減損損失 ＝ 帳簿価額 − 回収可能価額（戻入れ禁止）
```

### (3) 投資有価証券の企業集団判定フロー
```text
他社株式を取得した
  ├─ 意思決定機関を「支配」している（50%超、または40〜50%＋実質支配要件）？
  │     └─ YES → 子会社株式（連結財務諸表の対象）
  └─ NO → 財務・営業方針に「重要な影響」を与えられる（20%以上、または15〜20%＋影響要件）？
        ├─ YES → 関連会社株式（持分法適用・個別は原価法）
        └─ NO  → その他有価証券（原則：時価評価・全部純資産直入法）
```

### (4) 繰延税金資産の計上可否フロー
```text
会計上の利益 ＜ 課税所得（将来減算一時差異が発生）
  └─ 将来の課税所得の見積り等に照らし「回収可能性」があるか？
        ├─ YES → (借) 繰延税金資産 ／ (貸) 法人税等調整額（またはOCI）
        └─ NO  → 評価性引当額を控除し、繰延税金資産は計上しない
```
